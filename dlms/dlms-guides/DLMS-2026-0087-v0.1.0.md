## SUMMARY
This procedure governs the onboarding of any one of the seven Storage and
Versioning Stage agent instances — the Tier 8 agents that commit verified
documents to storage, apply access controls, update the version registry,
and produce storage verification records. The Version Control Agent and
Access Control Agent write to distinct targets and must be confirmed as
separate instances; the Storage Verifier must not be the same instance as
the DoD Agent.

## SCOPE

Applies to:
- All seven Storage and Versioning Stage (Tier 8) agents listed below
- agent:storage-versioning-orchestrator as procedure owner
- sysadmin:dlm-sysadmin for separation verification and escalation
- Audit Trail Agent as recipient of onboarding audit events

The seven Storage and Versioning Stage agents:

| Agent | Designated output | Separation constraint |
|---|---|---|
| Context Curator (Storage) | storage-context.md | None beyond universal |
| DoD Agent (Storage) | storage-dod.md | Must not be same instance as Storage Verifier |
| Version Control Agent | version-log.md (committed versions) | Exclusive write to version-log; ≠ Access Control Agent |
| Access Control Agent | access-manifest.md | Exclusive write to access-manifest; ≠ Version Control Agent |
| Version Registry Updater | version-registry.md (appended entry) | None beyond universal |
| Storage Verifier | storage-verification.md + storage-learnings.md | Must not be same instance as DoD Agent |
| Storage Metrics Agent | storage-metrics.md | None beyond universal |

Excludes:
- Storage & Versioning Orchestrator onboarding (DLMS-2026-0083)
- Any agent outside Tier 8

Executed by:
- Onboarding agent (self-check): S02, S03, S04, S05, S06, S08, S09
- agent:storage-versioning-orchestrator: queue assignment (S08)
- sysadmin:dlm-sysadmin: separation verification (S07)

## PREREQUISITES

P01: DLMS-2026-0014, DLMS-2026-0015, and DLMS-2026-0016 are in effect.
     Additionally: DLMS-2026-0036 (Document Versioning Policy),
     DLMS-2026-0037 (Document Status Transition Policy), DLMS-2026-0038
     (Document Retention Policy), DLMS-2026-0041 (Definition of Done
     Policy), DLMS-2026-0044 (Access Control Policy), and DLMS-2026-0059
     (Storage Stage SLA) are in effect.
     Verified by: agent:storage-versioning-orchestrator. Failure → D01.

P02: This agent's designated context package includes: (a) the agent's role
     identifier and designated output schema; (b) the Storage DoD template
     reference (DLMS-2026-0026); (c) relevant artefact template references
     (DLMS-2026-0051 for Version Control Agent, DLMS-2026-0052 for Access
     Control Agent); (d) DLMS-2026-0044 for Access Control Agent (access
     control rule set).
     Verified by: agent:storage-versioning-orchestrator. Failure → E01.

P03: Audit Trail Agent is reachable. Failure → E03.

P04: agent:storage-versioning-orchestrator is active. If not, defer S08.

## STEPS

S01: Retrieve context package.
  action: Retrieve this agent's context package and confirm it satisfies
          P02. Note role, designated output schema, and (for Access Control
          Agent) the access control rule set reference.
  actor:  agent:storage-versioning-orchestrator
  reads:  designated context package
  writes: (none — verification only)
  on_failure: → E01

S02: Validate context boundary.
  action: Confirm READS is limited to: (a) the incoming verified document
          artefact for this role's processing step; (b) relevant output
          schema; (c) governing policies per P01; (d) access control rule
          set (Access Control Agent only). The NEVER list must exclude:
          other agents' write targets; document body content beyond what is
          needed for version commit or access manifest generation.
          Version Control Agent and Access Control Agent READS must not
          overlap on each other's write targets.
  actor:  Onboarding agent; verified by agent:storage-versioning-orchestrator
  reads:  context boundary specification
  writes: boundary validation result (internal)
  on_failure: → D02

S03: Load governing policies into context.
  action: Load: DLMS-2026-0014, DLMS-2026-0015, DLMS-2026-0016,
          DLMS-2026-0036, DLMS-2026-0037, DLMS-2026-0038, DLMS-2026-0041,
          DLMS-2026-0044 (Access Control Agent and Storage Verifier), and
          DLMS-2026-0059 (SLA). Load the designated output schema.
  actor:  Onboarding agent
  reads:  policy references from context package
  writes: active policy context (internal)
  on_failure: → E01

S04: Emit onboarding-start audit event.
  action: Write onboarding-start event per DLMS-2026-0015. Required fields:
          agent_id, role, stage = "storage", tier = 8,
          onboarding_procedure_ref = "DLMS-2026-0087", timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-start event)
  on_failure: → E03

S05: Confirm artefact format.
  action: Generate a zero-content test artefact against the designated
          output schema. For the Version Control Agent: confirm the test
          artefact includes version_number (semver), committed_at, and
          prior_version_ref fields per DLMS-2026-0036. For the Access
          Control Agent: confirm the test access-manifest includes a valid
          access_class field. For Storage Verifier: confirm it can parse
          a known-passing storage-dod artefact and emit a storage-
          verification artefact with outcome: pass.
  actor:  Onboarding agent
  reads:  designated output schema
  writes: test artefact (internal, discarded)
  on_failure: → E02

S06: Confirm SLA reference.
  action: Confirm DLMS-2026-0059 is loaded and SLA metric targets relevant
          to this role are accessible. The DoD Agent and Storage Verifier
          must be able to cite specific metric identifiers.
  actor:  Onboarding agent
  reads:  DLMS-2026-0059 from context
  writes: SLA confirmation (internal)
  on_failure: → E01

S07: Confirm separation criteria.
  action: Per the scope table constraints:
          - Version Control Agent: confirm agent_id ≠ Access Control Agent
          - Access Control Agent: confirm agent_id ≠ Version Control Agent
          - DoD Agent (Storage): confirm agent_id ≠ Storage Verifier
          - Storage Verifier: confirm agent_id ≠ DoD Agent
          Per DLMS-2026-0014 R01.
  actor:  sysadmin:dlm-sysadmin
  reads:  All Tier 8 agent_ids from orchestrator's active registry
  writes: separation confirmation note (internal)
  on_failure: → D03

S08: Register with Storage & Versioning Orchestrator.
  action: Dispatch registration event to agent:storage-versioning-
          orchestrator: agent_id, role, stage = "storage", onboarding_status
          = "complete". Receive queue assignment.
  actor:  Onboarding agent; agent:storage-versioning-orchestrator
  reads:  Orchestrator endpoint from context package
  writes: Queue assignment in orchestrator's active roster
  on_failure: → E04

S09: Emit onboarding-complete audit event.
  action: Write onboarding-complete event per DLMS-2026-0015. Required
          fields: agent_id, role, stage = "storage", tier = 8,
          onboarding_procedure_ref = "DLMS-2026-0087",
          outcome [success | failure], queue_assignment (or null if
          deferred), timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-complete event)
  on_failure: → E03

## DECISION_POINTS

D01: If P01 fails → halt. Notify orchestrator and sysadmin:dlm-sysadmin.

D02: If S02 fails (boundary out of spec) → halt. Notify orchestrator for
     context package correction.

D03: If S07 fails (separation violated) → halt. Escalate to
     sysadmin:dlm-sysadmin. Resolve before proceeding.

## OUTPUTS

| Artefact | Produced by step | Written to | Consumed by |
|---|---|---|---|
| Operational Storage agent with validated context | S02–S06 | internal state | Storage Orchestrator; pipeline |
| Queue assignment entry | S08 | Orchestrator's active roster | Storage Orchestrator |
| onboarding-start audit event | S04 | audit-trail.log | Audit Trail Agent |
| onboarding-complete audit event | S09 | audit-trail.log | Audit Trail Agent; orchestrator |

## ERROR_CONDITIONS

E01: Context package unavailable or incomplete.
  likely_cause: Artefact templates not yet authored; Access Control rule
                set not available.
  resolution:   Defer; escalate to sysadmin:dlm-sysadmin.

E02: Artefact format validation fails.
  likely_cause: Version schema fields missing; access class not defined.
  resolution:   Halt. Log. Escalate to sysadmin:dlm-sysadmin.

E03: Audit trail unreachable.
  resolution:   Halt. Alert sysadmin:dlm-sysadmin. Retry after reachable.

E04: Orchestrator rejects queue registration.
  resolution:   Halt. Notify sysadmin:dlm-sysadmin.
