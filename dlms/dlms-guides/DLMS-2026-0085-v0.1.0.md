## SUMMARY
This procedure governs the onboarding of any one of the eleven Review and
Approval Stage agent instances — the Tier 5 agents that take a draft through
multi-perspective review (four independent lenses), synthesis, revision,
approval gating, and verification. Multi-Perspective Review Policy
(DLMS-2026-0017) governs lens independence; the four Perspective Reviewers
must be confirmed as distinct instances at onboarding. The procedure_owner
is the Review & Approval Orchestrator; agents register with it on completion.

## SCOPE

Applies to:
- All eleven Review and Approval Stage (Tier 5) agents listed below
- agent:review-approval-orchestrator as procedure owner and queue authority
- sysadmin:dlm-sysadmin for escalation and complex separation checks
- Audit Trail Agent as recipient of onboarding audit events

The eleven Review and Approval Stage agents and their separation constraints:

| Agent | Designated output | Separation constraint |
|---|---|---|
| Context Curator (Review) | review-context.md | None beyond universal |
| DoD Agent (Review) | review-dod.md | Must not be same instance as Review Verifier |
| Perspective Reviewer A (Accuracy) | review-accuracy.md | Must not share instance with B, C, or D |
| Perspective Reviewer B (Completeness) | review-completeness.md | Must not share instance with A, C, or D |
| Perspective Reviewer C (Readability) | review-readability.md | Must not share instance with A, B, or D |
| Perspective Reviewer D (Structure) | review-structure.md | Must not share instance with A, B, or C |
| Review Synthesizer | review-synthesis.md | Must not be same instance as any Reviewer |
| Revision Agent | draft-v0.2-agent.md | None beyond universal |
| Approval Gate Agent | approval-status.md | Must not be same instance as Review Synthesizer |
| Review Verifier | review-verification.md + review-learnings.md | Must not be same instance as DoD Agent |
| Review Metrics Agent | review-metrics.md | None beyond universal |

Excludes:
- Review & Approval Orchestrator onboarding (DLMS-2026-0083)
- Any agent outside Tier 5
- Ongoing stage operation after onboarding is complete

Executed by:
- Onboarding agent (self-check): S02, S03, S04, S05, S06, S08, S09
- agent:review-approval-orchestrator: queue assignment (S08)
- sysadmin:dlm-sysadmin: separation verification for Perspective Reviewers
  and cross-role checks (S07)

## PREREQUISITES

P01: DLMS-2026-0014, DLMS-2026-0015, and DLMS-2026-0016 are in effect.
     Additionally: DLMS-2026-0017 (Multi-Perspective Review Policy),
     DLMS-2026-0041 (Definition of Done Policy), DLMS-2026-0042 (Review
     Standards Policy), DLMS-2026-0043 (Quality Threshold Policy), and
     DLMS-2026-0058 (Review Stage SLA) are in effect.
     Verified by: agent:review-approval-orchestrator. Failure → D01.

P02: This agent's designated context package exists and contains: (a) this
     agent's role identifier and designated output schema; (b) the Review
     Stage DoD template reference (DLMS-2026-0025); (c) the relevant
     artefact template references for this role (DLMS-2026-0048 for
     Perspective Reviewers, DLMS-2026-0049 for Review Synthesizer,
     DLMS-2026-0050 for Approval Gate Agent); (d) for Perspective Reviewers:
     the assigned lens definition (accuracy | completeness | readability |
     structure); (e) references to DLMS-2026-0015, DLMS-2026-0016, and
     DLMS-2026-0017.
     Verified by: agent:review-approval-orchestrator. Failure → E01.

P03: Audit Trail Agent is reachable. Failure → E03.

P04: agent:review-approval-orchestrator is active and accepting queue
     registrations. If not active, defer S08; steps S01–S07 and S09 may
     proceed.

## STEPS

S01: Retrieve context package.
  action: Retrieve this agent's designated context package and confirm it
          satisfies P02. Note the agent's role identifier, designated lens
          (for Perspective Reviewers), and designated output schema.
  actor:  agent:review-approval-orchestrator (on behalf of onboarding agent)
  reads:  designated context package
  writes: (none — verification only)
  on_failure: → E01

S02: Validate context boundary.
  action: Confirm the READS list is limited to: (a) the incoming artefact(s)
          this agent is designated to read for its role; (b) the relevant
          output artefact template schema(s); (c) governing policies per P01.
          For Perspective Reviewers: READS must include only the document
          under review and this reviewer's lens definition — it must NOT
          include other reviewers' output artefacts (DLMS-2026-0017 R05:
          lens independence). The NEVER list must explicitly exclude other
          reviewers' perspective reports.
  actor:  Onboarding agent (self-check); verified by
          agent:review-approval-orchestrator
  reads:  context boundary specification within context package
  writes: boundary validation result (internal)
  on_failure: → D02

S03: Load governing policies into context.
  action: Load into active context: DLMS-2026-0014, DLMS-2026-0015,
          DLMS-2026-0016, DLMS-2026-0017, DLMS-2026-0041, DLMS-2026-0042,
          DLMS-2026-0043, DLMS-2026-0058, and the artefact template schemas
          relevant to this role.
          For Perspective Reviewers: additionally confirm the assigned lens
          definition is loaded. DLMS-2026-0017 requires each lens to have a
          distinct evaluation perspective with no content overlap.
  actor:  Onboarding agent
  reads:  policy and template references from context package
  writes: active policy context (internal)
  on_failure: → E01

S04: Emit onboarding-start audit event.
  action: Write onboarding-start event per DLMS-2026-0015. Required fields:
          agent_id, role, stage = "review", tier = 5,
          onboarding_procedure_ref = "DLMS-2026-0085",
          lens_assigned (for Perspective Reviewers; null for all others),
          timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-start event)
  on_failure: → E03

S05: Confirm artefact format.
  action: Generate a zero-content test artefact against this agent's
          designated output schema and confirm it passes format validation.
          The test artefact is not persisted.
          For Perspective Reviewers: test artefact must include a valid
          lens_id field matching the assigned lens.
          For Review Synthesizer: test artefact must include placeholder
          fields for all four perspective_report_refs (A, B, C, D).
          For Approval Gate Agent: test artefact must include
          decision [approved | deferred | rejected] as a required field.
  actor:  Onboarding agent
  reads:  designated output schema from context package
  writes: test artefact (internal, discarded)
  on_failure: → E02

S06: Confirm SLA reference.
  action: Confirm DLMS-2026-0058 (Review Stage SLA) is loaded in context
          and that this agent can cite the SLA metric identifiers relevant
          to its role. The DoD Agent and Review Verifier must be able to
          name specific metric targets; other agents confirm the SLA is
          present.
  actor:  Onboarding agent
  reads:  DLMS-2026-0058 from context
  writes: SLA reference confirmation (internal)
  on_failure: → E01

S07: Confirm separation criteria.
  action: Per the separation constraints in the scope table:
          - Perspective Reviewers A, B, C, D: confirm all four are distinct
            agent_id values. Per DLMS-2026-0017 R05 and DLMS-2026-0014 R01.
          - Review Synthesizer: confirm agent_id ≠ any Reviewer's agent_id.
          - Approval Gate Agent: confirm agent_id ≠ Review Synthesizer's
            agent_id.
          - DoD Agent (Review): confirm agent_id ≠ Review Verifier's
            agent_id.
          - All others: confirm agent_id ≠ downstream Review Verifier.
          sysadmin:dlm-sysadmin verifies Reviewer separation (four-way
          check); agent:review-approval-orchestrator verifies all other
          constraints.
  actor:  sysadmin:dlm-sysadmin (Reviewer four-way check);
          agent:review-approval-orchestrator (all other constraints)
  reads:  All Tier 5 agent_ids from the orchestrator's active agent registry
  writes: separation confirmation note (internal)
  on_failure: → D03

S08: Register with Review & Approval Orchestrator.
  action: Dispatch registration event to agent:review-approval-orchestrator:
          agent_id, role, lens_assigned (or null), stage = "review",
          onboarding_status = "complete". Receive and record queue
          assignment.
  actor:  Onboarding agent; agent:review-approval-orchestrator
  reads:  agent:review-approval-orchestrator endpoint from context package
  writes: Queue assignment entry in review orchestrator's active roster
  on_failure: → E04

S09: Emit onboarding-complete audit event.
  action: Write onboarding-complete event per DLMS-2026-0015. Required
          fields: agent_id, role, stage = "review", tier = 5,
          onboarding_procedure_ref = "DLMS-2026-0085",
          outcome [success | failure], lens_assigned (or null),
          queue_assignment (or null if deferred), timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-complete event)
  on_failure: → E03

## DECISION_POINTS

D01: If P01 fails (any required policy not in effect) → halt. Notify
     agent:review-approval-orchestrator and sysadmin:dlm-sysadmin.

D02: If S02 fails (boundary out of spec, or Perspective Reviewer READS
     includes another reviewer's output) → halt. Do not initiate. Notify
     agent:review-approval-orchestrator for context package correction.
     Lens independence (DLMS-2026-0017 R05) is a non-negotiable constraint
     — a Perspective Reviewer that can read peer output cannot be onboarded.

D03: If S07 fails (any separation constraint violated) → halt. Escalate to
     sysadmin:dlm-sysadmin. All four Reviewer instances and all constrained
     pairs must be provisioned as distinct instances before any can be
     onboarded.

## OUTPUTS

| Artefact | Produced by step | Written to | Consumed by |
|---|---|---|---|
| Operational Review Stage agent with validated context | S02–S06 | internal state | Review Orchestrator; stage pipeline |
| Queue assignment entry in review orchestrator | S08 | Review Orchestrator's active roster | Review & Approval Orchestrator |
| onboarding-start audit event | S04 | audit-trail.log | Audit Trail Agent; Agent Behaviour Analyst (CI) |
| onboarding-complete audit event | S09 | audit-trail.log | Audit Trail Agent; agent:review-approval-orchestrator |

## ERROR_CONDITIONS

E01: Context package unavailable or missing required references.
  condition:    Package unreachable or lens definition absent for Perspective
                Reviewer; output schema not found.
  likely_cause: Artefact templates not yet authored; incorrect package path;
                lens definition not included in context package.
  resolution:   agent:review-approval-orchestrator defers onboarding;
                escalate to sysadmin:dlm-sysadmin if unresolvable.

E02: Artefact format validation fails.
  condition:    Agent cannot produce a conformant test artefact in S05.
  likely_cause: Output schema not loaded or missing required fields.
  resolution:   Halt. Log failure. Escalate to sysadmin:dlm-sysadmin.

E03: Audit trail unreachable.
  condition:    S04 or S09 cannot write to audit-trail.log.
  likely_cause: Audit Trail Agent offline; message bus fault.
  resolution:   Halt. Alert sysadmin:dlm-sysadmin. Retry after both events
                can be written.

E04: Review & Approval Orchestrator rejects queue registration.
  condition:    Orchestrator returns rejection or non-acknowledgement in S08.
  likely_cause: Orchestrator not active; role slot already filled; version
                mismatch.
  resolution:   Halt. Notify sysadmin:dlm-sysadmin.
