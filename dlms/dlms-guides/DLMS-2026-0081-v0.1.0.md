## SUMMARY
This procedure governs onboarding of a DLM System Orchestrator agent
instance — the single Tier 1 routing agent that dispatches documents to
stage orchestrators without ever reading document content. The trigger is
deployment or re-activation after maintenance; the primary outputs are a
validated operational instance with a confirmed routing table and a pair of
onboarding audit events recorded in the audit trail.

## SCOPE

Applies to:
- The DLM System Orchestrator agent (exactly one active instance system-wide)
- sysadmin:dlm-sysadmin in the roles of procedure owner and separation verifier
- Audit Trail Agent as recipient of onboarding audit events

Excludes:
- Ongoing document routing operations after onboarding is complete
- Configuration or onboarding of stage orchestrators (covered by DLMS-2026-0083)
- Any agent not identified as the DLM System Orchestrator

Executed by:
- DLM System Orchestrator: self-check steps (S02, S03, S04, S05, S07)
- sysadmin:dlm-sysadmin: retrieval, validation, and separation steps
  (S01, S02 verification, S06)

## PREREQUISITES

P01: DLMS-2026-0014 (Verification Independence Policy), DLMS-2026-0015
     (Audit Trail Policy), and DLMS-2026-0016 (Agent Context Boundary
     Policy) are status: approved or provisionally in effect.
     Verified by: sysadmin:dlm-sysadmin. Failure → D01.

P02: The DLM System Orchestrator's designated context package exists and
     contains: (a) a routing table mapping each of the six stage identifiers
     (creation | review | indexing | storage | distribution | archival) to
     a stage orchestrator endpoint; (b) references to DLMS-2026-0015 and
     DLMS-2026-0016.
     Verified by: sysadmin:dlm-sysadmin. Failure → E01.

P03: Audit Trail Agent is reachable and accepting events. Verified by:
     test ping to Audit Trail Agent endpoint with positive acknowledgement.
     Failure → E03.

P04: At least one stage orchestrator (Tier 3) is active and registered as a
     valid routing target. Verified by: sysadmin:dlm-sysadmin via Tier 3
     status check. Failure → defer onboarding until at least one Tier 3
     orchestrator is active.

## STEPS

S01: Retrieve context package.
  action: Retrieve the DLM System Orchestrator's designated context package
          and confirm it satisfies P02. Record context_package_retrieved_at
          (ISO 8601).
  actor:  sysadmin:dlm-sysadmin
  reads:  designated context package
  writes: (none — verification only)
  on_failure: → E01

S02: Validate context boundary.
  action: Confirm the READS list in the context boundary specification is
          limited exclusively to: (a) routing table; (b) audit event schema
          (DLMS-2026-0015). Confirm the NEVER list explicitly excludes all
          document body content, all policy bodies, all template bodies, and
          all artefact content. Any document-content or policy-body resource
          appearing in READS renders the boundary invalid.
  actor:  DLM System Orchestrator (self-check); verified by
          sysadmin:dlm-sysadmin per DLMS-2026-0016
  reads:  context boundary specification within context package
  writes: boundary validation result (internal)
  on_failure: → D02

S03: Load routing table.
  action: Load the routing table into active working context. Confirm it
          contains exactly one entry per stage identifier:
          creation | review | indexing | storage | distribution | archival.
          No stage may be absent or mapped to more than one endpoint.
  actor:  DLM System Orchestrator
  reads:  routing table from context package
  writes: active routing table (internal state)
  on_failure: → E01 (if table is malformed or has fewer than six entries)

S04: Emit onboarding-start audit event.
  action: Write an onboarding-start event to the audit trail per
          DLMS-2026-0015. Required fields: agent_id = "agent:dlm-system-
          orchestrator", tier = 1, onboarding_procedure_ref = "DLMS-2026-0081",
          timestamp (ISO 8601).
  actor:  DLM System Orchestrator
  reads:  DLMS-2026-0015 (audit event schema)
  writes: audit-trail.log (onboarding-start event)
  on_failure: → E03

S05: Confirm routing capability.
  action: Send a routing ping to each endpoint in the active routing table
          (one per stage, six total). For each, record: stage_id, endpoint,
          acknowledgement_received (boolean), acknowledgement_at (ISO 8601
          or null). A stage is reachable if it returns a positive
          acknowledgement within 30 seconds.
  actor:  DLM System Orchestrator
  reads:  active routing table (from S03)
  writes: ping result log (internal)
  on_failure: If zero stages reachable → halt; see E02.
              If some stages unreachable → continue to S06; log unavailable
              stages in S07; notify sysadmin:dlm-sysadmin.

S06: Confirm separation criterion.
  action: Confirm the Audit Trail Agent is a distinct agent instance with a
          distinct agent_id from the DLM System Orchestrator. No single agent
          may both route documents and audit those routing events, per
          DLMS-2026-0014 R01.
  actor:  sysadmin:dlm-sysadmin
  reads:  Audit Trail Agent's agent_id from context package or agent registry
  writes: confirmation note (internal)
  on_failure: → D03

S07: Emit onboarding-complete audit event.
  action: Write an onboarding-complete event to the audit trail per
          DLMS-2026-0015. Required fields: agent_id, tier = 1,
          onboarding_procedure_ref = "DLMS-2026-0081",
          outcome [success | failure], stages_reachable (array of stage
          identifiers confirmed in S05), stages_unavailable (array or empty),
          timestamp (ISO 8601).
  actor:  DLM System Orchestrator
  reads:  DLMS-2026-0015 (audit event schema); ping result log from S05
  writes: audit-trail.log (onboarding-complete event)
  on_failure: → E03

## DECISION_POINTS

D01: If P01 fails (any required policy not approved or provisionally in
     effect) → halt. Notify sysadmin:dlm-sysadmin. Do not proceed until all
     three policies are in effect.

D02: If S02 fails (context boundary contains any document-content or policy-
     body resource in READS) → halt. Do not initiate the agent. Notify
     sysadmin:dlm-sysadmin for context package correction before
     re-attempting from S01.

D03: If S06 fails (Audit Trail Agent is the same instance as the DLM System
     Orchestrator, or no distinct Audit Trail Agent with a separate agent_id
     exists) → halt. Escalate to sysadmin:dlm-sysadmin.

## OUTPUTS

| Artefact | Produced by step | Written to | Consumed by |
|---|---|---|---|
| Operational DLM System Orchestrator with active routing table | S03 | internal agent state | All six Tier 3 stage orchestrators |
| onboarding-start audit event | S04 | audit-trail.log | Audit Trail Agent; Agent Behaviour Analyst (CI) |
| onboarding-complete audit event | S07 | audit-trail.log | Audit Trail Agent; sysadmin:dlm-sysadmin |

## ERROR_CONDITIONS

E01: Context package unavailable or routing table incomplete.
  condition:    Context package is unreachable, or routing table contains
                fewer than six stage entries, or an entry lacks a valid
                endpoint.
  likely_cause: Corpus not yet populated; incorrect context package path;
                one or more Tier 3 orchestrators not yet instantiated.
  resolution:   sysadmin:dlm-sysadmin provides corrected context package or
                defers onboarding until all six stage orchestrators are
                active.

E02: All stage orchestrator pings fail.
  condition:    Zero stage orchestrators return a positive acknowledgement
                in S05 within 30 seconds.
  likely_cause: Tier 3 orchestrators not yet deployed; message bus or
                network path not operational.
  resolution:   Halt at S05. Notify sysadmin:dlm-sysadmin. Retry only
                after at least one Tier 3 orchestrator is confirmed active.

E03: Audit trail unreachable.
  condition:    S04 or S07 cannot write an event to audit-trail.log.
  likely_cause: Audit Trail Agent offline; message bus fault; permission
                misconfiguration.
  resolution:   Halt at the failing step. Do not proceed. Do not mark
                onboarding complete. Alert sysadmin:dlm-sysadmin. Retry
                only after Audit Trail Agent is reachable and both required
                events are written.
