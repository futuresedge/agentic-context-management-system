## SUMMARY
This procedure governs the onboarding of any one of the twelve Indexing and
Classification Stage agent instances — the Tier 7 agents that extract,
classify, validate, and persist metadata and index entries for every document
that passes through the DLMS. The Classification Agent's use of the Taxonomy
(DLMS-2026-0021) as a controlled vocabulary constraint must be confirmed at
onboarding. There is no dedicated stage SLA for this stage; quality is
governed by Metadata Standard Policy (DLMS-2026-0018) and Taxonomy Policy
(DLMS-2026-0019).

## SCOPE

Applies to:
- All twelve Indexing and Classification Stage (Tier 7) agents listed below
- agent:indexing-classification-orchestrator as procedure owner
- sysadmin:dlm-sysadmin for separation verification
- Audit Trail Agent as recipient of onboarding audit events

The twelve Indexing and Classification Stage agents:

| Agent | Designated output | Separation constraint |
|---|---|---|
| Context Curator (Indexing) | indexing-context.md | None beyond universal |
| DoD Agent (Indexing) | indexing-dod.md | Must not be same instance as Indexing Verifier |
| Metadata Extractor | metadata-raw.md | None beyond universal |
| Classification Agent | metadata-final.md | Must not be same instance as Taxonomy Validator |
| Taxonomy Validator | taxonomy-validation.md | Must not be same instance as Classification Agent |
| Indexing Verifier | indexing-verification.md + indexing-learnings.md | Must not be same instance as DoD Agent |
| Index Update Orchestrator | (routes to index updaters; no output artefact) | Must not be same instance as any index updater |
| Master Index Updater | master-index.md (appended entry) | Exclusive write — no other agent writes master-index |
| Type Index Updater | index-by-type.md (appended entry) | Exclusive write |
| Tag Index Updater | index-by-tag.md (appended entry) | Exclusive write |
| Dependency Index Updater | dependency-graph.md (appended entry) | Exclusive write |
| Indexing Metrics Agent | indexing-metrics.md | None beyond universal |

Note: The three index updater agents (Master, Type, Tag) write to documents
also written by Tier 2 Governance Layer agents (Master Index Agent, Type
Index Agent, Tag Index Agent). These are not conflicts — the Tier 2 agents
maintain the index structures; the Tier 7 updaters append per-document
entries. Exclusive write within this stage means no two Tier 7 updater
instances write to the same index in the same indexing pipeline pass.

Excludes:
- Indexing & Classification Orchestrator onboarding (DLMS-2026-0083)
- Any agent outside Tier 7

Executed by:
- Onboarding agent (self-check): S02, S03, S04, S05, S06, S08, S09
- agent:indexing-classification-orchestrator: queue assignment (S08)
- sysadmin:dlm-sysadmin: separation verification (S07)

## PREREQUISITES

P01: DLMS-2026-0014, DLMS-2026-0015, and DLMS-2026-0016 are in effect.
     Additionally: DLMS-2026-0018 (Metadata Standard Policy),
     DLMS-2026-0019 (Taxonomy Policy), DLMS-2026-0021 (Taxonomy /
     Controlled Vocabulary), and DLMS-2026-0041 (Definition of Done Policy)
     are in effect. Verified by: agent:indexing-classification-orchestrator.
     Failure → D01.

P02: This agent's designated context package includes: (a) the agent's role
     identifier and designated output schema; (b) the Indexing DoD template
     reference (DLMS-2026-0027); (c) the relevant artefact template
     references (DLMS-2026-0031 for Metadata Extractor, DLMS-2026-0032 for
     Classification Agent, DLMS-2026-0033 for index entry updaters);
     (d) for the Classification Agent: a reference to the active Taxonomy
     (DLMS-2026-0021) as the controlled vocabulary source.
     Verified by: agent:indexing-classification-orchestrator. Failure → E01.

P03: Audit Trail Agent is reachable. Failure → E03.

P04: agent:indexing-classification-orchestrator is active. If not, defer
     S08; other steps may proceed.

## STEPS

S01: Retrieve context package.
  action: Retrieve this agent's designated context package and confirm it
          satisfies P02. Note the role identifier, designated output schema,
          and (for Classification Agent and Taxonomy Validator) the Taxonomy
          reference.
  actor:  agent:indexing-classification-orchestrator
  reads:  designated context package
  writes: (none — verification only)
  on_failure: → E01

S02: Validate context boundary.
  action: Confirm READS is limited to: (a) incoming document metadata or
          index events relevant to this role; (b) output schema for this
          role; (c) governing policies per P01; (d) DLMS-2026-0021 for
          Classification Agent and Taxonomy Validator only. The NEVER list
          must exclude: document body content beyond identifiers; other
          stages' artefacts. Classification Agent's READS must not include
          the Taxonomy Validator's output artefact (independence of
          classification and validation, per DLMS-2026-0014 R01).
  actor:  Onboarding agent; verified by agent:indexing-classification-
          orchestrator
  reads:  context boundary specification
  writes: boundary validation result (internal)
  on_failure: → D02

S03: Load governing policies into context.
  action: Load: DLMS-2026-0014, DLMS-2026-0015, DLMS-2026-0016,
          DLMS-2026-0018, DLMS-2026-0019, DLMS-2026-0041, and output schema
          for this role. Classification Agent and Taxonomy Validator also
          load DLMS-2026-0021 (the active version of the controlled
          vocabulary).
  actor:  Onboarding agent
  reads:  policy references from context package
  writes: active policy context (internal)
  on_failure: → E01

S04: Emit onboarding-start audit event.
  action: Write onboarding-start event per DLMS-2026-0015. Required fields:
          agent_id, role, stage = "indexing", tier = 7, onboarding_procedure_ref
          = "DLMS-2026-0086", timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-start event)
  on_failure: → E03

S05: Confirm artefact format.
  action: Generate a zero-content test artefact against this agent's
          designated output schema. For Classification Agent: test artefact
          must include a tags array where all entries are valid values from
          DLMS-2026-0021. Use a known-valid tag (e.g. "policy") for the test.
          For Taxonomy Validator: confirm it can evaluate a metadata-final
          artefact against DLMS-2026-0021 and emit a taxonomy-validation
          artefact with outcome: pass. For Index Updaters: confirm the test
          entry includes all required index entry fields per
          DLMS-2026-0033.
  actor:  Onboarding agent
  reads:  designated output schema; DLMS-2026-0021 (as applicable)
  writes: test artefact (internal, discarded)
  on_failure: → E02

S06: Confirm exclusive write target (Index Updaters only).
  action: For each Index Updater agent (Master, Type, Tag, Dependency):
          confirm no other active Tier 7 index updater instance is already
          assigned the same write target within this pipeline pass.
          Exclusivity is checked via the indexing orchestrator's active
          agent registry.
          For all other Tier 7 agents: this step is a no-op; record "N/A"
          and proceed.
  actor:  agent:indexing-classification-orchestrator
  reads:  Indexing orchestrator's active agent registry
  writes: (none — verification only)
  on_failure: → D04

S07: Confirm separation criteria.
  action: Per the separation constraints in the scope table:
          - Classification Agent: confirm agent_id ≠ Taxonomy Validator
          - Taxonomy Validator: confirm agent_id ≠ Classification Agent
          - DoD Agent: confirm agent_id ≠ Indexing Verifier
          - Index Update Orchestrator: confirm agent_id ≠ any Index Updater
          Per DLMS-2026-0014 R01.
  actor:  sysadmin:dlm-sysadmin
  reads:  All Tier 7 agent_ids from orchestrator's active registry
  writes: separation confirmation note (internal)
  on_failure: → D03

S08: Register with Indexing & Classification Orchestrator.
  action: Dispatch registration event to
          agent:indexing-classification-orchestrator: agent_id, role,
          stage = "indexing", onboarding_status = "complete". Receive queue
          assignment.
  actor:  Onboarding agent; agent:indexing-classification-orchestrator
  reads:  Orchestrator endpoint from context package
  writes: Queue assignment in orchestrator's active roster
  on_failure: → E04

S09: Emit onboarding-complete audit event.
  action: Write onboarding-complete event per DLMS-2026-0015. Required
          fields: agent_id, role, stage = "indexing", tier = 7,
          onboarding_procedure_ref = "DLMS-2026-0086",
          outcome [success | failure], queue_assignment (or null if
          deferred), timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-complete event)
  on_failure: → E03

## DECISION_POINTS

D01: If P01 fails → halt. Notify orchestrator and sysadmin:dlm-sysadmin.

D02: If S02 fails (boundary out of spec) → halt. Notify orchestrator for
     context package correction.

D03: If S07 fails (separation constraint violated) → halt. Escalate to
     sysadmin:dlm-sysadmin. Resolve before onboarding proceeds.

D04: If S06 finds an exclusive write conflict (Index Updater) → halt.
     Notify agent:indexing-classification-orchestrator to deactivate the
     conflicting instance and resolve before this agent proceeds to S07.

## OUTPUTS

| Artefact | Produced by step | Written to | Consumed by |
|---|---|---|---|
| Operational Indexing agent with validated context | S02–S05 | internal state | Indexing Orchestrator; pipeline |
| Queue assignment entry | S08 | Orchestrator's active roster | Indexing Orchestrator |
| onboarding-start audit event | S04 | audit-trail.log | Audit Trail Agent; Agent Behaviour Analyst |
| onboarding-complete audit event | S09 | audit-trail.log | Audit Trail Agent; orchestrator |

## ERROR_CONDITIONS

E01: Context package unavailable or incomplete.
  likely_cause: Metadata artefact templates or Taxonomy not yet authored.
  resolution:   Defer onboarding; escalate to sysadmin:dlm-sysadmin.

E02: Artefact format validation fails.
  likely_cause: Output schema not loaded; Classification Agent tags not
                validated against DLMS-2026-0021.
  resolution:   Halt. Log failure. Escalate to sysadmin:dlm-sysadmin.

E03: Audit trail unreachable.
  resolution:   Halt. Alert sysadmin:dlm-sysadmin. Retry after reachable.

E04: Orchestrator rejects queue registration.
  likely_cause: Orchestrator not active; role slot duplicate.
  resolution:   Halt. Notify sysadmin:dlm-sysadmin.
