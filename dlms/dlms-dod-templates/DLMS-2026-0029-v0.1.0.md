## SUMMARY
This template defines the structure of a Definition of Done completion record
for the Archival stage gate. The Archival Agent must produce a completed
record confirming that a document has been correctly transitioned to archived
status in accordance with the Retention Schedule (DLMS-2026-0022). Archival
is irreversible; the DoD gate ensures no document is incorrectly archived.

## TARGET_DOC_TYPE
dod-archival-record

## PURPOSE
The Archival DoD is the terminal gate of the document lifecycle. It confirms
that the retention schedule has been consulted, an archival recommendation
exists, access has been revoked or restricted, the document status is set to
archived, and that all supersession relationships are correctly recorded.
Once this DoD passes, the document leaves active circulation permanently.

## RECORD_SCHEMA

### Header_Fields

FIELD_01:
  name:        dod_id
  type:        string
  required:    true
  nullable:    false
  format:      DOD-archival-{doc_id}-{version}
  example:     DOD-archival-DLMS-2026-0030-1.0.0
  description: Unique identifier for this DoD completion record. Immutable.

FIELD_02:
  name:        doc_id
  type:        string
  required:    true
  description: The DLMS doc_id of the document being archived.

FIELD_03:
  name:        doc_version
  type:        string
  required:    true
  format:      MAJOR.MINOR.PATCH
  description: The version of the document being archived.

FIELD_04:
  name:        stage
  type:        string
  required:    true
  value:       archival
  description: Fixed value. Identifies this as an Archival stage DoD record.

FIELD_05:
  name:        evaluated_by
  type:        string
  required:    true
  description: agent_id of the Archival Verifier completing this record.
  constraints:
    - Must differ from the Archival Agent that performed the archival action

FIELD_06:
  name:        evaluated_at
  type:        datetime
  required:    true
  format:      ISO 8601 with timezone
  description: Timestamp when the DoD evaluation was completed.

FIELD_07:
  name:        archival_trigger
  type:        enum
  required:    true
  values:      [retention-schedule, superseded, sysadmin-directive,
               quality-failure, end-of-lifecycle]
  description: The reason archival was initiated. Required for audit trail.

### Checklist_Items

Each item carries three sub-fields:
  result:    pass | fail
  mandatory: true | false   (fail on a mandatory item = hard block)
  notes:     string | null  (required when result is fail)

ITEM_01:
  id:          CI-ARCHIVAL-01
  label:       Retention schedule consulted
  check:       The Retention Schedule (DLMS-2026-0022) has been read and
               the document's retention_class confirmed as permitting
               archival at this time.
  mandatory:   true
  governed_by: DLMS-2026-0022

ITEM_02:
  id:          CI-ARCHIVAL-02
  label:       Archival recommendation artefact exists
  check:       An Archival Recommendation artefact has been produced
               for this doc_id and doc_version, stating the trigger
               and justification for archival.
  mandatory:   true
  governed_by: DLMS-2026-0022

ITEM_03:
  id:          CI-ARCHIVAL-03
  label:       Document status set to archived
  check:       The document's status field value is archived at the
               time of this evaluation.
  mandatory:   true
  governed_by: DLMS-2026-0004

ITEM_04:
  id:          CI-ARCHIVAL-04
  label:       Access revoked or restricted per Access Manifest
  check:       The Access Manifest for this document has been updated to
               reflect archived status, and active-distribution access has
               been revoked.
  mandatory:   true
  governed_by: DLMS-2026-0016

ITEM_05:
  id:          CI-ARCHIVAL-05
  label:       superseded_by set correctly if document was superseded
  check:       If the archival_trigger is "superseded", the superseded_by
               field is non-null and references a valid, existing doc_id.
               If the trigger is not "superseded", superseded_by is null
               or the existing value is confirmed correct.
  mandatory:   true
  governed_by: DLMS-2026-0004, DLMS-2026-0020

ITEM_06:
  id:          CI-ARCHIVAL-06
  label:       Archival log entry created
  check:       An Archival Log entry has been produced for this archival
               event, recording the trigger, the evaluated_by agent, and
               the evaluated_at timestamp.
  mandatory:   true
  governed_by: DLMS-2026-0015

ITEM_07:
  id:          CI-ARCHIVAL-07
  label:       context_eligible set to false
  check:       The document's context_eligible field has been set to false
               to exclude it from any future context package delivery.
  mandatory:   true
  governed_by: DLMS-2026-0016, DLMS-2026-0004

ITEM_08:
  id:          CI-ARCHIVAL-08
  label:       Archival audit event queued
  check:       A document-archived audit event has been prepared for the
               Audit Trail Agent and will be submitted on DoD passage.
  mandatory:   true
  governed_by: DLMS-2026-0015

### Attestation_Block

attestation:
  dod_id:          {value from Header FIELD_01}
  verdict:         pass | fail
  blocking_items:  list of ITEM IDs where result: fail AND mandatory: true
                   (empty list [] when verdict is pass)
  observations:    list of ITEM IDs where result: fail AND mandatory: false
                   (empty list [] when no non-mandatory items failed)
  signed_by:       agent_id — must match evaluated_by
  signed_at:       ISO 8601 datetime

## ADVANCEMENT_RULE

Archival is complete and the lifecycle terminates if and only if:
  attestation.verdict == pass

A fail verdict halts archival. The document remains in its current active
or superseded status until blocking items are remediated and a new DoD
evaluation is completed. Archival cannot be partially completed.

## VALIDATION_RULES

V01: dod_id matches DOD-archival-{doc_id}-{version}.
V02: stage value is exactly "archival".
V03: verdict is "pass" or "fail" only.
V04: When verdict is "fail", blocking_items is non-empty.
V05: When verdict is "pass", blocking_items is an empty list [].
V06: All 8 checklist items are recorded.
V07: archival_trigger is one of the five valid enum values.
V08: evaluated_by differs from the Archival Agent.
V09: When archival_trigger is "superseded", CI-ARCHIVAL-05 notes include
     the superseding doc_id.
