## SUMMARY
This template defines the structure of a Definition of Done completion record
for the Distribution stage gate. The Distribution Agent must produce a
completed record confirming that the document has been distributed to all
intended recipients in accordance with its context eligibility and
confidentiality classification. Failure to distribute to a defined recipient
or to respect access controls is a hard blocking item.

## TARGET_DOC_TYPE
dod-distribution-record

## PURPOSE
The Distribution DoD ensures that approved documents reach the agents and
systems that need them, and that access controls derived from the Agent
Context Boundary Policy (DLMS-2026-0016) and the context_eligible field
are correctly applied during distribution. Evidence of successful delivery
(the Distribution Log) must exist before this DoD can pass.

## RECORD_SCHEMA

### Header_Fields

FIELD_01:
  name:        dod_id
  type:        string
  required:    true
  nullable:    false
  format:      DOD-distribution-{doc_id}-{version}
  example:     DOD-distribution-DLMS-2026-0030-1.0.0
  description: Unique identifier for this DoD completion record. Immutable.

FIELD_02:
  name:        doc_id
  type:        string
  required:    true
  description: The DLMS doc_id of the document being distributed.

FIELD_03:
  name:        doc_version
  type:        string
  required:    true
  format:      MAJOR.MINOR.PATCH
  description: The approved version of the document being distributed.

FIELD_04:
  name:        stage
  type:        string
  required:    true
  value:       distribution
  description: Fixed value. Identifies this as a Distribution stage DoD record.

FIELD_05:
  name:        evaluated_by
  type:        string
  required:    true
  description: agent_id of the Distribution Verifier completing this record.
  constraints:
    - Must differ from the Distribution Agent that performed the distribution

FIELD_06:
  name:        evaluated_at
  type:        datetime
  required:    true
  format:      ISO 8601 with timezone
  description: Timestamp when the DoD evaluation was completed.

### Checklist_Items

Each item carries three sub-fields:
  result:    pass | fail
  mandatory: true | false   (fail on a mandatory item = hard block)
  notes:     string | null  (required when result is fail)

ITEM_01:
  id:          CI-DISTRIBUTION-01
  label:       Distribution plan exists for this document version
  check:       A Distribution Plan artefact exists identifying all intended
               recipients for this doc_id and doc_version.
  mandatory:   true
  governed_by: DLMS-2026-0016

ITEM_02:
  id:          CI-DISTRIBUTION-02
  label:       All recipients in the plan have a Distribution Log entry
  check:       For every recipient declared in the Distribution Plan, a
               Distribution Log entry exists confirming delivery or
               documenting a delivery failure with reason.
  mandatory:   true
  governed_by: DLMS-2026-0016

ITEM_03:
  id:          CI-DISTRIBUTION-03
  label:       context_eligible checked and applied
  check:       The document's context_eligible field has been evaluated.
               If context_eligible is false, the document has not been
               distributed to any agent context package.
  mandatory:   true
  governed_by: DLMS-2026-0016, DLMS-2026-0004

ITEM_04:
  id:          CI-DISTRIBUTION-04
  label:       Confidentiality classification respected
  check:       Any confidentiality restrictions on this document have been
               applied to limit distribution to authorised recipients only.
               No distribution to unauthorised agents or systems has occurred.
  mandatory:   true
  governed_by: DLMS-2026-0016

ITEM_05:
  id:          CI-DISTRIBUTION-05
  label:       Notifications issued to all recipients
  check:       A notification has been sent to all recipients in the
               Distribution Plan confirming availability of the document.
  mandatory:   false
  governed_by: DLMS-2026-0016

ITEM_06:
  id:          CI-DISTRIBUTION-06
  label:       Distribution audit event queued
  check:       A document-distributed audit event has been prepared for the
               Audit Trail Agent and will be submitted on DoD passage.
  mandatory:   true
  governed_by: DLMS-2026-0015

### Attestation_Block

attestation:
  dod_id:          {value from Header FIELD_01}
  verdict:         pass | fail
  blocking_items:  list of ITEM IDs where result: fail AND mandatory: true
                   (empty list [] when verdict is pass)
  observations:    list of ITEM IDs where result: fail AND mandatory: false
                   (empty list [] when no non-mandatory items failed)
  signed_by:       agent_id — must match evaluated_by
  signed_at:       ISO 8601 datetime

## ADVANCEMENT_RULE

The document lifecycle advances to the Indexing stage if and only if:
  attestation.verdict == pass

Distribution failures that cannot be remediated (e.g. a recipient system
is unavailable) must be escalated to the SysAdmin queue before this DoD
can be marked pass. Partial distribution is never a pass state.

## VALIDATION_RULES

V01: dod_id matches DOD-distribution-{doc_id}-{version}.
V02: stage value is exactly "distribution".
V03: verdict is "pass" or "fail" only.
V04: When verdict is "fail", blocking_items is non-empty.
V05: When verdict is "pass", blocking_items is an empty list [].
V06: All 6 checklist items are recorded.
V07: evaluated_by differs from the Distribution Agent.
