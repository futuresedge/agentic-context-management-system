## SUMMARY
This template defines the structure of a Definition of Done completion record
for the Review stage gate. The Review Synthesizer must produce a completed
record after all Perspective Reviewer verdicts are consolidated, before the
document may advance to the Approval gate. A single fail verdict from any
mandatory lens, or any unresolved conflict, blocks advancement.

## TARGET_DOC_TYPE
dod-review-record

## PURPOSE
The Review DoD confirms that multi-perspective review has been completed with
the required number of independent lenses, that the synthesis artefact exists
and is complete, and that no blocking verdicts remain unresolved. It
implements the structural gate requirements of the Multi-Perspective Review
Policy (DLMS-2026-0017) and the Verification Independence Policy
(DLMS-2026-0014).

## RECORD_SCHEMA

### Header_Fields

FIELD_01:
  name:        dod_id
  type:        string
  required:    true
  nullable:    false
  format:      DOD-review-{doc_id}-{version}
  example:     DOD-review-DLMS-2026-0030-0.1.0
  description: Unique identifier for this DoD completion record. Immutable.

FIELD_02:
  name:        doc_id
  type:        string
  required:    true
  description: The DLMS doc_id of the document being evaluated.

FIELD_03:
  name:        doc_version
  type:        string
  required:    true
  format:      MAJOR.MINOR.PATCH
  description: The version of the document being evaluated at gate time.

FIELD_04:
  name:        stage
  type:        string
  required:    true
  value:       review
  description: Fixed value. Identifies this as a Review stage DoD record.

FIELD_05:
  name:        evaluated_by
  type:        string
  required:    true
  description: agent_id of the Review Synthesizer completing this record.
  constraints:
    - Must differ from created_by and all Perspective Reviewer agent_ids
      (DLMS-2026-0014 R04)

FIELD_06:
  name:        evaluated_at
  type:        datetime
  required:    true
  format:      ISO 8601 with timezone
  description: Timestamp when the DoD evaluation was completed.

FIELD_07:
  name:        review_session_id
  type:        string
  required:    true
  description: Identifier of the review session this DoD closes.
               Links this record to the set of Perspective Reviewer outputs.

### Checklist_Items

Each item carries three sub-fields:
  result:    pass | fail
  mandatory: true | false   (fail on a mandatory item = hard block on advancement)
  notes:     string | null  (required when result is fail)

ITEM_01:
  id:          CI-REVIEW-01
  label:       Minimum perspective count met
  check:       The number of independent Perspective Reviewer verdicts in this
               review session meets or exceeds the minimum defined in
               DLMS-2026-0017 for the document's doc_type.
  mandatory:   true
  governed_by: DLMS-2026-0017 R01

ITEM_02:
  id:          CI-REVIEW-02
  label:       All mandatory lenses produced verdicts
  check:       Every mandatory lens defined for this doc_type has a recorded
               verdict from an independent Perspective Reviewer in this session.
  mandatory:   true
  governed_by: DLMS-2026-0017

ITEM_03:
  id:          CI-REVIEW-03
  label:       No unresolved fail verdicts from any reviewer
  check:       No Perspective Reviewer produced a verdict of fail that
               remains unaddressed. Each fail verdict must be either
               remediated (document returned to author) or resolved through
               the conflict resolution process.
  mandatory:   true
  governed_by: DLMS-2026-0017

ITEM_04:
  id:          CI-REVIEW-04
  label:       All inter-lens conflicts documented in synthesis
  check:       Every case where two or more Perspective Reviewers produced
               contradictory assessments is explicitly documented in the
               synthesis artefact, per DLMS-2026-0017 definitions.
  mandatory:   true
  governed_by: DLMS-2026-0017

ITEM_05:
  id:          CI-REVIEW-05
  label:       Synthesis artefact exists and is complete
  check:       The Review Synthesizer has produced a synthesis artefact for
               this review session. The artefact is not null, not empty, and
               addresses all lens verdicts.
  mandatory:   true
  governed_by: DLMS-2026-0017

ITEM_06:
  id:          CI-REVIEW-06
  label:       Synthesis artefact contains a final stage recommendation
  check:       The synthesis artefact includes an explicit final
               recommendation field with value: advance | return | escalate.
  mandatory:   true
  governed_by: DLMS-2026-0017

ITEM_07:
  id:          CI-REVIEW-07
  label:       All Perspective Reviewers independent from document author
  check:       No Perspective Reviewer agent_id matches the document's
               created_by field. Independence checked per DLMS-2026-0014 R01.
  mandatory:   true
  governed_by: DLMS-2026-0014 R01

ITEM_08:
  id:          CI-REVIEW-08
  label:       All pass-with-observations findings individually addressable
  check:       Every observation recorded against a pass-with-observations
               verdict is a discrete, actionable finding — not a vague
               general comment.
  mandatory:   false
  governed_by: DLMS-2026-0017

### Attestation_Block

attestation:
  dod_id:          {value from Header FIELD_01}
  verdict:         pass | fail
  blocking_items:  list of ITEM IDs where result: fail AND mandatory: true
                   (empty list [] when verdict is pass)
  observations:    list of ITEM IDs where result: fail AND mandatory: false
                   (empty list [] when no non-mandatory items failed)
  signed_by:       agent_id — must match evaluated_by
  signed_at:       ISO 8601 datetime

## ADVANCEMENT_RULE

A document may advance from Review to Approval stage if and only if:
  attestation.verdict == pass
  AND synthesis artefact recommendation == advance

A document with verdict: fail, or with recommendation: return, is sent back
to the Author Agent. A recommendation: escalate routes to the SysAdmin queue.
Each re-evaluation produces a new DoD record; prior records are retained.

## VALIDATION_RULES

V01: dod_id matches DOD-review-{doc_id}-{version}.
V02: stage value is exactly "review".
V03: verdict is "pass" or "fail" only.
V04: When verdict is "fail", blocking_items is non-empty.
V05: When verdict is "pass", blocking_items is an empty list [].
V06: All 8 checklist items are recorded (no items may be skipped).
V07: evaluated_by differs from created_by and all reviewer agent_ids in
     the review session.
V08: review_session_id is non-null.
