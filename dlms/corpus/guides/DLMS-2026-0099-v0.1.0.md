## SUMMARY

This procedure governs the Distribution stage of the DLMS document lifecycle:
from Storage stage handoff through context curation, DoD establishment,
distribution planning (with mandatory impact assessment evaluation per
DLMS-2026-0077), delivery to authorised recipients, change notification
broadcast, independent verification, and terminal stage completion. The
Distribution Planner evaluates impact assessment status before delivery
proceeds; if active dependencies require an impact assessment, the pipeline
halts until the assessment is cleared. Change notifications are broadcast
only after confirmed delivery. The primary outputs are distribution-log.md,
change-notification artefacts per recipient, distribution-verification.md
(stage gate artefact), and distribution-metrics.md.

## SCOPE

Agents active in this stage:

| Pipeline Position | Agent | Output Artefact |
|---|---|---|
| P01 | Distribution Orchestrator | (coordination only) |
| P02 | Context Curator (Distribution) | distribution-context.md |
| P03 | DoD Agent (Distribution) | distribution-dod.md |
| P04 | Distribution Planner | distribution-plan.md |
| P05 | Distribution Agent | distribution-log.md |
| P06 | Change Notification Agent | change-notification.[recipient].md (per recipient) |
| P07 | Distribution Verifier | distribution-verification.md; distribution-learnings.md |
| P08 | Distribution Metrics Agent | distribution-metrics.md |

Excludes:
- Storage, Indexing, Approval Gate, Review, and Creation stage agents
- Archival stage agents
- Tier 13 CI agents that consume distribution-metrics.md (governed by
  DLMS-2026-0076)

Executed by:
- agent:distribution-orchestrator: pipeline coordination, impact assessment
  gate, CI dispatch, and terminal completion (S01, S09, S10)
- Stage agents: own designated pipeline steps (S02–S08)
- sysadmin:dlm-sysadmin: escalation recipient for E02, E03, E05; impact
  assessment resolution authority for D01

## PREREQUISITES

P01: All Distribution stage agents are onboarded per DLMS-2026-0088
     (Distribution Stage Agent Onboarding Procedure). If any agent instance
     is not onboarded, defer pipeline activation. Failure → E02.

P02: DLMS-2026-0014 (Verification Independence Policy),
     DLMS-2026-0015 (Audit Trail Policy), DLMS-2026-0016 (Agent Context
     Boundary Policy), DLMS-2026-0041 (Definition of Done Policy),
     DLMS-2026-0043 (Quality Threshold Policy),
     DLMS-2026-0060 (Distribution Stage SLA), and
     DLMS-2026-0077 (Impact Assessment Policy) are in effect.
     Verified by: agent:distribution-orchestrator. Failure → E02.

P03: Distribution DoD template (DLMS-2026-0028 — TMPL-dod-distribution-001)
     is loaded and accessible for DoD Agent (Distribution). Failure → E01.

P04: Audit Trail Agent is reachable and accepting log entries. Failure → E03.

P05: Storage stage verification record is present: storage-verification.md
     with outcome = pass, doc-[id]-v[n]-agent.md, and access-manifest.md.
     If any artefact is absent or storage-verification.md outcome ≠ pass,
     reject intake and halt. Failure → E05.

## STEPS

S01: Receive handoff from Storage stage and validate prerequisites.
  action: Distribution Orchestrator receives the Distribution intake
          artefacts (storage-verification.md + doc-[id]-v[n]-agent.md +
          access-manifest.md). Confirm P05: storage-verification.md
          outcome = pass. Log receipt to Audit Trail Agent.
  actor:  agent:distribution-orchestrator
  reads:  storage-verification.md; doc-[id]-v[n]-agent.md;
          access-manifest.md
  writes: audit log entry
  on_failure: → E05

S02: Context Curator (Distribution) produces distribution context package.
  action: Context Curator (Distribution) reads designated context sources
          and produces distribution-context.md. READS limited to designated
          context sources per DLMS-2026-0016. Context scope includes
          doc_id, version, doc_type, confidentiality class, and recipient
          list from access-manifest.md.
  actor:  agent:context-curator-distribution
  reads:  designated context sources (doc_id, version, confidentiality
          class, access-manifest.md summary — scoped per DLMS-2026-0016)
  writes: distribution-context.md
  on_failure: → E02

S03: DoD Agent (Distribution) produces distribution-dod.md.
  action: DoD Agent (Distribution) loads DLMS-2026-0028 (TMPL-dod-
          distribution-001) and records the Definition of Done checklist
          for this distribution instance. Establishes criteria the
          Distribution Verifier will evaluate independently. DoD Agent
          MUST NOT pre-evaluate distribution outputs (DLMS-2026-0014 R01).
  actor:  agent:dod-distribution
  reads:  DLMS-2026-0028; distribution-context.md
  writes: distribution-dod.md
  on_failure: → E02

S04: Distribution Planner produces distribution plan.
  action: Distribution Planner reads access-manifest.md and evaluates
          DLMS-2026-0077 (Impact Assessment Policy). Determines whether
          any active dependencies of this document require a prior impact
          assessment before distribution proceeds. Produces
          distribution-plan.md per DLMS-2026-0053
          (TMPL-distribution-plan-001). The plan must include:
          recipient_list (from access-manifest.md), delivery_method per
          recipient, and impact_assessment_status field (required | cleared
          | not-applicable).
  actor:  agent:distribution-planner
  reads:  access-manifest.md; distribution-context.md; DLMS-2026-0077;
          dependency-graph entry for this doc_id
  writes: distribution-plan.md
  on_failure: → E02
  [D01] distribution-plan.md impact_assessment_status = required → halt
        pipeline. Log to Audit Trail Agent. Escalate to
        sysadmin:dlm-sysadmin. Pipeline resumes at S05 only when
        impact_assessment_status changes to: cleared.

S05: Distribution Agent delivers document to authorised recipients.
  action: Distribution Agent reads distribution-plan.md and executes
          delivery to each recipient listed in access-manifest.md using
          the method specified in distribution-plan.md. Delivery is per
          recipient; each delivery event is logged individually. Produces
          distribution-log.md per DLMS-2026-0054
          (TMPL-distribution-log-001) recording delivery status per
          recipient.
  actor:  agent:distribution-agent
  reads:  distribution-plan.md; doc-[id]-v[n]-agent.md; access-manifest.md
  writes: distribution-log.md
  on_failure: → E02

S06: Change Notification Agent broadcasts notifications.
  action: Change Notification Agent reads distribution-log.md (confirmed
          delivery) and distribution-plan.md. Broadcasts a change
          notification to each confirmed recipient. Produces one
          change-notification.[recipient].md per recipient. Change
          notifications are dispatched ONLY after delivery confirmation
          in distribution-log.md; no notification precedes delivery.
  actor:  agent:change-notification
  reads:  distribution-log.md; distribution-plan.md; distribution-context.md
  writes: change-notification.[recipient].md per recipient
  on_failure: → E02

S07: Distribution Verifier evaluates against DoD.
  action: Distribution Verifier independently evaluates whether S05–S06
          outputs satisfy all acceptance criteria in distribution-dod.md.
          Reads distribution-log.md, change-notification artefacts, and
          distribution-dod.md. Produces distribution-verification.md
          (outcome: pass | fail) per DLMS-2026-0030 (TMPL-verification-001)
          and distribution-learnings.md per DLMS-2026-0034
          (TMPL-learnings-001). Distribution Verifier MUST NOT be DoD Agent
          (Distribution) or Distribution Planner (DLMS-2026-0014 R01).
  actor:  agent:distribution-verifier
  reads:  distribution-log.md; change-notification.[recipient].md artefacts;
          distribution-dod.md
  writes: distribution-verification.md; distribution-learnings.md
  on_failure: → E02
  [D02] distribution-verification outcome = fail → E01.

S08: Distribution Metrics Agent records stage performance.
  action: Distribution Metrics Agent reads distribution-verification.md,
          distribution-log.md, and audit trail logs for this pipeline run.
          Records: elapsed stage time, delivery success rate per recipient,
          impact assessment delay duration (if D01 was triggered), DoD
          pass/fail outcome, and SLA variance against DLMS-2026-0060.
          Produces distribution-metrics.md.
  actor:  agent:distribution-metrics
  reads:  distribution-verification.md; distribution-log.md; audit trail
          log entries for this pipeline run
  writes: distribution-metrics.md
  on_failure: → E02

S09: CI dispatch.
  action: Dispatch distribution-metrics.md and distribution-learnings.md
          to the CI quality monitor queue. Dispatch distribution-
          verification.md to CI monitor scope. CI feedback consumed by
          Tier 13 per DLMS-2026-0076 (CI Cycle Policy).
  actor:  agent:distribution-orchestrator
  reads:  distribution-metrics.md; distribution-learnings.md;
          distribution-verification.md
  writes: CI queue entries (external to this stage's write scope)
  on_failure: log warning and continue (non-blocking)

S10: Terminal stage completion.
  action: Log pipeline completion to Audit Trail Agent. Document is now
          live and in circulation. Set document status to active per
          DLMS-2026-0037 (Document Status Transition Policy). Notify
          agent:archival-orchestrator that this document_id is now eligible
          for the Archival evaluation cycle (per retention schedule in
          DLMS-2026-0022). No further forward stage transition is triggered
          — Archival Stage SOP (DLMS-2026-0100) is triggered independently
          by retention schedule evaluation.
  actor:  agent:distribution-orchestrator
  reads:  distribution-verification.md (confirm outcome = pass)
  writes: status update (active); audit log entry; Archival eligibility
          notification
  on_failure: → E02

## DECISION_POINTS

D01: Impact assessment required (at S04).
  condition: distribution-plan.md impact_assessment_status = required.
  action:    Halt pipeline at S04. Log to Audit Trail Agent with the
             dependency identifiers that triggered the assessment
             requirement. Escalate to sysadmin:dlm-sysadmin per
             DLMS-2026-0077. Pipeline resumes at S05 only when
             impact_assessment_status is updated to: cleared.

D02: Distribution Verifier returns fail (at S07).
  condition: distribution-verification.md outcome = fail.
  action:    → E01. Do not advance to S08 or S09. Halt pipeline.

## OUTPUTS

| Artefact | Produced by | Purpose |
|---|---|---|
| distribution-context.md | Context Curator (Distribution) | Scoped context for this distribution run |
| distribution-dod.md | DoD Agent (Distribution) | Acceptance criteria for this distribution instance |
| distribution-plan.md | Distribution Planner | Delivery plan; recipient list; impact assessment status |
| distribution-log.md | Distribution Agent | Per-recipient delivery confirmation log |
| change-notification.[recipient].md | Change Notification Agent | Broadcast notification per recipient |
| distribution-verification.md | Distribution Verifier | Independent DoD evaluation (stage gate artefact) |
| distribution-learnings.md | Distribution Verifier | Lessons and observations for CI feedback |
| distribution-metrics.md | Distribution Metrics Agent | Stage performance record |

## ERROR_CONDITIONS

E01: DoD failure.
  condition: Distribution Verifier returns outcome = fail (D02).
  action:    Halt pipeline. Log to Audit Trail Agent with failure reasons
             from distribution-verification.md. Escalate to
             sysadmin:dlm-sysadmin. Determine whether partial delivery
             occurred and whether a retraction notification is required.

E02: Agent unavailable or pipeline step failure.
  condition: Any stage agent fails to produce its designated output.
  action:    Halt pipeline at failure point. Log to Audit Trail Agent
             including step identifier and agent ID.
             agent:distribution-orchestrator escalates to
             sysadmin:dlm-sysadmin.

E03: Audit Trail Agent unreachable.
  condition: Audit Trail Agent does not respond at S01 or any subsequent
             audit log step.
  action:    Halt pipeline immediately (DLMS-2026-0015 R01). Escalate to
             sysadmin:dlm-sysadmin.

E05: Missing Storage stage prerequisite.
  condition: storage-verification.md absent or outcome ≠ pass; or
             doc-[id]-v[n]-agent.md absent; or access-manifest.md absent.
  action:    Reject intake. Log to Audit Trail Agent identifying absent or
             non-compliant artefacts. Return signal to Storage stage. Do
             not begin Distribution stage processing under any
             circumstances.

## REVIEW_SCHEDULE

This procedure is reviewed whenever DLMS-2026-0077 (Impact Assessment
Policy) or DLMS-2026-0060 (Distribution Stage SLA) changes, and whenever
the recipient registration schema in DLMS-2026-0052 (Access Manifest
Template) is updated. Minimum annual review by agent:distribution-
orchestrator and sysadmin:dlm-sysadmin.
