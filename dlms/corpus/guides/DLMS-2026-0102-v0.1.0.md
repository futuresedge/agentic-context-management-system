## SUMMARY

This procedure governs the end-to-end CI (Continuous Improvement) cycle from
inter-cycle gate validation through parallel Phase 1 monitoring, escalation
propagation, sequential Phase 2 synthesis, and SBR- delivery to the SysAdmin
operations queue. It implements the 7-day cadence defined in DLMS-2026-0076
and ensures all escalation, verification independence, and audit trail
obligations are met. The primary outputs are six Phase 1 monitoring artefacts
(QR-, PR-, BNR-, ABR-, AR-, and learning-synthesis.md), three Phase 2
synthesis artefacts (CIS-, IMP-, ci-verification.md), and a sysadmin-
briefing.md (SBR-) delivered to sysadmin:dlm-sysadmin.

## SCOPE

Agents active in this procedure:

| Phase | Position | Agent | Output Artefact |
|---|---|---|---|
| — | P00 | CI Cycle Orchestrator | (coordination and gate management) |
| 1 (parallel) | P01 | Quality Monitor | QR-{YYYY}-{NNNN}.md |
| 1 (parallel) | P02 | Performance Monitor | PR-{YYYY}-{NNNN}.md |
| 1 (parallel) | P03 | Bottleneck Analyst | BNR-{YYYY}-{NNNN}.md |
| 1 (parallel) | P04 | Agent Behaviour Analyst | ABR-{YYYY}-{NNNN}.md |
| 1 (parallel) | P05 | Learning Synthesizer | learning-synthesis.md |
| 1 (soft-dep) | P06 | Anomaly Detector | AR-{YYYY}-{NNNN}.md |
| 2 (sequential) | P07 | CI Perspective Synthesizer | CIS-{YYYY}-{NNNN}.md |
| 2 (sequential) | P08 | Recommendation Generator | IMP-{YYYY}-{NNNN}.md |
| 2 (sequential) | P09 | CI Verifier | ci-verification.md |
| 2 (sequential) | P10 | SysAdmin Briefing Agent | sysadmin-briefing.md (SBR-) |

Excludes:
- All Tier 14 SysAdmin agents (governed by DLMS-2026-0101)
- All stage-pipeline agents (governed by DLMS-2026-0094 through 0100)
- Tier 2 Governance Layer agents (governed by DLMS-2026-0093)
- sysadmin:dlm-sysadmin (consumer of SBR-; not a participant in this
  procedure)

Executed by:
- agent:ci-cycle-orchestrator: gate management, cycle ID assignment, phase
  coordination, and SBR- delivery confirmation (S01, S02, S09, S13, S14)
- Phase 1 agents (P01–P06): monitoring and analysis within designated input
  scope (S03–S08)
- Phase 2 agents (P07–P10): synthesis chain (S10–S13)
- sysadmin:dlm-sysadmin: notification recipient for E02, E03

## PREREQUISITES

P01: All CI cycle agents (P00–P10) are onboarded per DLMS-2026-0092 (CI
     Cycle Agent Onboarding Procedure). If any agent instance is not
     onboarded, defer cycle activation. Failure → E01.

P02: DLMS-2026-0014 (Verification Independence Policy), DLMS-2026-0015
     (Audit Trail Policy), DLMS-2026-0016 (Agent Context Boundary Policy),
     DLMS-2026-0076 (CI Cycle Policy), DLMS-2026-0078 (SLA Breach Response
     Policy), and DLMS-2026-0080 (SysAdmin Escalation Policy) are in effect.
     Verified by: agent:ci-cycle-orchestrator. Failure → procedure deferred.

P03: CI Verifier (agent:ci-verifier) is confirmed as a distinct agent
     instance from all other Tier 13 agents (P01–P09) and from the Tier 12
     Knowledge Base Agent. Per DLMS-2026-0014 R01. Failure → E01.

P04: Audit Trail Agent is reachable and accepting log entries.
     Verified by: agent:ci-cycle-orchestrator. Failure → E04.

P05: Cycle template artefacts are accessible: TMPL-0066 through TMPL-0073
     and TMPL-0075 (DLMS-2026-0066–0073, 0075).
     Verified by: agent:ci-cycle-orchestrator. Failure → E01.

## STEPS

S01: Inter-cycle gate — confirm prior CD- is present.
  action: CI Cycle Orchestrator checks the CI cycle queue for the prior
          cycle's change directive (CD-). If CD- is absent, the current cycle
          cannot begin. Log gate check to Audit Trail Agent.
  actor:  agent:ci-cycle-orchestrator
  reads:  CI cycle queue (change directive artefact reference)
  writes: audit log entry (gate check result, timestamp)
  on_failure: → E03

  [D01] Prior CD- present in queue:
    - yes → S02
    - no → E03 (cycle breach event logged; sysadmin:dlm-sysadmin notified;
      HALT until CD- is received)

S02: Assign cycle ID and log cycle start.
  action: CI Cycle Orchestrator assigns a cycle_id in the format
          CYCLE-{YYYY}-{NNNN} (zero-padded sequential within year). Logs
          cycle start event to Audit Trail Agent with cycle_id, start
          timestamp, and trigger confirmation.
  actor:  agent:ci-cycle-orchestrator
  reads:  cycle counter register; prior CD- artefact reference
  writes: audit log entry (cycle start, cycle_id, timestamp)
  on_failure: → E04

S03: Quality Monitor produces quality report.
  action: Quality Monitor activates and reads its designated input scope per
          DLMS-2026-0016. Produces QR-{YYYY}-{NNNN}.md per TMPL-0066
          (DLMS-2026-0066), covering document quality metrics for the cycle
          period. Must not read Performance Monitor, Bottleneck Analyst,
          Agent Behaviour Analyst, or Learning Synthesizer outputs — these
          are produced in parallel.
  actor:  agent:quality-monitor
  reads:  designated quality input scope (per DLMS-2026-0016); TMPL-0066
  writes: QR-{YYYY}-{NNNN}.md
  on_failure: → E01

S04: Performance Monitor produces performance report.
  action: Performance Monitor activates concurrently with S03, S05, S06,
          S07. Reads its designated input scope per DLMS-2026-0016. Produces
          PR-{YYYY}-{NNNN}.md per TMPL-0067 (DLMS-2026-0067), covering
          pipeline performance metrics for the cycle period.
  actor:  agent:performance-monitor
  reads:  designated performance input scope (per DLMS-2026-0016); TMPL-0067
  writes: PR-{YYYY}-{NNNN}.md
  on_failure: → E01

S05: Bottleneck Analyst produces bottleneck report.
  action: Bottleneck Analyst activates concurrently with S03, S04, S06, S07.
          Reads its designated input scope per DLMS-2026-0016. Produces
          BNR-{YYYY}-{NNNN}.md per TMPL-0069 (DLMS-2026-0069), identifying
          throughput constraints and bottleneck events for the cycle period.
  actor:  agent:bottleneck-analyst
  reads:  designated bottleneck input scope (per DLMS-2026-0016); TMPL-0069
  writes: BNR-{YYYY}-{NNNN}.md
  on_failure: → E01

S06: Agent Behaviour Analyst produces behaviour report.
  action: Agent Behaviour Analyst activates concurrently with S03, S04, S05,
          S07. Reads its designated input scope per DLMS-2026-0016. Produces
          ABR-{YYYY}-{NNNN}.md per TMPL-0070 (DLMS-2026-0070), summarising
          agent compliance, deviation events, and behaviour patterns.
  actor:  agent:agent-behaviour-analyst
  reads:  designated behaviour input scope (per DLMS-2026-0016); TMPL-0070
  writes: ABR-{YYYY}-{NNNN}.md
  on_failure: → E01

S07: Learning Synthesizer produces learning synthesis.
  action: Learning Synthesizer activates concurrently with S03, S04, S05,
          S06. Reads its designated input scope per DLMS-2026-0016. Produces
          learning-synthesis.md per TMPL-0075 (DLMS-2026-0075), capturing
          cross-cycle learning signals and improvement candidates.
  actor:  agent:learning-synthesizer
  reads:  designated learning input scope (per DLMS-2026-0016); TMPL-0075
  writes: learning-synthesis.md
  on_failure: → E01

S08: Anomaly Detector produces anomaly report.
  action: Anomaly Detector waits for QR-{YYYY}-{NNNN}.md AND
          PR-{YYYY}-{NNNN}.md to be available (soft dependency on S03 and
          S04). Reads only QR- and PR- as its designated input scope
          (DLMS-2026-0016). MUST NOT read ABR-{YYYY}-{NNNN}.md or
          BNR-{YYYY}-{NNNN}.md — this constraint is hard (per DLMS-2026-0076
          anomaly detection independence rules). Produces AR-{YYYY}-{NNNN}.md
          per TMPL-0068 (DLMS-2026-0068).
  actor:  agent:anomaly-detector
  reads:  QR-{YYYY}-{NNNN}.md; PR-{YYYY}-{NNNN}.md; TMPL-0068
          NEVER: ABR-{YYYY}-{NNNN}.md; BNR-{YYYY}-{NNNN}.md
  writes: AR-{YYYY}-{NNNN}.md
  on_failure: → E01

S09: Phase 1 gate — confirm all Phase 1 artefacts complete.
  action: CI Cycle Orchestrator confirms that all six Phase 1 artefacts are
          present and complete: QR-, PR-, BNR-, ABR-, AR-, and
          learning-synthesis.md. If all are present, proceed to escalation
          propagation check (inline before S10). Maximum wait: 48 hours from
          S02 cycle start.
  actor:  agent:ci-cycle-orchestrator
  reads:  QR-, PR-, BNR-, ABR-, AR-, learning-synthesis.md (presence check)
  writes: audit log entry (Phase 1 gate pass, timestamp)
  on_failure: → E04

  [D02] Phase 1 gate within 48-hour window:
    - all 6 artefacts present within 48h → escalation propagation check,
      then S10
    - any artefact missing after 48h → E02 (blocked phase event; sysadmin
      notified; Phase 2 does not begin)

  ESCALATION PROPAGATION (inline check before S10):
    If any Phase 1 artefact (QR-, PR-, BNR-, ABR-, AR-, or
    learning-synthesis.md) carries escalation_required=true: EVERY Phase 2
    artefact (CIS-, IMP-, ci-verification.md, SBR-) MUST carry
    escalation_carried_forward=true. This propagation is non-excusable
    (DLMS-2026-0076 R06). No Phase 2 synthesis agent may suppress,
    override, or omit the escalation_carried_forward flag.

S10: CI Perspective Synthesizer produces synthesis report.
  action: CI Perspective Synthesizer reads all five monitor reports
          (QR-, PR-, BNR-, ABR-, AR-) and learning-synthesis.md. Produces
          CIS-{YYYY}-{NNNN}.md per TMPL-0071 (DLMS-2026-0071), integrating
          cross-domain findings into a unified CI perspective. Each
          Phase 2 artefact generated_at timestamp must be strictly after
          the previous Phase 2 artefact (sequential ordering enforced).
  actor:  agent:ci-perspective-synthesizer
  reads:  QR-, PR-, BNR-, ABR-, AR-, learning-synthesis.md; TMPL-0071
  writes: CIS-{YYYY}-{NNNN}.md
  on_failure: → E01

S11: Recommendation Generator produces improvement recommendations.
  action: Recommendation Generator reads CIS-{YYYY}-{NNNN}.md and
          learning-synthesis.md ONLY (DLMS-2026-0016). Produces
          IMP-{YYYY}-{NNNN}.md per TMPL-0072 (DLMS-2026-0072), with
          prioritised recommendations for SysAdmin consideration. Must not
          read raw Phase 1 monitor reports directly.
  actor:  agent:recommendation-generator
  reads:  CIS-{YYYY}-{NNNN}.md; learning-synthesis.md; TMPL-0072
          NEVER: QR-, PR-, BNR-, ABR-, AR- directly
  writes: IMP-{YYYY}-{NNNN}.md
  on_failure: → E01

S12: CI Verifier performs independent verification.
  action: CI Verifier reads all Tier 13 output artefacts (QR-, PR-, BNR-,
          ABR-, AR-, learning-synthesis.md, CIS-, IMP-) and assesses the
          coherence and completeness of the full CI cycle output. Produces
          ci-verification.md with outcome: pass or fail. CI Verifier must be
          a distinct agent instance from all 9 other Tier 13 agents AND from
          the Tier 12 Knowledge Base Agent (DLMS-2026-0014 R01).
  actor:  agent:ci-verifier
  reads:  QR-, PR-, BNR-, ABR-, AR-, learning-synthesis.md, CIS-, IMP-
  writes: ci-verification.md
  on_failure: → E01

S13: SysAdmin Briefing Agent produces sysadmin briefing.
  action: SysAdmin Briefing Agent reads ci-verification.md and
          IMP-{YYYY}-{NNNN}.md ONLY. Produces sysadmin-briefing.md (SBR-)
          per TMPL-sysadmin-briefing-001 (DLMS-2026-0073), summarising all
          recommendations and escalation flags for sysadmin:dlm-sysadmin.
          Must not read raw Phase 1 or Phase 2 synthesis artefacts beyond
          ci-verification.md and IMP-.
  actor:  agent:sysadmin-briefing
  reads:  ci-verification.md; IMP-{YYYY}-{NNNN}.md; TMPL-0073
          NEVER: QR-, PR-, BNR-, ABR-, AR-, CIS- directly
  writes: sysadmin-briefing.md (SBR-)
  on_failure: → E01

S14: Deliver SBR- and begin 2-day review window.
  action: CI Cycle Orchestrator confirms SBR- is complete and dispatches it
          to the sysadmin operations queue. Logs SBR- delivery to Audit Trail
          Agent with delivery timestamp. Begins monitoring the 2-day review
          window per DLMS-2026-0076 R07. If no CD- is received within
          2 days, trigger E03.
  actor:  agent:ci-cycle-orchestrator
  reads:  sysadmin-briefing.md (SBR- — completion check)
  writes: audit log entry (SBR- delivery, timestamp); CI queue dispatch entry
  on_failure: → E04

  [D03] CD- received within 2-day review window:
    - yes → log cycle completion to Audit Trail Agent; close cycle_id; end
    - no (2 days elapsed, no CD-) → E03 (cycle breach event; sysadmin
      notified)

## DECISION_POINTS

D01: Inter-cycle gate.
  condition: Is the prior cycle's CD- present in the CI cycle queue?
  if_true:   S02 — assign cycle ID and proceed.
  if_false:  E03 — log cycle breach event; notify sysadmin:dlm-sysadmin;
             HALT until CD- is received.

D02: Phase 1 gate (48-hour window).
  condition: Are all 6 Phase 1 artefacts (QR-, PR-, BNR-, ABR-, AR-,
             learning-synthesis.md) present within 48 hours of cycle start?
  if_true:   Perform escalation propagation check; proceed to S10.
  if_false:  E02 — blocked phase event; Phase 2 does not begin; sysadmin
             notified.

D03: Cycle completion gate (2-day CD- window).
  condition: Has a CD- been received from sysadmin:dlm-sysadmin within
             2 days of SBR- delivery?
  if_true:   Log cycle completion; close cycle_id.
  if_false:  E03 — cycle breach event; sysadmin notified.

## ERROR_CONDITIONS

E01: Agent unavailable or artefact production failure.
  condition: A Phase 1 or Phase 2 agent fails to produce its required output
             artefact within the cycle window.
  likely_cause: Agent runtime failure; input scope unavailable; onboarding
                not completed (P01 prerequisite gap).
  resolution: CI Cycle Orchestrator logs the failure to Audit Trail Agent.
              Notify sysadmin:dlm-sysadmin. If the failed agent is a Phase 1
              agent, the Phase 1 gate at S09 will not pass — E02 applies
              after 48 hours. If a Phase 2 agent fails, halt Phase 2 and
              notify sysadmin.

E02: Phase 1 gate timeout (48-hour deadline breached).
  condition: One or more Phase 1 artefacts are not complete within 48 hours
             of cycle start.
  likely_cause: Agent failure (→ E01); input data unavailable; resource
                constraint.
  resolution: Log a blocked phase event to Audit Trail Agent. Notify
              sysadmin:dlm-sysadmin with the identity of the missing
              artefact(s). Phase 2 does not begin until the Phase 1 gate
              passes. Notify DLMS-2026-0078 SLA Breach Response pathway if
              applicable.

E03: Cycle breach — CD- not received within required window.
  condition: (a) Prior cycle CD- is absent when the new cycle trigger fires
             (D01 fail); OR (b) no CD- is received from sysadmin:dlm-sysadmin
             within 2 days of SBR- delivery (D03 fail).
  likely_cause: SysAdmin operations cycle delayed; CD- issuance missed;
                escalation not acknowledged.
  resolution: Log a cycle breach event to Audit Trail Agent with cycle_id
              and timestamp. Notify sysadmin:dlm-sysadmin. For (a): HALT
              the new cycle until CD- is received. For (b): cycle_id remains
              open; escalation R01(f) is raised per DLMS-2026-0080.

E04: Audit Trail Agent unreachable.
  condition: Audit Trail Agent cannot accept log entries during any step.
  likely_cause: Audit Trail infrastructure failure.
  resolution: HALT immediately. Do not proceed with any cycle step. Notify
              sysadmin:dlm-sysadmin. Per DLMS-2026-0015: no procedure step
              executes without a reachable Audit Trail.

## REVIEW_SCHEDULE

  - Addition or removal of a Tier 13 CI monitoring or synthesis agent from
    the agent roster (DLMS-2026-0092).
  - A change to DLMS-2026-0014 (Verification Independence Policy) that alters
    CI Verifier independence constraints.
