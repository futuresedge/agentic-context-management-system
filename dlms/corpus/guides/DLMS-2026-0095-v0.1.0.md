## SUMMARY

This procedure governs the Review stage of the DLMS document lifecycle: from
under_review status receipt through context curation, DoD establishment,
parallel multi-perspective review, synthesis, optional revision, independent
verification, and metrics recording, to handoff to the Approval Gate with
review-verification.md as the gate artefact. Four Perspective Reviewers
activate concurrently and independently, each bounded to a single lens
dimension per DLMS-2026-0017 (Multi-Perspective Review Policy); no reviewer
may access another reviewer's output before synthesis. The primary outputs are
review-synthesis.md (consolidated review record), review-verification.md
(independent stage gate artefact), and review-metrics.md (stage performance
record).

## SCOPE

Agents active in this stage:

| Pipeline Position | Agent | Output Artefact |
|---|---|---|
| P01 | Review-Approval Orchestrator | (coordination only) |
| P02 | Context Curator (Review) | review-context.md |
| P03 | DoD Agent (Review) | review-dod.md |
| P04 | Reviewer A (Accuracy) | review-accuracy.md |
| P05 | Reviewer B (Completeness) | review-completeness.md |
| P06 | Reviewer C (Readability) | review-readability.md |
| P07 | Reviewer D (Structure) | review-structure.md |
| P08 | Review Synthesizer | review-synthesis.md |
| P09 | Revision Agent | draft-v0.2-agent.md (conditional) |
| P10 | Review Verifier | review-verification.md, review-learnings.md |
| P11 | Review Metrics Agent | review-metrics.md |

Note: P04–P07 (Perspective Reviewers) activate in PARALLEL. Sequential
activation violates lens independence under DLMS-2026-0017 R05.

Excludes:
- Creation stage agents (draft-v0.1-agent.md and creation-verification.md
  are received as inputs; no Creation stage agent re-activates in this
  stage)
- Approval Gate, Indexing, Storage, Distribution, or Archival stage agents

Executed by:
- agent:review-approval-orchestrator: pipeline coordination, parallel fan-out
  management (S04–S07), CI dispatch, and handoff (S01, S13)
- Stage agents: own designated pipeline steps (S02–S12)
- sysadmin:dlm-sysadmin: escalation recipient for E02, E03, E04, E05

## PREREQUISITES

P01: All Review stage agents are onboarded per DLMS-2026-0085 (Review and
     Approval Stage Agent Onboarding Procedure). If any agent instance is
     not onboarded, defer pipeline activation until onboarding is complete.
     Failure → E02.

P02: DLMS-2026-0014 (Verification Independence Policy),
     DLMS-2026-0015 (Audit Trail Policy), DLMS-2026-0016 (Agent Context
     Boundary Policy), DLMS-2026-0017 (Multi-Perspective Review Policy),
     DLMS-2026-0041 (Definition of Done Policy),
     DLMS-2026-0042 (Review Standards Policy),
     DLMS-2026-0043 (Quality Threshold Policy), and
     DLMS-2026-0058 (Review Stage SLA) are in effect.
     Verified by: agent:review-approval-orchestrator. Failure → E02.

P03: Review DoD template (DLMS-2026-0025 — TMPL-dod-review-001) is loaded
     and accessible for DoD Agent (Review). Failure → E01.

P04: Audit Trail Agent is reachable and accepting log entries. Failure → E03.

P05: Creation stage verification record is present. creation-verification.md
     with outcome = pass must be present; document status must be
     under_review. If either condition is absent, reject intake and halt.
     Failure → E05.

## STEPS

S01: Receive handoff from Creation stage and validate prerequisites.
  action: Review-Approval Orchestrator receives the Review intake artefacts
          (draft-v0.1-agent.md + creation-verification.md). Confirm P05:
          creation-verification.md outcome = pass; document status =
          under_review. Log receipt to Audit Trail Agent.
  actor:  agent:review-approval-orchestrator
  reads:  draft-v0.1-agent.md; creation-verification.md
  writes: audit log entry
  on_failure: → E05

S02: Context Curator (Review) produces review context package.
  action: Context Curator (Review) reads the designated context sources for
          this review run and produces review-context.md. READS is limited
          to designated context sources per DLMS-2026-0016. The document
          artefact (draft-v0.1-agent.md) is included in context scope but
          the Context Curator does not perform review itself.
  actor:  agent:context-curator-review
  reads:  designated context sources (doc_id, doc_type, status,
          creation-verification.md summary, governing policies list —
          scoped per DLMS-2026-0016)
  writes: review-context.md
  on_failure: → E02

S03: DoD Agent (Review) produces review-dod.md.
  action: DoD Agent (Review) loads DLMS-2026-0025 (TMPL-dod-review-001) and
          records the Definition of Done checklist for this review instance.
          Establishes acceptance criteria that the Review Verifier will
          evaluate independently. DoD Agent MUST NOT pre-evaluate the
          document content (DLMS-2026-0014 R01).
  actor:  agent:dod-review
  reads:  DLMS-2026-0025; review-context.md
  writes: review-dod.md
  on_failure: → E02

S04–S07: Perspective Reviewers activate in PARALLEL.
  action: Review-Approval Orchestrator initiates concurrent activation of
          all four Perspective Reviewers. Each reviewer reads ONLY its
          designated lens skill file and draft-v0.1-agent.md (or current
          revision). No reviewer accesses another reviewer's output
          artefact before synthesis (DLMS-2026-0017 R05 lens independence).
          Each reviewer uses DLMS-2026-0048 (TMPL-review-perspective-001)
          as output schema.

  S04 — Reviewer A (Accuracy lens):
    actor:  agent:reviewer-perspective-a
    reads:  draft-v0.1-agent.md; accuracy lens skill
    writes: review-accuracy.md

  S05 — Reviewer B (Completeness lens):
    actor:  agent:reviewer-perspective-b
    reads:  draft-v0.1-agent.md; completeness lens skill
    writes: review-completeness.md

  S06 — Reviewer C (Readability lens):
    actor:  agent:reviewer-perspective-c
    reads:  draft-v0.1-agent.md; readability lens skill
    writes: review-readability.md

  S07 — Reviewer D (Structure lens):
    actor:  agent:reviewer-perspective-d
    reads:  draft-v0.1-agent.md; structure lens skill
    writes: review-structure.md

  on_failure (any reviewer): → E02

S08: Review Synthesizer consolidates reviewer outputs.
  action: Review Synthesizer reads all four reviewer output artefacts and
          review-dod.md. Produces review-synthesis.md per DLMS-2026-0049
          (TMPL-review-synthesis-001). Synthesis must include: aggregate
          findings per lens, synthesis verdict (revision_required: true |
          false), and consolidated recommendation. Synthesizer MUST NOT
          re-perform individual lens review; scope is consolidation only.
  actor:  agent:review-synthesizer
  reads:  review-accuracy.md; review-completeness.md; review-readability.md;
          review-structure.md; review-dod.md
  writes: review-synthesis.md
  on_failure: → E02
  [D01] review-synthesis.md revision_required = true → S09 (Revision Agent).
        revision_required = false → S10 (Review Verifier).

S09: Revision Agent produces revised draft (conditional on D01).
  action: Revision Agent reads the current draft artefact and
          review-synthesis.md. Produces the next revision artefact
          (draft-v0.2-agent.md or subsequent) incorporating the synthesis
          recommendations. Revision counter incremented. If revision counter
          exceeds the maximum per DLMS-2026-0042 → E04. On completion,
          return to S04–S07 (Perspective Reviewers re-run on revised draft).
  actor:  agent:revision-agent
  reads:  current draft artefact (draft-v0.N-agent.md); review-synthesis.md
  writes: draft-v0.N+1-agent.md
  on_failure: → E02

S10: Review Verifier evaluates against DoD.
  action: Review Verifier independently evaluates whether the final draft
          artefact satisfies all acceptance criteria in review-dod.md.
          Reads the final draft artefact (draft-v0.1-agent.md or latest
          revision), review-dod.md, and review-synthesis.md. Produces
          review-verification.md (outcome: pass | fail) per DLMS-2026-0030
          (TMPL-verification-001) and review-learnings.md per DLMS-2026-0034
          (TMPL-learnings-001) for CI feedback. Review Verifier MUST NOT be
          DoD Agent (Review) or any Perspective Reviewer (DLMS-2026-0014 R01).
  actor:  agent:review-verifier
  reads:  final draft artefact; review-dod.md; review-synthesis.md
  writes: review-verification.md; review-learnings.md
  on_failure: → E02
  [D02] review-verification outcome = fail → E01.

S11: Review Metrics Agent records stage performance.
  action: Review Metrics Agent reads review-verification.md,
          review-synthesis.md, and audit trail logs for this pipeline run.
          Records: end-to-end stage elapsed time, review round count,
          reviewer findings summary per lens, synthesis verdict,
          DoD pass/fail outcome, and SLA variance against DLMS-2026-0058.
          Produces review-metrics.md.
  actor:  agent:review-metrics
  reads:  review-verification.md; review-synthesis.md; audit trail log
          entries for this pipeline run
  writes: review-metrics.md
  on_failure: → E02

S12: CI dispatch.
  action: Dispatch review-metrics.md and review-learnings.md to the CI
          quality monitor queue. Dispatch review-verification.md to CI
          monitor scope. CI feedback is consumed by Tier 13 (Quality
          Monitor, Performance Monitor, Anomaly Detector) per
          DLMS-2026-0076 (CI Cycle Policy).
  actor:  agent:review-approval-orchestrator
  reads:  review-metrics.md; review-learnings.md; review-verification.md
  writes: CI queue entries (external to this stage's write scope)
  on_failure: log warning and continue (non-blocking)

S13: Handoff to Approval Gate.
  action: Pass review-verification.md, review-synthesis.md, and the final
          draft artefact to the Approval Gate intake queue. Log handoff to
          Audit Trail Agent. Approval Gate SOP (DLMS-2026-0096) is
          triggered on receipt.
  actor:  agent:review-approval-orchestrator
  reads:  review-verification.md (confirm outcome = pass before handoff)
  writes: handoff artefact to Approval Gate queue; audit log entry
  on_failure: → E02

## DECISION_POINTS

D01: Review synthesis requires revision (at S08).
  condition: review-synthesis.md revision_required = true.
  action:    Activate S09 (Revision Agent). Increment revision counter.
             Return to S04–S07 for full re-review of revised draft.
             If revision counter exceeds maximum per DLMS-2026-0042 → E04.

D02: Review Verifier returns fail (at S10).
  condition: review-verification.md outcome = fail.
  action:    → E01. Do not advance to S11 or S12. Issue return signal to
             Review-Approval Orchestrator. Halt pipeline.

| review-context.md | Context Curator (Review) | Scoped context for this review run |
| review-dod.md | DoD Agent (Review) | Acceptance criteria for this review instance |
| review-accuracy.md | Reviewer A | Accuracy dimension findings |
| review-completeness.md | Reviewer B | Completeness dimension findings |
| review-readability.md | Reviewer C | Readability dimension findings |
| review-structure.md | Reviewer D | Structure dimension findings |
| review-synthesis.md | Review Synthesizer | Consolidated review record |

| review-learnings.md | Review Verifier | Lessons and observations for CI feedback |
| review-metrics.md | Review Metrics Agent | Stage performance record |

## ERROR_CONDITIONS

E01: DoD failure.
  condition: Review Verifier returns outcome = fail (D02).
  action:    Halt pipeline. Log to Audit Trail Agent with failure reasons
             from review-verification.md. Issue return-to-review directive.
             Author and Creation Orchestrator are notified.
             sysadmin:dlm-sysadmin is escalated for manual resolution.

E02: Agent unavailable or pipeline step failure.
  condition: Any stage agent fails to produce its designated output artefact.
  action:    Halt pipeline at failure point. Log to Audit Trail Agent
             including step identifier and agent ID.
             agent:review-approval-orchestrator escalates to
             sysadmin:dlm-sysadmin.

E03: Audit Trail Agent unreachable.
  condition: Audit Trail Agent does not respond at S01 or any subsequent
             audit log step.
  action:    Halt pipeline immediately. Do not proceed without audit
             capability (DLMS-2026-0015 R01). Escalate to
             sysadmin:dlm-sysadmin.

E04: Revision limit exceeded.
  condition: Review revision loop (D01 → S09 → S04–S08) exceeds the maximum
             revision count per DLMS-2026-0042.
  action:    Halt pipeline. Log to Audit Trail Agent with full revision
             history and synthesis recommendations at each cycle. Escalate
             to sysadmin:dlm-sysadmin for manual review resolution.

E05: Missing Creation stage prerequisite.
  condition: creation-verification.md absent or outcome ≠ pass; or document
             status ≠ under_review.
  action:    Reject intake. Log to Audit Trail Agent identifying the missing
             or non-compliant artefact. Return to Creation stage. Do not
             begin Review stage processing under any circumstances.

## REVIEW_SCHEDULE

This procedure is reviewed at each major SLA renegotiation cycle for
DLMS-2026-0058 and whenever the reviewer panel composition or lens skill set
changes. Minimum annual review conducted by agent:review-approval-orchestrator
and sysadmin:dlm-sysadmin. Any change to the parallel reviewer fan-out
structure requires a DLMS-2026-0017 compliance check before the procedure
is updated.
