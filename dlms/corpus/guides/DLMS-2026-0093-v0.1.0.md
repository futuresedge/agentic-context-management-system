## SUMMARY
This procedure governs the onboarding of any one of the eight DLM SysAdmin
and Governance (Tier 14) agents — the agents that collectively oversee
decision-making, verification, policy management, SLA management, rules and
patterns curation, guide curation, configuration control, DoD custody, and
system-wide activity monitoring. The SysAdmin Verifier must not be the same
instance as the DLM SysAdmin Agent whose decisions it verifies. The
SysAdmin Activity Monitor must be a distinct instance from every agent it
monitors; because it monitors the entire SysAdmin tier, no Tier 14 agent
may share an agent_id with the SysAdmin Activity Monitor.

## SCOPE

Applies to:
- All eight DLM SysAdmin and Governance (Tier 14) agents listed below
- sysadmin:dlm-sysadmin as procedure owner and separation verifier
- Audit Trail Agent as recipient of onboarding audit events

The eight DLM SysAdmin and Governance agents:

| Agent | Designated output | Separation constraint |
|---|---|---|
| DLM SysAdmin Agent | SysAdmin decisions and directives | Must not be same instance as SysAdmin Verifier |
| SysAdmin Verifier | sysadmin-verification.md | Must not be same instance as DLM SysAdmin Agent |
| Policy Manager | updated policy documents | Must not be same instance as SysAdmin Verifier |
| SLA Manager | updated SLA policy documents | Must not be same instance as SysAdmin Verifier |
| Rules and Patterns Agent | updated rules and pattern documents | None beyond universal |
| Guide Curator | updated guide documents | None beyond universal |
| Configuration Controller | system-configuration.md | None beyond universal; exclusive write to config |
| DoD Custodian | updated DoD templates | None beyond universal |
| SysAdmin Activity Monitor | sysadmin-activity-report.md | Must not be same instance as any other Tier 14 agent |

Note: The SysAdmin Activity Monitor must monitor all other Tier 14 agents
impartially; it therefore cannot share an agent_id with any of the eight
other agents listed above.

Excludes:
- Any agent outside Tier 14

Executed by:
- Onboarding agent (self-check): S02, S03, S04, S05, S06, S08, S09
- sysadmin:dlm-sysadmin: separation verification (S07), roster registration (S08)

## PREREQUISITES

P01: DLMS-2026-0014, DLMS-2026-0015, DLMS-2026-0016, DLMS-2026-0041,
     DLMS-2026-0065 (Template Governance Policy), DLMS-2026-0076 (CI Cycle
     Policy), DLMS-2026-0078 (SLA Breach Response Policy),
     DLMS-2026-0079 (Change Management Policy), and DLMS-2026-0080
     (SysAdmin Escalation Policy) are in effect.
     Verified by: sysadmin:dlm-sysadmin. Failure → D01.

P02: This agent's designated context package includes: (a) role identifier
     and designated output schema; (b) for Policy Manager: read access to
     all current policy document headers (not bodies) and DLMS-2026-0001;
     (c) for SLA Manager: read access to all SLA policy document headers
     and DLMS-2026-0062; (d) for Configuration Controller: read access to
     DLMS-2026-0079 and the current system-configuration.md; (e) for DoD
     Custodian: read access to DoD templates (DLMS-2026-0024 through
     DLMS-2026-0029); (f) for SysAdmin Verifier: read access to all
     SysAdmin decision artefacts and DLMS-2026-0080 (SysAdmin Escalation Policy); (g) for SysAdmin
     Activity Monitor: read access to Tier 14 agent_registry and
     activity event stream.
     Verified by: sysadmin:dlm-sysadmin. Failure → E01.

P03: Audit Trail Agent is reachable. Failure → E03.

## STEPS

S01: Retrieve context package.
  action: Retrieve this agent's context package and confirm it satisfies
          P02. Note role, designated output schema, and any policy read
          access references.
  actor:  sysadmin:dlm-sysadmin
  reads:  designated context package
  writes: (none — verification only)
  on_failure: → E01

S02: Validate context boundary.
  action: Confirm READS is correctly scoped for each role:
          - DLM SysAdmin Agent: READS = CI verification, recommendations,
            and briefing artefacts; active policy summaries; SLA status.
            NEVER = individual stage document content; detailed audit
            trail data beyond summary status.
          - SysAdmin Verifier: READS = SysAdmin decision artefacts and
            DLMS-2026-0080 only; NEVER = inbound briefing artefacts that
            preceded the decision (must assess the decision output, not
            re-read its inputs).
          - Policy Manager: READS = policy document headers + DLMS-2026-0001;
            WRITES = policy document updates; NEVER = stage artefacts.
          - SLA Manager: READS = SLA document headers + SLA metric data;
            WRITES = SLA document updates; NEVER = other policy bodies.
          - Configuration Controller: READS = system-configuration.md +
            DLMS-2026-0079; WRITES = system-configuration.md only; NEVER =
            individual stage or document artefacts.
          - DoD Custodian: READS = active DoD templates (0024-0029) +
            empirical stage performance data; WRITES = DoD template updates;
            NEVER = stage artefacts directly.
          - SysAdmin Activity Monitor: READS = Tier 14 activity event
            stream only; WRITES = sysadmin-activity-report.md; NEVER =
            document content or stage artefacts.
  actor:  Onboarding agent; verified by sysadmin:dlm-sysadmin
  reads:  context boundary specification
  writes: boundary validation result (internal)
  on_failure: → D02

S03: Load governing policies into context.
  action: Load: DLMS-2026-0014, DLMS-2026-0015, DLMS-2026-0016,
          DLMS-2026-0041, DLMS-2026-0065, DLMS-2026-0076, DLMS-2026-0078,
          DLMS-2026-0079, DLMS-2026-0080. Load designated output schema.
  actor:  Onboarding agent
  reads:  policy references from context package
  writes: active policy context (internal)
  on_failure: → E01

S04: Emit onboarding-start audit event.
  action: Write onboarding-start event per DLMS-2026-0015. Required fields:
          agent_id, role, tier = 14,
          onboarding_procedure_ref = "DLMS-2026-0093", timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-start event)
  on_failure: → E03

S05: Confirm artefact format.
  action: Generate a zero-content test artefact against designated output
          schema. For SysAdmin Verifier: test artefact must include
          decision_ref, verified_by, verification_outcome (approved |
          rejected | deferred), and DLMS-2026-0080 (SysAdmin Escalation
          Policy) rule citations. For
          Configuration Controller: test configuration record must include
          config_version and changed_by fields. For SysAdmin Activity
          Monitor: test report must include monitoring_period,
          agents_monitored (array of agent_ids), and anomalies_detected
          (integer or array).
  actor:  Onboarding agent
  reads:  designated output schema
  writes: test artefact (internal, discarded)
  on_failure: → E02

S06: Confirm SysAdmin policy binding.
  action: Confirm that DLMS-2026-0078 (SLA Breach Response Policy) and
          DLMS-2026-0080 (SysAdmin Escalation Policy) are loaded and that
          this agent's role is explicitly referenced in those policies.
          Configuration Controller: additionally confirm DLMS-2026-0079
          (Change Management Policy) binding.
  actor:  Onboarding agent
  reads:  DLMS-2026-0078; DLMS-2026-0079; DLMS-2026-0080
  writes: policy binding confirmation (internal)
  on_failure: → E01

S07: Confirm separation criteria.
  action: Per the scope table constraints:
          - DLM SysAdmin Agent: confirm agent_id ≠ SysAdmin Verifier
          - SysAdmin Verifier: confirm agent_id ≠ DLM SysAdmin Agent;
            confirm agent_id ≠ Policy Manager and SLA Manager (SysAdmin
            Verifier must not also manage the documents it verifies)
          - SysAdmin Activity Monitor: confirm agent_id is distinct from
            every other Tier 14 agent_id (all eight other agents)
          Per DLMS-2026-0014 R01.
  actor:  sysadmin:dlm-sysadmin
  reads:  All Tier 14 agent_ids from sysadmin registry
  writes: separation confirmation note (internal)
  on_failure: → D03

S08: Register with DLM SysAdmin and Governance roster.
  action: Register agent_id and role in the DLM SysAdmin and Governance
          active roster maintained by sysadmin:dlm-sysadmin. No external
          orchestrator registration is required — Tier 14 agents operate
          on directives from sysadmin:dlm-sysadmin.
  actor:  sysadmin:dlm-sysadmin
  reads:  Tier 14 active roster
  writes: Registration entry
  on_failure: → E04

S09: Emit onboarding-complete audit event.
  action: Write onboarding-complete event per DLMS-2026-0015. Required
          fields: agent_id, role, tier = 14,
          onboarding_procedure_ref = "DLMS-2026-0093",
          outcome [success | failure], timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-complete event)
  on_failure: → E03

## DECISION_POINTS

D01: If P01 fails → halt. Notify sysadmin:dlm-sysadmin. No Tier 14 agent
     may operate until all Wave 13 SysAdmin policies (DLMS-2026-0078,
     0079, 0080) are in effect.

D02: If S02 fails → halt. Notify sysadmin:dlm-sysadmin for context package
     correction.

D03: If S07 fails:
     - DLM SysAdmin / SysAdmin Verifier conflict → halt. Resolve agent_id
       assignment before either agent proceeds.
     - SysAdmin Activity Monitor conflict with any Tier 14 agent → halt.
       SysAdmin Activity Monitor must have a unique agent_id across all of
       Tier 14 before it can be activated.

## OUTPUTS

| Artefact | Produced by step | Written to | Consumed by |
|---|---|---|---|
| Operational SysAdmin/Governance agent with validated context | S02–S06 | internal state | sysadmin:dlm-sysadmin |
| Registration entry | S08 | Tier 14 active roster | sysadmin:dlm-sysadmin |
| onboarding-start audit event | S04 | audit-trail.log | Audit Trail Agent |
| onboarding-complete audit event | S09 | audit-trail.log | Audit Trail Agent; sysadmin:dlm-sysadmin |

## ERROR_CONDITIONS

E01: Context package unavailable or Wave 13 SysAdmin policies not in effect.
  likely_cause: DLMS-2026-0078, 0079, or 0080 not yet authored or approved.
  resolution:   Defer; escalate to sysadmin:dlm-sysadmin.

E02: Artefact format validation fails.
  likely_cause: decision_ref or verification_outcome fields absent; anomaly
                tracking schema missing from Activity Monitor schema.
  resolution:   Halt. Log. Escalate to sysadmin:dlm-sysadmin.

E03: Audit trail unreachable.
  resolution:   Halt. Alert sysadmin:dlm-sysadmin. Retry after reachable.

E04: Roster registration fails.
  resolution:   Halt. Notify sysadmin:dlm-sysadmin.

## REVIEW_SCHEDULE

interval_max: 12 months (or whenever a Wave 13 SysAdmin policy is updated)
trigger_conditions:
  - Any Tier 14 agent is replaced or its role description changes
  - DLMS-2026-0078, DLMS-2026-0079, or DLMS-2026-0080 are revised
  - The SysAdmin Activity Monitor's monitoring scope changes to include
    additional tiers
review_owner:   sysadmin:dlm-sysadmin
review_process: Standard procedure review per DLMS-2026-0001
