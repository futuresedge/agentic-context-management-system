## SUMMARY

This procedure governs the Archival stage of the DLMS document lifecycle:
from a retention schedule signal or supersession event through context
curation, DoD establishment, lifecycle evaluation, impact assessment gate,
archival commitment, status transition to archived, independent verification,
and terminal stage completion. The Archival stage is a terminal state; once
a document's status is set to archived, no further forward stage transitions
occur within the DLMS lifecycle pipeline — the only subsequent action is
destruction per DLMS-2026-0040 (Document Archival Policy), which is governed
separately. The primary outputs are archival-log.md (archival commitment
record), archival-verification.md (stage gate artefact), and archival-
metrics.md (performance record).

## SCOPE

Agents active in this stage:

| Pipeline Position | Agent | Output Artefact |
|---|---|---|
| P01 | Archival Orchestrator | (coordination only) |
| P02 | Context Curator (Archival) | archival-context.md |
| P03 | DoD Agent (Archival) | archival-dod.md |
| P04 | Retention Evaluator | archival-recommendation.md |
| P05 | Archival Agent | archival-log.md |
| P06 | Status Transition Agent | status-transition-record.md |
| P07 | Archival Verifier | archival-verification.md; archival-learnings.md |
| P08 | Archival Metrics Agent | archival-metrics.md |

Excludes:
- Distribution, Storage, Indexing, Approval Gate, Review, and Creation
  stage agents
- Tier 13 CI agents and Tier 14 SysAdmin agents (governed by their own
  SOPs and operating procedures)

Executed by:
- agent:archival-orchestrator: pipeline coordination, impact assessment
  gate management, CI dispatch, and terminal state confirmation
  (S01, S09, S10)
- Stage agents: own designated pipeline steps (S02–S08)
- sysadmin:dlm-sysadmin: escalation recipient for E02, E03; impact
  assessment resolution authority for D02

## PREREQUISITES

P01: All Archival stage agents are onboarded per DLMS-2026-0089 (Archival
     Stage Agent Onboarding Procedure). If any agent instance is not
     onboarded, defer pipeline activation. Failure → E02.

P02: DLMS-2026-0014 (Verification Independence Policy),
     DLMS-2026-0015 (Audit Trail Policy), DLMS-2026-0016 (Agent Context
     Boundary Policy), DLMS-2026-0022 (Retention Schedule),
     DLMS-2026-0037 (Document Status Transition Policy),
     DLMS-2026-0039 (Document Retention Policy),
     DLMS-2026-0040 (Document Archival Policy),
     DLMS-2026-0041 (Definition of Done Policy),
     DLMS-2026-0043 (Quality Threshold Policy),
     DLMS-2026-0061 (Archival Stage SLA), and
     DLMS-2026-0077 (Impact Assessment Policy) are in effect.
     Verified by: agent:archival-orchestrator. Failure → E02.

P03: Archival DoD template (DLMS-2026-0029 — TMPL-dod-archival-001) is
     loaded and accessible for DoD Agent (Archival). Failure → E01.

P04: Audit Trail Agent is reachable and accepting log entries. Failure → E03.

P05: The archival trigger is valid. Either: (a) a retention schedule
     evaluation signal from DLMS-2026-0022 is present for this doc_id
     and the signal has not been resolved; or (b) the document status is
     superseded following a confirmed status transition. If neither
     condition is met, reject the trigger as invalid. Failure → E05.

## STEPS

S01: Receive archival trigger and validate prerequisites.
  action: Archival Orchestrator receives the archival trigger (retention
          signal or supersession event). Confirm P05: valid trigger present.
          Retrieve document lifecycle record for this doc_id (all prior
          stage verification artefacts and version records). Log receipt
          to Audit Trail Agent.
  actor:  agent:archival-orchestrator
  reads:  archival trigger; document lifecycle record (all verification
          artefacts and version history for this doc_id)
  writes: audit log entry
  on_failure: → E05

S02: Context Curator (Archival) produces archival context package.
  action: Context Curator (Archival) reads designated context sources and
          produces archival-context.md. READS limited to designated context
          sources per DLMS-2026-0016. Context scope includes doc_id,
          current status, retention class, trigger type, and governing
          policy references.
  actor:  agent:context-curator-archival
  reads:  designated context sources (doc_id, status, retention_class,
          trigger type, governing policies — scoped per DLMS-2026-0016)
  writes: archival-context.md
  on_failure: → E02

S03: DoD Agent (Archival) produces archival-dod.md.
  action: DoD Agent (Archival) loads DLMS-2026-0029 (TMPL-dod-archival-001)
          and records the Definition of Done checklist for this archival
          instance. Establishes acceptance criteria the Archival Verifier
          will evaluate independently. DoD Agent MUST NOT pre-evaluate
          archival outputs (DLMS-2026-0014 R01).
  actor:  agent:dod-archival
  reads:  DLMS-2026-0029; archival-context.md
  writes: archival-dod.md
  on_failure: → E02

S04: Retention Evaluator produces archival recommendation.
  action: Retention Evaluator reads the full document lifecycle history
          for this doc_id (all version records, verification artefacts,
          and the retention schedule entry from DLMS-2026-0022). Evaluates:
          (a) retention class eligibility for archival; (b) whether any
          active dependencies in the dependency graph require an impact
          assessment before archival proceeds per DLMS-2026-0077.
          Produces archival-recommendation.md per DLMS-2026-0055
          (TMPL-archival-recommendation-001), including:
          archival_eligible: true | false; impact_assessment_required:
          true | false; assessment_dependencies list.
  actor:  agent:retention-evaluator
  reads:  document lifecycle history (version records, all prior
          verification artefacts for this doc_id); DLMS-2026-0022;
          DLMS-2026-0039; DLMS-2026-0077; dependency-graph entry
  writes: archival-recommendation.md
  on_failure: → E02
  [D01] archival-recommendation.md archival_eligible = false → E04.
  [D01] impact_assessment_required = true → D02.
  [D01] archival_eligible = true AND impact_assessment_required = false
        → S05.

S05: Archival Agent commits document to archival storage.
  action: Archival Agent reads archival-recommendation.md (confirmed
          archival_eligible = true, impact_assessment_required = false or
          cleared) and executes archival storage commitment for
          doc-[id]-v[n]-agent.md. Produces archival-log.md per
          DLMS-2026-0056 (TMPL-archival-log-001) recording: doc_id, version
          archived, archival storage location, trigger type, and timestamp.
  actor:  agent:archival-agent
  reads:  archival-recommendation.md; doc-[id]-v[n]-agent.md;
          archival-context.md
  writes: archival-log.md
  on_failure: → E02

S06: Status Transition Agent sets status to archived.
  action: Status Transition Agent reads archival-log.md (confirming
          archival commit) and executes the status transition for this
          doc_id from current status (active or superseded) to archived,
          per DLMS-2026-0037 (Document Status Transition Policy). Produces
          status-transition-record.md recording: previous status, new
          status (archived), transition timestamp, and authorising artefact
          (archival-log.md reference).
  actor:  agent:status-transition
  reads:  archival-log.md; archival-context.md; DLMS-2026-0037
  writes: status-transition-record.md
  on_failure: → E02

S07: Archival Verifier evaluates against DoD.
  action: Archival Verifier independently evaluates whether S05–S06
          outputs satisfy all acceptance criteria in archival-dod.md.
          Reads archival-log.md, status-transition-record.md, archival-
          recommendation.md, and archival-dod.md. Produces archival-
          verification.md (outcome: pass | fail) per DLMS-2026-0030
          (TMPL-verification-001) and archival-learnings.md per
          DLMS-2026-0034 (TMPL-learnings-001). Archival Verifier MUST NOT
          be DoD Agent (Archival) or Retention Evaluator
          (DLMS-2026-0014 R01).
  actor:  agent:archival-verifier
  reads:  archival-log.md; status-transition-record.md;
          archival-recommendation.md; archival-dod.md
  writes: archival-verification.md; archival-learnings.md
  on_failure: → E02
  [D03] archival-verification outcome = fail → E01.

S08: Archival Metrics Agent records stage performance.
  action: Archival Metrics Agent reads archival-verification.md,
          archival-recommendation.md, and audit trail logs for this
          pipeline run. Records: elapsed stage time, trigger type,
          impact assessment delay duration (if D02 was triggered),
          DoD pass/fail outcome, and SLA variance against DLMS-2026-0061.
          Produces archival-metrics.md.
  actor:  agent:archival-metrics
  reads:  archival-verification.md; archival-recommendation.md; audit
          trail log entries for this pipeline run
  writes: archival-metrics.md
  on_failure: → E02

S09: CI dispatch.
  action: Dispatch archival-metrics.md and archival-learnings.md to the CI
          quality monitor queue. Dispatch archival-verification.md to CI
          monitor scope. CI feedback consumed by Tier 13 per
          DLMS-2026-0076 (CI Cycle Policy).
  actor:  agent:archival-orchestrator
  reads:  archival-metrics.md; archival-learnings.md;
          archival-verification.md
  writes: CI queue entries (external to this stage's write scope)
  on_failure: log warning and continue (non-blocking)

S10: Terminal state confirmation.
  action: Log pipeline completion to Audit Trail Agent. Document status is
          now archived (confirmed by status-transition-record.md). No
          further forward stage transitions occur in the DLMS document
          lifecycle pipeline for this doc_id. The only permissible
          subsequent action is document destruction, governed by
          DLMS-2026-0040 (Document Archival Policy) and triggered
          independently by a separate destruction evaluation signal.
          Notify agent:archival-orchestrator to close this pipeline
          instance.
  actor:  agent:archival-orchestrator
  reads:  archival-verification.md (confirm outcome = pass);
          status-transition-record.md (confirm status = archived)
  writes: audit log entry (terminal state confirmed)
  on_failure: → E02

## DECISION_POINTS

D01: Retention Evaluator returns assessment (at S04).
  condition: archival-recommendation.md evaluation results.
  action per outcome:
    archival_eligible = false:           → E04.
    impact_assessment_required = true:   → D02.
    archival_eligible = true AND
    impact_assessment_required = false:  → S05.

D02: Impact assessment required (at S04 via D01).
  condition: archival-recommendation.md impact_assessment_required = true.
  action:    Halt pipeline. Log to Audit Trail Agent with the dependency
             identifiers requiring assessment (from assessment_dependencies
             list). Escalate to sysadmin:dlm-sysadmin per DLMS-2026-0077.
             Pipeline resumes at S05 only when all dependencies in the
             assessment_dependencies list are resolved and
             impact_assessment_required is updated to: false.

D03: Archival Verifier returns fail (at S07).
  condition: archival-verification.md outcome = fail.
  action:    → E01. Do not advance to S08 or S09. Halt pipeline.

## OUTPUTS

| Artefact | Produced by | Purpose |
|---|---|---|
| archival-context.md | Context Curator (Archival) | Scoped context for this archival run |
| archival-dod.md | DoD Agent (Archival) | Acceptance criteria for this archival instance |
| archival-recommendation.md | Retention Evaluator | Lifecycle evaluation; archival eligibility; impact deps |
| archival-log.md | Archival Agent | Archival storage commitment record |
| status-transition-record.md | Status Transition Agent | Formal status change record (→ archived) |
| archival-verification.md | Archival Verifier | Independent DoD evaluation (stage gate artefact) |
| archival-learnings.md | Archival Verifier | Lessons and observations for CI feedback |
| archival-metrics.md | Archival Metrics Agent | Stage performance record |

## ERROR_CONDITIONS

E01: DoD failure.
  condition: Archival Verifier returns outcome = fail (D03).
  action:    Halt pipeline. Log to Audit Trail Agent with failure reasons
             from archival-verification.md. Escalate to
             sysadmin:dlm-sysadmin. Determine whether the archival
             commitment (S05) or the status transition (S06) succeeded
             and whether rollback is required.

E02: Agent unavailable or pipeline step failure.
  condition: Any stage agent fails to produce its designated output.
  action:    Halt pipeline at failure point. Log to Audit Trail Agent
             including step identifier and agent ID.
             agent:archival-orchestrator escalates to
             sysadmin:dlm-sysadmin.

E03: Audit Trail Agent unreachable.
  condition: Audit Trail Agent does not respond at S01 or any subsequent
             audit log step.
  action:    Halt pipeline immediately (DLMS-2026-0015 R01). Escalate to
             sysadmin:dlm-sysadmin.

E04: Document not eligible for archival.
  condition: archival-recommendation.md archival_eligible = false (D01).
  action:    Halt pipeline. Log to Audit Trail Agent with the ineligibility
             reason from archival-recommendation.md. Escalate to
             sysadmin:dlm-sysadmin for determination of appropriate next
             action (e.g. extend retention period, re-evaluate trigger).

E05: Invalid archival trigger.
  condition: Archival trigger does not satisfy P05 conditions (no valid
             retention signal and document status is not superseded).
  action:    Reject pipeline initiation. Log to Audit Trail Agent. Notify
             agent:archival-orchestrator. Do not begin Archival stage
             processing under any circumstances.

## REVIEW_SCHEDULE

This procedure is reviewed whenever DLMS-2026-0022 (Retention Schedule),
DLMS-2026-0039 (Document Retention Policy), or DLMS-2026-0040 (Document
Archival Policy) are updated, and at each major SLA renegotiation for
DLMS-2026-0061. Minimum annual review by agent:archival-orchestrator and
sysadmin:dlm-sysadmin.
