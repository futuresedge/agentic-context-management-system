## SUMMARY

This procedure governs the Approval Gate sub-stage of the DLMS document
lifecycle: from Review stage handoff through DoD establishment, approval
decision recording, independent verification, metrics capture, and either
advancement to the Indexing stage (approved), return-to-review, deferral, or
terminal rejection. The Approval Gate operates as a distinct sub-phase within
Tier 5 (Review-Approval Orchestrator) and shares DLMS-2026-0058 (Review Stage
SLA) with the Review stage. The primary outputs are approval-status.md
(decision record), approval-verification.md (independent verification), and
approval-metrics.md (stage performance record).

## SCOPE

Agents active in this stage:

| Pipeline Position | Agent | Output Artefact |
|---|---|---|
| P01 | Review-Approval Orchestrator | (coordination only) |
| P02 | DoD Agent (Approval) | approval-dod.md |
| P03 | Approval Gate Agent | approval-status.md |
| P04 | Approval Verifier | approval-verification.md, approval-learnings.md |
| P05 | Review Metrics Agent | approval-metrics.md |

Excludes:
- Review stage agents (review-synthesis.md and review-verification.md are
  received as inputs; no Review stage agents re-activate)
- Indexing, Storage, Distribution, and Archival stage agents
- Creation stage agents

Executed by:
- agent:review-approval-orchestrator: pipeline coordination, intake
  validation, CI dispatch, and handoff (S01, S06, S07)
- Stage agents: own designated pipeline steps (S02–S05)
- sysadmin:dlm-sysadmin: escalation recipient; notified on rejection
  outcome (D01-b)

## PREREQUISITES

P01: All Approval Gate agents are onboarded per DLMS-2026-0085 (Review and
     Approval Stage Agent Onboarding Procedure). If any agent instance is
     not onboarded, defer pipeline activation until onboarding is complete.
     Failure → E02.

P02: DLMS-2026-0014 (Verification Independence Policy),
     DLMS-2026-0015 (Audit Trail Policy), DLMS-2026-0016 (Agent Context
     Boundary Policy), DLMS-2026-0041 (Definition of Done Policy),
     DLMS-2026-0042 (Review Standards Policy),
     DLMS-2026-0043 (Quality Threshold Policy), and
     DLMS-2026-0058 (Review Stage SLA) are in effect.
     Verified by: agent:review-approval-orchestrator. Failure → E02.

P03: Approval Gate DoD template (DLMS-2026-0026 — TMPL-dod-approval-001) is
     loaded and accessible for DoD Agent (Approval). Failure → E01.

P04: Audit Trail Agent is reachable and accepting log entries. Failure → E03.

P05: Review stage prerequisite artefacts are present: review-verification.md
     (outcome = pass) and review-synthesis.md. If either artefact is absent
     or review-verification.md outcome ≠ pass, reject intake and halt.
     Failure → E05.

## STEPS

S01: Receive handoff from Review stage and validate prerequisites.
  action: Review-Approval Orchestrator receives the Approval Gate intake
          artefacts (review-verification.md + review-synthesis.md + final
          draft artefact). Confirm P05: review-verification.md outcome =
          pass. Log receipt to Audit Trail Agent.
  actor:  agent:review-approval-orchestrator
  reads:  review-verification.md; review-synthesis.md; final draft artefact
  writes: audit log entry
  on_failure: → E05

S02: DoD Agent (Approval) produces approval-dod.md.
  action: DoD Agent (Approval) loads DLMS-2026-0026 (TMPL-dod-approval-001)
          and records the Definition of Done checklist for this approval
          instance. The checklist establishes the criteria that the Approval
          Verifier will evaluate independently after the decision is
          recorded. DoD Agent MUST NOT make the approval decision itself
          (DLMS-2026-0014 R01 — evaluation and decision remain separated).
  actor:  agent:dod-approval
  reads:  DLMS-2026-0026; review-synthesis.md; review-verification.md
  writes: approval-dod.md
  on_failure: → E02

S03: Approval Gate Agent records approval decision.
  action: Approval Gate Agent reads review-synthesis.md,
          review-verification.md, and approval-dod.md. Evaluates the
          document against approval criteria and records a decision.
          Produces approval-status.md per DLMS-2026-0050
          (TMPL-approval-status-001). Decision must be one of:
          approved | rejected | deferred | return-to-review.
  actor:  agent:approval-gate
  reads:  review-synthesis.md; review-verification.md; approval-dod.md
  writes: approval-status.md
  on_failure: → E02
  [D01] Evaluate approval-status.md decision field:
        approved       → S04
        rejected       → D01-b (terminal; notify author; halt pipeline)
        deferred       → D01-c (hold; set deferred-until timestamp)
        return-to-review → D01-d (re-trigger Review Stage SOP)

S04: Approval Verifier evaluates against DoD.
  action: Approval Verifier independently evaluates whether the approval
          decision recorded in approval-status.md satisfies all acceptance
          criteria in approval-dod.md, and that the approval process was
          correctly executed. Produces approval-verification.md (outcome:
          pass | fail) per DLMS-2026-0030 (TMPL-verification-001) and
          approval-learnings.md per DLMS-2026-0034 (TMPL-learnings-001)
          for CI feedback. Approval Verifier MUST NOT be the same agent
          instance as DoD Agent (Approval) or Approval Gate Agent
          (DLMS-2026-0014 R01).
  actor:  agent:approval-verifier
  reads:  approval-status.md; approval-dod.md; review-synthesis.md
  writes: approval-verification.md; approval-learnings.md
  on_failure: → E02
  [D02] approval-verification outcome = fail → E01.

S05: Review Metrics Agent records approval gate metrics.
  action: Review Metrics Agent reads approval-verification.md,
          approval-status.md, and audit trail logs for this approval run.
          Records: approval decision outcome, time-to-decision elapsed from
          Review stage handoff, DoD pass/fail outcome, and SLA variance
          against DLMS-2026-0058. Produces approval-metrics.md.
          Note: this is the second metrics artefact produced by the Review
          Metrics Agent in Tier 5; review-metrics.md covers the Review
          sub-phase; approval-metrics.md covers the Approval sub-phase.
  actor:  agent:review-metrics
  reads:  approval-verification.md; approval-status.md; audit trail log
          entries for this approval run
  writes: approval-metrics.md
  on_failure: → E02

S06: CI dispatch.
  action: Dispatch approval-metrics.md and approval-learnings.md to the CI
          quality monitor queue. Dispatch approval-verification.md to CI
          monitor scope. CI feedback is consumed by Tier 13 per
          DLMS-2026-0076 (CI Cycle Policy).
  actor:  agent:review-approval-orchestrator
  reads:  approval-metrics.md; approval-learnings.md;
          approval-verification.md
  writes: CI queue entries (external to this stage's write scope)
  on_failure: log warning and continue (non-blocking)

S07: Handoff to Indexing stage (approved outcome only).
  action: Pass approval-verification.md and approval-status.md to the
          Indexing stage intake queue. Log handoff to Audit Trail Agent.
          Indexing Stage SOP (DLMS-2026-0097) is triggered on receipt.
          This step executes ONLY for approved outcome — see D01 for all
          other branches.
  actor:  agent:review-approval-orchestrator
  reads:  approval-verification.md (confirm outcome = pass before handoff)
  writes: handoff artefact to Indexing queue; audit log entry
  on_failure: → E02

## DECISION_POINTS

D01: Approval Gate Agent records decision (at S03).
  condition: approval-status.md decision field.
  action per outcome:
    approved:         → S04 (proceed to Approval Verifier, then Indexing).
    rejected:         Halt pipeline. Log to Audit Trail Agent. Notify
                      sysadmin:dlm-sysadmin and document author with
                      rejection reason from approval-status.md. Document
                      status set to rejected (terminal — no further stage
                      transitions in this pipeline run).
    deferred:         Halt pipeline. Log to Audit Trail Agent. Set
                      deferred-until timestamp in approval-status.md.
                      Document remains under_review. Pipeline resumes at
                      S03 on expiry of deferral period.
    return-to-review: Halt Approval Gate pipeline. Log to Audit Trail Agent
                      with return reason. Re-trigger Review Stage SOP
                      (DLMS-2026-0095) from S01 with updated context.

D02: Approval Verifier returns fail (at S04).
  condition: approval-verification.md outcome = fail.
  action:    → E01. Do not advance to S05 or S06. Halt pipeline.

## OUTPUTS

| Artefact | Produced by | Purpose |
|---|---|---|
| approval-dod.md | DoD Agent (Approval) | Acceptance criteria for this approval instance |
| approval-status.md | Approval Gate Agent | Formal approval decision record |
| approval-verification.md | Approval Verifier | Independent DoD evaluation (stage gate artefact) |
| approval-learnings.md | Approval Verifier | Lessons and observations for CI feedback |
| approval-metrics.md | Review Metrics Agent | Approval sub-phase performance record |

## ERROR_CONDITIONS

E01: DoD failure.
  condition: Approval Verifier returns outcome = fail (D02).
  action:    Halt pipeline. Log to Audit Trail Agent with failure reasons
             from approval-verification.md. Escalate to
             sysadmin:dlm-sysadmin for manual review of the approval
             process execution.

E02: Agent unavailable or pipeline step failure.
  condition: Any stage agent fails to produce its designated output artefact.
  action:    Halt pipeline at failure point. Log to Audit Trail Agent
             including step identifier and agent ID.
             agent:review-approval-orchestrator escalates to
             sysadmin:dlm-sysadmin.

E03: Audit Trail Agent unreachable.
  condition: Audit Trail Agent does not respond at S01 or any subsequent
             audit log step.
  action:    Halt pipeline immediately. Do not proceed without audit
             capability (DLMS-2026-0015 R01). Escalate to
             sysadmin:dlm-sysadmin.

E05: Missing Review stage prerequisite.
  condition: review-verification.md absent or outcome ≠ pass; or
             review-synthesis.md absent.
  action:    Reject intake. Log to Audit Trail Agent identifying the absent
             or non-compliant artefact. Do not begin Approval Gate
             processing under any circumstances. Return signal sent to
             Review-Approval Orchestrator.

## REVIEW_SCHEDULE

This procedure is reviewed at each major SLA renegotiation cycle for
DLMS-2026-0058 and whenever the approval decision taxonomy or criteria
change. Minimum annual review conducted by agent:review-approval-orchestrator
and sysadmin:dlm-sysadmin. Any change to the D01 decision branches requires
a version increment per DLMS-2026-0038.
