## SUMMARY
This procedure governs the onboarding of any one of the ten Continuous
Improvement (Tier 13) agent instances — six monitor agents that observe
system behaviour and four synthesis agents that consolidate, recommend, and
brief sysadmin. The CI Verifier must not be the same instance as any monitor
or synthesis agent it verifies; this constraint is applied across up to nine
agents. The Learning Synthesizer must not be the same instance as the
Knowledge Base Agent (Tier 12), as its outputs feed the Knowledge Base but
it does not own it.

## SCOPE

Applies to:
- All ten Continuous Improvement (Tier 13) agents listed below
- agent:ci-cycle-orchestrator as procedure owner
- sysadmin:dlm-sysadmin for final separation verification
- Audit Trail Agent as recipient of onboarding audit events

The ten Continuous Improvement agents, grouped by function:

**Monitor agents (6):**
| Agent | Designated output | Separation constraint |
|---|---|---|
| Quality Monitor | quality-report.md | None beyond universal; ≠ CI Verifier |
| Performance Monitor | performance-report.md | None beyond universal; ≠ CI Verifier |
| Anomaly Detector | anomaly-report.md | None beyond universal; ≠ CI Verifier |
| Bottleneck Analyst | bottleneck-report.md | None beyond universal; ≠ CI Verifier |
| Agent Behaviour Analyst | agent-behaviour-report.md | None beyond universal; ≠ CI Verifier |
| Learning Synthesizer | learning-synthesis.md | ≠ Knowledge Base Agent (Tier 12); ≠ CI Verifier |

**Synthesis agents (4):**
| Agent | Designated output | Separation constraint |
|---|---|---|
| CI Perspective Synthesizer | ci-synthesis.md | ≠ CI Verifier |
| Recommendation Generator | recommendations.md | ≠ CI Verifier |
| CI Verifier | ci-verification.md | ≠ all nine other Tier 13 agents; ≠ Knowledge Base Agent (Tier 12) |
| SysAdmin Briefing Agent | sysadmin-briefing.md | None beyond universal |

Note: The CI Verifier's separation constraint extends to all ten Tier 13
agents (itself excluded). If paired with a Knowledge Base Agent that
consumes its outputs, it must also be a distinct instance from that agent.

Excludes:
- CI Cycle Orchestrator onboarding (DLMS-2026-0083)
- Any agent outside Tier 13

Executed by:
- Onboarding agent (self-check): S02, S03, S04, S05, S06, S08, S09
- agent:ci-cycle-orchestrator: queue assignment (S08)
- sysadmin:dlm-sysadmin: CI Verifier separation verification (S07)

## PREREQUISITES

P01: DLMS-2026-0014, DLMS-2026-0015, DLMS-2026-0016, DLMS-2026-0041,
     DLMS-2026-0063 (Knowledge Base Contribution Policy),
     DLMS-2026-0064 (Learning Synthesis Policy), and DLMS-2026-0076
     (CI Cycle Policy) are in effect.
     Verified by: agent:ci-cycle-orchestrator. Failure → D01.

P02: This agent's context package includes: (a) role identifier and
     designated output schema; (b) relevant Wave 12 CI artefact template
     references (DLMS-2026-0066 through DLMS-2026-0075 as applicable to
     this role); (c) for Learning Synthesizer: DLMS-2026-0064 and the
     current-cycle data scope definition; (d) for CI Verifier: read-access
     references for all CI output artefacts from monitors and synthesis
     agents; (e) for SysAdmin Briefing Agent: DLMS-2026-0073 (briefing
     template).
     Verified by: agent:ci-cycle-orchestrator. Failure → E01.

P03: Audit Trail Agent is reachable. Failure → E03.

P04: agent:ci-cycle-orchestrator is active. If not, defer S08.

## STEPS

S01: Retrieve context package.
  action: Retrieve this agent's context package and confirm it satisfies
          P02. Note role, designated output schema, and (for Learning
          Synthesizer) the cycle data scope.
  actor:  agent:ci-cycle-orchestrator
  reads:  designated context package
  writes: (none — verification only)
  on_failure: → E01

S02: Validate context boundary.
  action: Confirm READS is correctly scoped for each role:
          - Monitor agents: READS = stage metrics and audit events for
            their monitoring domain only; NEVER = document body content;
            policy bodies; other monitors' output artefacts.
          - Learning Synthesizer: READS = all Stage Verifier learnings
            artefacts from the current CI cycle; WRITES = learning-
            synthesis.md only; NEVER = knowledge-base.md (it contributes
            to the Knowledge Base; it does not own it).
          - CI Perspective Synthesizer: READS = all monitor output
            artefacts from current cycle; WRITES = ci-synthesis.md only.
          - Recommendation Generator: READS = ci-synthesis.md and
            learning-synthesis.md; WRITES = recommendations.md only.
          - CI Verifier: READS = all Tier 13 monitor and synthesis output
            artefacts for the current cycle; WRITES = ci-verification.md
            only; NEVER = recommendations.md as an input before verifying
            the underlying synthesis (order discipline).
          - SysAdmin Briefing Agent: READS = ci-verification.md and
            recommendations.md; WRITES = sysadmin-briefing.md only.
  actor:  Onboarding agent; verified by agent:ci-cycle-orchestrator
  reads:  context boundary specification
  writes: boundary validation result (internal)
  on_failure: → D02

S03: Load governing policies into context.
  action: Load: DLMS-2026-0014, DLMS-2026-0015, DLMS-2026-0016,
          DLMS-2026-0041. Additionally:
          - Learning Synthesizer: DLMS-2026-0064
          - Knowledge Base Agent interactions: DLMS-2026-0063 (Learning
            Synthesizer must confirm its output meets ingestion criteria)
          - All agents: DLMS-2026-0076 (CI Cycle Policy).
  actor:  Onboarding agent
  reads:  policy references from context package
  writes: active policy context (internal)
  on_failure: → E01

S04: Emit onboarding-start audit event.
  action: Write onboarding-start event per DLMS-2026-0015. Required fields:
          agent_id, role, ci_cycle_id, tier = 13,
          onboarding_procedure_ref = "DLMS-2026-0092", timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-start event)
  on_failure: → E03

S05: Confirm artefact format.
  action: Generate a zero-content test artefact against designated output
          schema using the relevant Wave 12 template. For CI Verifier:
          confirm it can parse a minimal set of monitor and synthesis
          artefacts and produce ci-verification.md with outcome: pass.
          For SysAdmin Briefing Agent: confirm test briefing includes
          cycle_id, top_recommendations (array), and sysadmin_action_required
          (boolean) fields.
  actor:  Onboarding agent
  reads:  designated output schema; relevant Wave 12 CI template
  writes: test artefact (internal, discarded)
  on_failure: → E02

S06: Confirm CI Cycle Policy reference.
  action: Confirm DLMS-2026-0076 is loaded and that this agent's role and
          output artefact type are explicitly referenced in the policy's
          CI cycle structure. If the role is not referenced, halt and
          escalate — a policy gap exists.
  actor:  Onboarding agent
  reads:  DLMS-2026-0076
  writes: policy binding confirmation (internal)
  on_failure: → E01

S07: Confirm separation criteria.
  action: Per the scope tables above:
          - CI Verifier: confirm agent_id ≠ each of the nine other
            Tier 13 agents (all monitors and all other synthesis agents)
          - Learning Synthesizer: confirm agent_id ≠ Knowledge Base
            Agent (Tier 12)
          For all other agents: confirm agent_id is unique within the
          current Tier 13 active roster.
          Per DLMS-2026-0014 R01.
  actor:  sysadmin:dlm-sysadmin
  reads:  All Tier 13 agent_ids and Tier 12 Knowledge Base Agent agent_id
  writes: separation confirmation note (internal)
  on_failure: → D03

S08: Register with CI Cycle Orchestrator.
  action: Dispatch registration event to agent:ci-cycle-orchestrator:
          agent_id, role, ci_cycle_id, tier = 13, onboarding_status =
          "complete". Receive cycle-phase assignment.
  actor:  Onboarding agent; agent:ci-cycle-orchestrator
  reads:  Orchestrator endpoint from context package
  writes: Phase assignment in orchestrator's active roster
  on_failure: → E04

S09: Emit onboarding-complete audit event.
  action: Write onboarding-complete event per DLMS-2026-0015. Required
          fields: agent_id, role, ci_cycle_id, tier = 13,
          onboarding_procedure_ref = "DLMS-2026-0092",
          outcome [success | failure], cycle_phase_assignment (or null),
          timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-complete event)
  on_failure: → E03

## DECISION_POINTS

D01: If P01 fails → halt. Notify orchestrator and sysadmin:dlm-sysadmin.

D02: If S02 fails → halt. Notify orchestrator for context package correction.

D03: If S07 fails (any separation constraint violated) → halt. Escalate to
     sysadmin:dlm-sysadmin. All conflicting agents must be resolved before
     the CI cycle begins.

## OUTPUTS

| Artefact | Produced by step | Written to | Consumed by |
|---|---|---|---|
| Operational CI agent with validated context | S02–S06 | internal state | CI Cycle Orchestrator; cycle pipeline |
| Cycle-phase assignment entry | S08 | Orchestrator's active roster | CI Cycle Orchestrator |
| onboarding-start audit event | S04 | audit-trail.log | Audit Trail Agent |
| onboarding-complete audit event | S09 | audit-trail.log | Audit Trail Agent; orchestrator |

## ERROR_CONDITIONS

E01: Context package unavailable or policy binding not found in DLMS-2026-0076.
  resolution:   Defer; escalate to sysadmin:dlm-sysadmin.

E02: Artefact format validation fails.
  likely_cause: Wave 12 template fields missing; SysAdmin Briefing Agent
                schema incomplete.
  resolution:   Halt. Log. Escalate to sysadmin:dlm-sysadmin.

E03: Audit trail unreachable.
  resolution:   Halt. Alert sysadmin:dlm-sysadmin. Retry after reachable.

E04: Orchestrator rejects cycle-phase registration.
  resolution:   Halt. Notify sysadmin:dlm-sysadmin.

## REVIEW_SCHEDULE

interval_max: Per CI cycle (minimum every six months or at the start of
              each major CI cycle, whichever is sooner)
trigger_conditions:
  - Tier 13 agent roster changes
  - DLMS-2026-0076 revised with CI cycle structure changes affecting
    monitor or synthesis agent roles
  - Wave 12 CI artefact templates revised
review_owner:   agent:ci-cycle-orchestrator; sysadmin:dlm-sysadmin
review_process: Standard procedure review per DLMS-2026-0001
