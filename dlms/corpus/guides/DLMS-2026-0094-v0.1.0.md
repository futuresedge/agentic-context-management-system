## SUMMARY

This procedure governs the Creation stage of the DLMS document lifecycle: from
intake request through context curation, problem analysis, DoD establishment,
authoring, template validation, and independent verification, to handoff to the
Review stage with document status set to under_review. All processing agents
operate under minimal viable context discipline; no agent reads beyond its
designated context package. The primary outputs are draft-v0.1-agent.md (the
draft document artefact), creation-verification.md (independent verification
record), and creation-metrics.md (stage performance record).

## SCOPE

Agents active in this stage:

| Pipeline Position | Agent | Output Artefact |
|---|---|---|
| P01 | Creation Orchestrator | (coordination only) |
| P02 | Context Curator (Creation) | creation-context.md |
| P03 | Problem Analysis Agent | problem-analysis.md |
| P04 | DoD Agent (Creation) | creation-dod.md |
| P05 | Document Author | draft-v0.1-agent.md |
| P06 | Template Validator | template-compliance.md |
| P07 | Creation Verifier | creation-verification.md, creation-learnings.md |
| P08 | Creation Metrics Agent | creation-metrics.md |

Excludes:
- Agents from any other stage pipeline (Review, Approval Gate, Indexing,
  Storage, Distribution, Archival)
- Any Tier 2 Governance Layer, Tier 13 CI, or Tier 14 SysAdmin agents
  (governed by their own SOPs)

Executed by:
- agent:creation-orchestrator: pipeline coordination, intake validation,
  CI dispatch, and handoff (S01, S09, S10)
- Stage agents: own designated pipeline steps (S02–S08)
- sysadmin:dlm-sysadmin: intake submission (S01 trigger); escalation
  recipient for E02, E03, E04

## PREREQUISITES

P01: All Creation stage agents are onboarded per DLMS-2026-0084 (Creation
     Stage Agent Onboarding Procedure). If any agent instance is not
     onboarded, defer pipeline activation until onboarding is complete.
     Failure → E02.

P02: DLMS-2026-0014 (Verification Independence Policy),
     DLMS-2026-0015 (Audit Trail Policy), DLMS-2026-0016 (Agent Context
     Boundary Policy), DLMS-2026-0035 (Document Creation Policy),
     DLMS-2026-0041 (Definition of Done Policy),
     DLMS-2026-0042 (Review Standards Policy),
     DLMS-2026-0043 (Quality Threshold Policy), and
     DLMS-2026-0057 (Creation Stage SLA) are in effect.
     Verified by: agent:creation-orchestrator. Failure → E02.

P03: Creation DoD template (DLMS-2026-0024 — TMPL-dod-creation-001) is
     loaded and accessible for DoD Agent (Creation). Failure → E01.

P04: Audit Trail Agent is reachable and accepting log entries. Failure → E03.

## STEPS

S01: Receive intake request and validate trigger.
  action: Creation Orchestrator receives the document intake request.
          Validate that the request originates from sysadmin:dlm-sysadmin
          or an authorised external author. Confirm that a new doc_id has
          been assigned per DLMS-2026-0003 (Naming Convention Policy).
          Log receipt to Audit Trail Agent.
  actor:  agent:creation-orchestrator
  reads:  intake request artefact
  writes: audit log entry
  on_failure: → E02

S02: Context Curator (Creation) produces context package.
  action: Context Curator (Creation) reads the designated context sources
          for this document and produces creation-context.md per
          DLMS-2026-0046 (TMPL-creation-context-001). Context package must
          satisfy DLMS-2026-0016: READS is limited to designated context
          sources; no document body content from prior runs is accessible.
  actor:  agent:context-curator-creation
  reads:  designated context sources (doc_id, doc_type, brief, governing
          policies list — scoped per DLMS-2026-0016)
  writes: creation-context.md
  on_failure: → E02

S03: Problem Analysis Agent produces problem analysis.
  action: Problem Analysis Agent reads creation-context.md and performs
          structured analysis across three lens dimensions — accuracy,
          completeness, and audience suitability — loading each lens skill
          file on demand. Produces problem-analysis.md per DLMS-2026-0047
          (TMPL-problem-analysis-001), summarising document design intent,
          identified gaps, and authoring scope.
  actor:  agent:problem-analysis
  reads:  creation-context.md; accuracy lens skill; completeness lens
          skill; audience lens skill (each loaded on demand)
  writes: problem-analysis.md
  on_failure: → E02

S04: DoD Agent (Creation) produces creation-dod.md.
  action: DoD Agent (Creation) loads DLMS-2026-0024 (TMPL-dod-creation-001)
          and records the Definition of Done checklist for this document
          instance. The checklist establishes the acceptance criteria that
          the Creation Verifier will evaluate independently. DoD Agent MUST
          NOT pre-evaluate the draft (DLMS-2026-0014 R01).
  actor:  agent:dod-creation
  reads:  DLMS-2026-0024; problem-analysis.md; creation-context.md
  writes: creation-dod.md
  on_failure: → E02

S05: Document Author produces draft artefact.
  action: Document Author reads creation-context.md and problem-analysis.md
          and the relevant document template (per doc_type). Produces
          draft-v0.1-agent.md conforming to the assigned template schema and
          the authoring scope defined in problem-analysis.md. The NEVER list
          must exclude: DoD artefacts; verification artefacts; other agents'
          output artefacts.
  actor:  agent:document-author
  reads:  creation-context.md; problem-analysis.md; assigned doc_type
          template
  writes: draft-v0.1-agent.md
  on_failure: → E02

S06: Template Validator evaluates schema compliance.
  action: Template Validator reads draft-v0.1-agent.md and the assigned
          template schema for the document's doc_type. Produces
          template-compliance.md with result: pass or fail. Validates:
          frontmatter schema completeness, required section headings, body
          section order, UPPER_SNAKE_CASE heading convention, and mandatory
          field population.
  actor:  agent:template-validator
  reads:  draft-v0.1-agent.md; assigned doc_type template schema
  writes: template-compliance.md
  on_failure: → E02
  [D01] template-compliance result = fail → return to S05 (Document Author
        revision). Revision counter incremented. If revision count exceeds
        maximum per DLMS-2026-0042 → E04.

S07: Creation Verifier evaluates against DoD.
  action: Creation Verifier independently evaluates whether draft-v0.1-
          agent.md satisfies all acceptance criteria in creation-dod.md.
          Reads draft artefact, creation-dod.md, and creation-context.md.
          Produces creation-verification.md (outcome: pass | fail) per
          DLMS-2026-0030 (TMPL-verification-001), and creation-learnings.md
          per DLMS-2026-0034 (TMPL-learnings-001) for CI feedback.
          Creation Verifier MUST NOT be the same agent instance as DoD Agent
          (Creation) or Document Author (DLMS-2026-0014 R01).
  actor:  agent:creation-verifier
  reads:  draft-v0.1-agent.md; creation-dod.md; creation-context.md
  writes: creation-verification.md; creation-learnings.md
  on_failure: → E02
  [D02] creation-verification outcome = fail → E01.

S08: Creation Metrics Agent records stage performance.
  action: Creation Metrics Agent reads creation-verification.md,
          template-compliance.md, and audit trail logs for this pipeline
          run. Records: end-to-end stage elapsed time, revision count,
          DoD pass/fail outcome, and SLA variance against DLMS-2026-0057.
          Produces creation-metrics.md.
  actor:  agent:creation-metrics
  reads:  creation-verification.md; template-compliance.md; audit trail
          log entries for this pipeline run
  writes: creation-metrics.md
  on_failure: → E02

S09: CI dispatch.
  action: Dispatch creation-metrics.md and creation-learnings.md to the CI
          quality monitor queue. Dispatch creation-verification.md to CI
          monitor scope for independent audit. CI feedback is consumed by
          Tier 13 (Quality Monitor, Performance Monitor, Anomaly Detector)
          per DLMS-2026-0076 (CI Cycle Policy).
  actor:  agent:creation-orchestrator
  reads:  creation-metrics.md; creation-learnings.md;
          creation-verification.md
  writes: CI queue entries (external to this stage's write scope)
  on_failure: log warning and continue (non-blocking)

S10: Handoff to Review stage.
  action: Set document status to under_review per DLMS-2026-0037 (Document
          Status Transition Policy). Pass draft-v0.1-agent.md and
          creation-verification.md to the Review stage intake queue. Log
          handoff event to Audit Trail Agent.
  actor:  agent:creation-orchestrator
  reads:  creation-verification.md (confirm outcome = pass before handoff)
  writes: status update (under_review); handoff artefact to Review queue;
          audit log entry
  on_failure: → E02

## DECISION_POINTS

D01: Template Validator returns fail (at S06).
  condition: template-compliance.md result = fail.
  action:    Return to S05 (Document Author). Increment revision counter.
             If revision counter exceeds maximum per DLMS-2026-0042 → E04.

D02: Creation Verifier returns fail (at S07).
  condition: creation-verification.md outcome = fail.
  action:    → E01. Do not advance to S08 or S09. Issue return-to-creation
             directive to Creation Orchestrator. Halt pipeline.

## OUTPUTS

| Artefact | Produced by | Purpose |
|---|---|---|
| creation-context.md | Context Curator (Creation) | Scoped context package for this pipeline run |
| problem-analysis.md | Problem Analysis Agent | Document design intent and authoring scope |
| creation-dod.md | DoD Agent (Creation) | Acceptance criteria for this document |
| draft-v0.1-agent.md | Document Author | Primary draft document artefact |
| template-compliance.md | Template Validator | Template schema validation result |
| creation-verification.md | Creation Verifier | Independent DoD evaluation (stage gate artefact) |
| creation-learnings.md | Creation Verifier | Lessons and observations for CI feedback |
| creation-metrics.md | Creation Metrics Agent | Stage performance record |

## ERROR_CONDITIONS

E01: DoD failure.
  condition: Creation Verifier returns outcome = fail (D02).
  action:    Halt pipeline. Log failure to Audit Trail Agent. Issue
             return-to-creation directive. sysadmin:dlm-sysadmin and
             the document author are notified. Pipeline may re-run
             after documented remediation addressing the failure reasons
             recorded in creation-verification.md.

E02: Agent unavailable or pipeline step failure.
  condition: Any stage agent fails to produce its designated output artefact
             at any step.
  action:    Halt pipeline at the failure point. Log failure to Audit Trail
             Agent including step identifier and agent ID.
             agent:creation-orchestrator escalates to
             sysadmin:dlm-sysadmin.

E03: Audit Trail Agent unreachable.
  condition: Audit Trail Agent does not respond at S01 or any subsequent
             audit log step.
  action:    Halt pipeline immediately. Do not proceed without audit
             capability (DLMS-2026-0015 R01). Escalate to
             sysadmin:dlm-sysadmin.

E04: Revision limit exceeded.
  condition: Template validation failure loop (D01 → S05 → S06) exceeds
             the maximum revision count defined in DLMS-2026-0042.
  action:    Halt pipeline. Log to Audit Trail Agent with full revision
             history. Escalate to sysadmin:dlm-sysadmin for manual review
             of document-template alignment. Do not re-run until root
             cause is resolved.

## REVIEW_SCHEDULE

This procedure is reviewed at each major SLA renegotiation cycle for
DLMS-2026-0057 and whenever the Creation stage agent roster changes.
Minimum annual review conducted by agent:creation-orchestrator and
sysadmin:dlm-sysadmin. Any change to the pipeline step sequence requires
a version increment per DLMS-2026-0038.
