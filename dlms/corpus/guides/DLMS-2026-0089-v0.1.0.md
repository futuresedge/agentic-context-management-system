## SUMMARY
This procedure governs the onboarding of any one of the seven Archival Stage
agent instances — the Tier 10 agents that evaluate retention, execute
archival transitions, manage document status changes, and verify archival
completeness. The Retention Evaluator must have access to DLMS-2026-0039
(Document Retention Policy) and DLMS-2026-0022 (Document Retention Reference)
as read-only inputs; it must not be the same instance as the Archival
Verifier. An Impact Assessment check per DLMS-2026-0077 is required for any
document with active dependencies before archival proceeds.

## SCOPE

Applies to:
- All seven Archival Stage (Tier 10) agents listed below
- agent:archival-orchestrator as procedure owner
- sysadmin:dlm-sysadmin for separation verification
- Audit Trail Agent as recipient of onboarding audit events

The seven Archival Stage agents:

| Agent | Designated output | Separation constraint |
|---|---|---|
| Context Curator (Archival) | archival-context.md | None beyond universal |
| DoD Agent (Archival) | archival-dod.md | Must not be same instance as Archival Verifier |
| Retention Evaluator | archival-recommendation.md | Must not be same instance as Archival Verifier |
| Archival Agent | archival-log.md | Must not be same instance as Retention Evaluator |
| Status Transition Agent | status-transition-record.md | None beyond universal; reads DLMS-2026-0037 only |
| Archival Verifier | archival-verification.md + archival-learnings.md | Must not be same instance as DoD Agent or Retention Evaluator |
| Archival Metrics Agent | archival-metrics.md | None beyond universal |

Excludes:
- Archival Orchestrator onboarding (DLMS-2026-0083)
- Any agent outside Tier 10

Executed by:
- Onboarding agent (self-check): S02, S03, S04, S05, S06, S08, S09
- agent:archival-orchestrator: queue assignment (S08)
- sysadmin:dlm-sysadmin: separation verification (S07)

## PREREQUISITES

P01: DLMS-2026-0014, DLMS-2026-0015, and DLMS-2026-0016 are in effect.
     Additionally: DLMS-2026-0022 (Document Retention Reference),
     DLMS-2026-0037 (Document Status Transition Policy), DLMS-2026-0038
     (Document Retention Policy), DLMS-2026-0039 (Document Archival Policy),
     DLMS-2026-0040 (Document Destruction Policy), DLMS-2026-0041
     (Definition of Done Policy), DLMS-2026-0061 (Archival Stage SLA), and
     DLMS-2026-0077 (Impact Assessment Policy) are in effect.
     Verified by: agent:archival-orchestrator. Failure → D01.

P02: This agent's designated context package includes: (a) role identifier
     and designated output schema; (b) Archival DoD template reference
     (DLMS-2026-0029); (c) relevant artefact template references
     (DLMS-2026-0055 for Retention Evaluator; DLMS-2026-0056 for Archival
     Agent); (d) for Retention Evaluator: read-access reference to
     DLMS-2026-0022 and DLMS-2026-0039.
     Verified by: agent:archival-orchestrator. Failure → E01.

P03: Audit Trail Agent is reachable. Failure → E03.

P04: agent:archival-orchestrator is active. If not, defer S08.

## STEPS

S01: Retrieve context package.
  action: Retrieve this agent's context package and confirm it satisfies
          P02. Note role, designated output schema, and (for Retention
          Evaluator) the retention policy and reference reads.
  actor:  agent:archival-orchestrator
  reads:  designated context package
  writes: (none — verification only)
  on_failure: → E01

S02: Validate context boundary.
  action: Confirm READS is limited to: (a) incoming document metadata
          for this role; (b) designated output schema; (c) governing
          policies per P01; (d) DLMS-2026-0022 + DLMS-2026-0039 for
          Retention Evaluator only; (e) DLMS-2026-0037 for Status
          Transition Agent only. NEVER list must exclude: document body
          content; other stages' artefacts. Retention Evaluator READS
          must not include the Archival Verifier's output nor the Archival
          Agent's output artefact (evaluation must precede, not reference,
          archival execution).
  actor:  Onboarding agent; verified by agent:archival-orchestrator
  reads:  context boundary specification
  writes: boundary validation result (internal)
  on_failure: → D02

S03: Load governing policies into context.
  action: Load: DLMS-2026-0014, DLMS-2026-0015, DLMS-2026-0016,
          DLMS-2026-0037, DLMS-2026-0039, DLMS-2026-0040,
          DLMS-2026-0041, DLMS-2026-0061. Retention Evaluator also loads
          DLMS-2026-0022 and DLMS-2026-0077.
  actor:  Onboarding agent
  reads:  policy references from context package
  writes: active policy context (internal)
  on_failure: → E01

S04: Emit onboarding-start audit event.
  action: Write onboarding-start event per DLMS-2026-0015. Required fields:
          agent_id, role, stage = "archival", tier = 10,
          onboarding_procedure_ref = "DLMS-2026-0089", timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-start event)
  on_failure: → E03

S05: Confirm artefact format.
  action: Generate a zero-content test artefact against designated output
          schema. For Retention Evaluator: test recommendation must include
          retention_class, retention_period, impact_assessment_required
          (boolean), and retention_basis referencing DLMS-2026-0022.
          For Archival Agent: test log must include archived_at, storage_ref,
          and prior_status. For Archival Verifier: parse a known-passing
          archival-dod and produce archival-verification with outcome: pass.
  actor:  Onboarding agent
  reads:  designated output schema
  writes: test artefact (internal, discarded)
  on_failure: → E02

S06: Confirm SLA and impact assessment reference.
  action: Confirm DLMS-2026-0061 is loaded. Confirm DLMS-2026-0077 rule
          that an impact assessment is required before archiving any document
          with active incoming dependencies is accessible to the Retention
          Evaluator. Verify that impact_assessment_required can be set to
          true in the test artefact from S05.
  actor:  Onboarding agent
  reads:  DLMS-2026-0061; DLMS-2026-0077
  writes: SLA and impact assessment confirmation (internal)
  on_failure: → E01

S07: Confirm separation criteria.
  action: Per the scope table constraints:
          - Retention Evaluator: confirm agent_id ≠ Archival Verifier and
            agent_id ≠ Archival Agent
          - DoD Agent (Archival): confirm agent_id ≠ Archival Verifier
          - Archival Verifier: confirm agent_id ≠ DoD Agent and
            agent_id ≠ Retention Evaluator
          Per DLMS-2026-0014 R01.
  actor:  sysadmin:dlm-sysadmin
  reads:  All Tier 10 agent_ids from orchestrator's active registry
  writes: separation confirmation note (internal)
  on_failure: → D03

S08: Register with Archival Orchestrator.
  action: Dispatch registration event to agent:archival-orchestrator:
          agent_id, role, stage = "archival", onboarding_status = "complete".
          Receive queue assignment.
  actor:  Onboarding agent; agent:archival-orchestrator
  reads:  Orchestrator endpoint from context package
  writes: Queue assignment in orchestrator's active roster
  on_failure: → E04

S09: Emit onboarding-complete audit event.
  action: Write onboarding-complete event per DLMS-2026-0015. Required
          fields: agent_id, role, stage = "archival", tier = 10,
          onboarding_procedure_ref = "DLMS-2026-0089",
          outcome [success | failure], queue_assignment (or null if
          deferred), timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-complete event)
  on_failure: → E03

## DECISION_POINTS

D01: If P01 fails → halt. Notify orchestrator and sysadmin:dlm-sysadmin.

D02: If S02 fails → halt. Notify orchestrator for context package correction.

D03: If S07 fails (separation violated) → halt. Escalate to
     sysadmin:dlm-sysadmin.

## OUTPUTS

| Artefact | Produced by step | Written to | Consumed by |
|---|---|---|---|
| Operational Archival agent with validated context | S02–S06 | internal state | Archival Orchestrator; pipeline |
| Queue assignment entry | S08 | Orchestrator's active roster | Archival Orchestrator |
| onboarding-start audit event | S04 | audit-trail.log | Audit Trail Agent |
| onboarding-complete audit event | S09 | audit-trail.log | Audit Trail Agent; orchestrator |

## ERROR_CONDITIONS

E01: Context package unavailable or incomplete.
  likely_cause: DLMS-2026-0039, 0055, or 0056 not yet authored;
                DLMS-2026-0077 not in effect.
  resolution:   Defer; escalate to sysadmin:dlm-sysadmin.

E02: Artefact format validation fails.
  likely_cause: impact_assessment_required field absent; retention_basis
                not referencing DLMS-2026-0022.
  resolution:   Halt. Log. Escalate to sysadmin:dlm-sysadmin.

E03: Audit trail unreachable.
  resolution:   Halt. Alert sysadmin:dlm-sysadmin. Retry after reachable.

E04: Orchestrator rejects queue registration.
  resolution:   Halt. Notify sysadmin:dlm-sysadmin.
