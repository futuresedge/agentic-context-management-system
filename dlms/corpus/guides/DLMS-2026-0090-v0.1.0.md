## SUMMARY
This procedure governs the onboarding of any one of the eight Context Delivery
Layer (Tier 11) agent instances — the agents that receive context requests,
retrieve relevant documents, validate the retrieved context package against
quality and recency constraints, compress the result, and deliver it to the
requesting agent. The four validator agents (Recency, Accuracy, Completeness,
Format) must all be distinct instances from each other and from the Delivery
Verifier; this five-way separation is a hard constraint of DLMS-2026-0014.

## SCOPE

Applies to:
- All eight Context Delivery Layer (Tier 11) agents listed below
- sysadmin:dlm-sysadmin as procedure owner
- Audit Trail Agent as recipient of onboarding audit events

The eight Context Delivery Layer agents:

| Agent | Designated output | Separation constraint |
|---|---|---|
| Context Request Handler | context-request.md (queues request) | None beyond universal |
| Document Retrieval Agent | retrieved-documents.bundle | None beyond universal |
| Recency Validator | recency-validation.md | ≠ Accuracy Validator; ≠ Completeness Validator; ≠ Format Validator; ≠ Delivery Verifier |
| Accuracy Validator | accuracy-validation.md | ≠ Recency Validator; ≠ Completeness Validator; ≠ Format Validator; ≠ Delivery Verifier |
| Completeness Validator | completeness-validation.md | ≠ Recency Validator; ≠ Accuracy Validator; ≠ Format Validator; ≠ Delivery Verifier |
| Format Validator | format-validation.md | ≠ Recency Validator; ≠ Accuracy Validator; ≠ Completeness Validator; ≠ Delivery Verifier |
| Context Compressor | compressed-context.bundle | Must not be same instance as Delivery Verifier |
| Delivery Verifier | delivery-verification.md | ≠ all four validators; ≠ Context Compressor |

Note: The five-way validator/verifier separation ensures no single agent
instance can both produce a validation result and verify the overall
delivery against that same result.

Excludes:
- Any agent outside Tier 11

Executed by:
- Onboarding agent (self-check): S02, S03, S04, S05, S06, S08, S09
- sysadmin:dlm-sysadmin: separation verification (S07), queue assignment (S08)

## PREREQUISITES

P01: DLMS-2026-0014, DLMS-2026-0015, DLMS-2026-0016, DLMS-2026-0041
     (Definition of Done Policy), and DLMS-2026-0062 (Context Delivery SLA)
     are in effect. Verified by: sysadmin:dlm-sysadmin. Failure → D01.

P02: This agent's designated context package includes: (a) role identifier
     and designated output schema for each validation type; (b) for
     Recency Validator: the maximum acceptable document age threshold from
     DLMS-2026-0062; (c) for Format Validator: the canonical list of valid
     context bundle fields.
     Verified by: sysadmin:dlm-sysadmin. Failure → E01.

P03: Audit Trail Agent is reachable. Failure → E03.

## STEPS

S01: Retrieve context package.
  action: Retrieve this agent's context package and confirm it satisfies
          P02.
  actor:  sysadmin:dlm-sysadmin
  reads:  designated context package
  writes: (none — verification only)
  on_failure: → E01

S02: Validate context boundary.
  action: Confirm READS is limited to: (a) the incoming retrieved-documents
          bundle for validation/compression/verification roles; (b) output
          schema for this role; (c) governing policies per P01. NEVER list
          must exclude: upstream document body content beyond what is
          bundled in the retrieved set; other validators' output artefacts
          (each validator performs its check independently). Delivery
          Verifier READS must not include individual validator outputs —
          it receives only the aggregated delivery-ready signal.
  actor:  Onboarding agent; verified by sysadmin:dlm-sysadmin
  reads:  context boundary specification
  writes: boundary validation result (internal)
  on_failure: → D02

S03: Load governing policies into context.
  action: Load: DLMS-2026-0014, DLMS-2026-0015, DLMS-2026-0016,
          DLMS-2026-0041, DLMS-2026-0062. Load designated output schema.
  actor:  Onboarding agent
  reads:  policy references from context package
  writes: active policy context (internal)
  on_failure: → E01

S04: Emit onboarding-start audit event.
  action: Write onboarding-start event per DLMS-2026-0015. Required fields:
          agent_id, role, tier = 11,
          onboarding_procedure_ref = "DLMS-2026-0090", timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-start event)
  on_failure: → E03

S05: Confirm artefact format.
  action: Generate a zero-content test artefact against designated output
          schema. For each Validator: test artefact must include
          validation_type, outcome (pass | fail | warning), and
          evaluated_at. For Delivery Verifier: confirm it can parse a
          fully assembled delivery-ready signal and produce
          delivery-verification with outcome: delivered. For Context
          Compressor: confirm output is a valid compressed context bundle
          with a document_count field.
  actor:  Onboarding agent
  reads:  designated output schema
  writes: test artefact (internal, discarded)
  on_failure: → E02

S06: Confirm SLA reference.
  action: Confirm DLMS-2026-0062 is loaded and that Recency Validator can
          read the maximum acceptable document age threshold. Delivery
          Verifier must be able to cite the latency_target metric from
          DLMS-2026-0062.
  actor:  Onboarding agent
  reads:  DLMS-2026-0062
  writes: SLA confirmation (internal)
  on_failure: → E01

S07: Confirm separation criteria.
  action: Confirm the five-way separation constraint across all four
          validators and the Delivery Verifier:
          - Recency, Accuracy, Completeness, Format Validators: all four
            have distinct agent_ids from each other and from Delivery Verifier
          - Context Compressor: agent_id ≠ Delivery Verifier
          Per DLMS-2026-0014 R01. Performed only when multiple Tier 11
          agents are being onboarded in the same initialisation pass. If
          only one agent is onboarding, confirm it does not share an
          agent_id with any already-registered Tier 11 agent.
  actor:  sysadmin:dlm-sysadmin
  reads:  All Tier 11 agent_ids from sysadmin registry
  writes: separation confirmation note (internal)
  on_failure: → D03

S08: Register with Context Delivery Layer roster.
  action: Register agent_id and role in the Context Delivery Layer active
          roster maintained by sysadmin:dlm-sysadmin. No external
          orchestrator registration is required — the Context Delivery
          Layer operates on direct inbound requests.
  actor:  sysadmin:dlm-sysadmin
  reads:  Context Delivery Layer active roster
  writes: Registration entry in active roster
  on_failure: → E04

S09: Emit onboarding-complete audit event.
  action: Write onboarding-complete event per DLMS-2026-0015. Required
          fields: agent_id, role, tier = 11,
          onboarding_procedure_ref = "DLMS-2026-0090",
          outcome [success | failure], timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-complete event)
  on_failure: → E03

## DECISION_POINTS

D01: If P01 fails → halt. Notify sysadmin:dlm-sysadmin.

D02: If S02 fails → halt. Notify sysadmin:dlm-sysadmin for context package
     correction.

D03: If S07 fails (any separation constraint violated across the five
     validator/verifier roles) → halt. Escalate to sysadmin:dlm-sysadmin.
     All five roles must be resolved before any of the five may operate.

## OUTPUTS

| Artefact | Produced by step | Written to | Consumed by |
|---|---|---|---|
| Operational Context Delivery agent with validated context | S02–S06 | internal state | Context Delivery Layer roster |
| Registration entry | S08 | sysadmin Context Delivery Layer roster | sysadmin:dlm-sysadmin |
| onboarding-start audit event | S04 | audit-trail.log | Audit Trail Agent |
| onboarding-complete audit event | S09 | audit-trail.log | Audit Trail Agent; sysadmin:dlm-sysadmin |

## ERROR_CONDITIONS

E01: Context package unavailable or SLA thresholds not accessible.
  resolution:   Defer; escalate to sysadmin:dlm-sysadmin.

E02: Artefact format validation fails.
  likely_cause: validation_type enumeration not defined; compressed bundle
                fields missing; Delivery Verifier schema incomplete.
  resolution:   Halt. Log. Escalate to sysadmin:dlm-sysadmin.

E03: Audit trail unreachable.
  resolution:   Halt. Alert sysadmin:dlm-sysadmin. Retry after reachable.

E04: Registration in active roster fails.
  resolution:   Halt. Notify sysadmin:dlm-sysadmin.
