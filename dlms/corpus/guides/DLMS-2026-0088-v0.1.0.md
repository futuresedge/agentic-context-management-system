## SUMMARY
This procedure governs the onboarding of any one of the seven Distribution
Stage agent instances — the Tier 9 agents responsible for planning,
executing, and verifying the distribution of approved documents to
registered recipients. The Impact Assessment Policy (DLMS-2026-0077) is
a required context reference for the Distribution Planner, whose plan must
confirm that distribution to active recipients does not violate any
outstanding impact assessment findings. Distribution Verifier must be a
distinct instance from the DoD Agent.

## SCOPE

Applies to:
- All seven Distribution Stage (Tier 9) agents listed below
- agent:distribution-orchestrator as procedure owner
- sysadmin:dlm-sysadmin for separation verification
- Audit Trail Agent as recipient of onboarding audit events

The seven Distribution Stage agents:

| Agent | Designated output | Separation constraint |
|---|---|---|
| Context Curator (Distribution) | distribution-context.md | None beyond universal |
| DoD Agent (Distribution) | distribution-dod.md | Must not be same instance as Distribution Verifier |
| Distribution Planner | distribution-plan.md | Must not be same instance as Distribution Agent |
| Distribution Agent | distribution-log.md (delivery records) | Must not be same instance as Distribution Planner |
| Change Notification Agent | change-notification.{recipient}.md | None beyond universal |
| Distribution Verifier | distribution-verification.md + distribution-learnings.md | Must not be same instance as DoD Agent |
| Distribution Metrics Agent | distribution-metrics.md | None beyond universal |

Excludes:
- Distribution Orchestrator onboarding (DLMS-2026-0083)
- Any agent outside Tier 9

Executed by:
- Onboarding agent (self-check): S02, S03, S04, S05, S06, S08, S09
- agent:distribution-orchestrator: queue assignment (S08)
- sysadmin:dlm-sysadmin: separation verification (S07)

## PREREQUISITES

P01: DLMS-2026-0014, DLMS-2026-0015, and DLMS-2026-0016 are in effect.
     Additionally: DLMS-2026-0041 (Definition of Done Policy),
     DLMS-2026-0060 (Distribution Stage SLA), and DLMS-2026-0077
     (Impact Assessment Policy) are in effect.
     Verified by: agent:distribution-orchestrator. Failure → D01.

P02: This agent's designated context package includes: (a) role identifier
     and designated output schema; (b) Distribution DoD template reference
     (DLMS-2026-0028); (c) relevant artefact template references
     (DLMS-2026-0053 for Distribution Planner, DLMS-2026-0054 for
     Distribution Agent); (d) for Distribution Planner: a reference to
     DLMS-2026-0077 for impact assessment requirements.
     Verified by: agent:distribution-orchestrator. Failure → E01.

P03: Audit Trail Agent is reachable. Failure → E03.

P04: agent:distribution-orchestrator is active. If not, defer S08.

## STEPS

S01: Retrieve context package.
  action: Retrieve this agent's context package and confirm it satisfies
          P02. Note role, designated output schema, and (for Distribution
          Planner) the Impact Assessment Policy reference.
  actor:  agent:distribution-orchestrator
  reads:  designated context package
  writes: (none — verification only)
  on_failure: → E01

S02: Validate context boundary.
  action: Confirm READS is limited to: (a) incoming document metadata and
          recipient list for this role's step; (b) designated output schema;
          (c) governing policies per P01; (d) DLMS-2026-0077 for Distribution
          Planner only. NEVER list must exclude: document body content beyond
          identifiers; other agents' distribution logs or plans. Distribution
          Planner and Distribution Agent READS must not include each other's
          output artefacts.
  actor:  Onboarding agent; verified by agent:distribution-orchestrator
  reads:  context boundary specification
  writes: boundary validation result (internal)
  on_failure: → D02

S03: Load governing policies into context.
  action: Load: DLMS-2026-0014, DLMS-2026-0015, DLMS-2026-0016,
          DLMS-2026-0041, DLMS-2026-0060, DLMS-2026-0077 (for Distribution
          Planner). Load designated output schema and required artefact
          templates.
  actor:  Onboarding agent
  reads:  policy references from context package
  writes: active policy context (internal)
  on_failure: → E01

S04: Emit onboarding-start audit event.
  action: Write onboarding-start event per DLMS-2026-0015. Required fields:
          agent_id, role, stage = "distribution", tier = 9,
          onboarding_procedure_ref = "DLMS-2026-0088", timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-start event)
  on_failure: → E03

S05: Confirm artefact format.
  action: Generate a zero-content test artefact against designated output
          schema. For Distribution Planner: test plan must include a
          impact_assessment_status field to hold the outcome of DLMS-
          2026-0077 evaluation before distribution is permitted. For
          Distribution Agent: test delivery record must include recipient_id,
          dispatched_at, and delivery_status. For Distribution Verifier:
          parse a known-passing distribution-dod artefact and produce a
          distribution-verification with outcome: pass.
  actor:  Onboarding agent
  reads:  designated output schema
  writes: test artefact (internal, discarded)
  on_failure: → E02

S06: Confirm SLA reference.
  action: Confirm DLMS-2026-0060 is loaded. DoD Agent and Distribution
          Verifier must cite specific metric identifiers from DLMS-2026-0060
          (e.g. distribution_latency_threshold, notification_delay_sla).
  actor:  Onboarding agent
  reads:  DLMS-2026-0060
  writes: SLA confirmation (internal)
  on_failure: → E01

S07: Confirm separation criteria.
  action: Per the scope table constraints:
          - Distribution Planner: confirm agent_id ≠ Distribution Agent
          - Distribution Agent: confirm agent_id ≠ Distribution Planner
          - DoD Agent (Distribution): confirm agent_id ≠ Distribution Verifier
          - Distribution Verifier: confirm agent_id ≠ DoD Agent
          Per DLMS-2026-0014 R01.
  actor:  sysadmin:dlm-sysadmin
  reads:  All Tier 9 agent_ids from orchestrator's active registry
  writes: separation confirmation note (internal)
  on_failure: → D03

S08: Register with Distribution Orchestrator.
  action: Dispatch registration event to agent:distribution-orchestrator:
          agent_id, role, stage = "distribution", onboarding_status =
          "complete". Receive queue assignment.
  actor:  Onboarding agent; agent:distribution-orchestrator
  reads:  Orchestrator endpoint from context package
  writes: Queue assignment in orchestrator's active roster
  on_failure: → E04

S09: Emit onboarding-complete audit event.
  action: Write onboarding-complete event per DLMS-2026-0015. Required
          fields: agent_id, role, stage = "distribution", tier = 9,
          onboarding_procedure_ref = "DLMS-2026-0088",
          outcome [success | failure], queue_assignment (or null if
          deferred), timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015
  writes: audit-trail.log (onboarding-complete event)
  on_failure: → E03

## DECISION_POINTS

D01: If P01 fails → halt. Notify orchestrator and sysadmin:dlm-sysadmin.

D02: If S02 fails → halt. Notify orchestrator for context package correction.

D03: If S07 fails (separation violated) → halt. Escalate to
     sysadmin:dlm-sysadmin.

## OUTPUTS

| Artefact | Produced by step | Written to | Consumed by |
|---|---|---|---|
| Operational Distribution agent with validated context | S02–S06 | internal state | Distribution Orchestrator; pipeline |
| Queue assignment entry | S08 | Orchestrator's active roster | Distribution Orchestrator |
| onboarding-start audit event | S04 | audit-trail.log | Audit Trail Agent |
| onboarding-complete audit event | S09 | audit-trail.log | Audit Trail Agent; orchestrator |

## ERROR_CONDITIONS

E01: Context package unavailable or incomplete.
  likely_cause: DLMS-2026-0053/0054 templates not yet authored;
                DLMS-2026-0077 not in effect.
  resolution:   Defer; escalate to sysadmin:dlm-sysadmin.

E02: Artefact format validation fails.
  likely_cause: impact_assessment_status field absent from Distribution
                Planner schema; delivery status enumeration not defined.
  resolution:   Halt. Log. Escalate to sysadmin:dlm-sysadmin.

E03: Audit trail unreachable.
  resolution:   Halt. Alert sysadmin:dlm-sysadmin. Retry after reachable.

E04: Orchestrator rejects queue registration.
  resolution:   Halt. Notify sysadmin:dlm-sysadmin.
