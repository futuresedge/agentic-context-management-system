## SUMMARY
This procedure governs the onboarding of any one of the three Cross-Cutting
Services (Tier 12) agents — the Audit Trail Agent, the Knowledge Base Agent,
and the Document Relationship Agent — which operate system-wide and are not
scoped to any single stage. The Audit Trail Agent presents a bootstrapping
constraint: it cannot audit its own onboarding because the audit trail does
not exist until the agent is active. This is resolved by a manual bootstrap
record written by sysadmin:dlm-sysadmin outside the automated trail. All
subsequent audit events are then written by the Audit Trail Agent itself.

## SCOPE

Applies to:
- All three Cross-Cutting Services (Tier 12) agents listed below
- sysadmin:dlm-sysadmin as procedure owner
- Audit Trail Agent as recipient of post-bootstrap onboarding events (for
  Knowledge Base Agent and Document Relationship Agent only)

The three Cross-Cutting Services agents:

| Agent | Designated output | Separation constraint | Special constraint |
|---|---|---|---|
| Audit Trail Agent | audit-trail.log (all agent events) | Must not audit its own onboarding (bootstrap exception — see S04-alt) | Must be distinct instance from any agent it audits |
| Knowledge Base Agent | knowledge-base.md (curated entries) | None beyond universal | Knowledge base entries must reference their originating learnings artefact |
| Document Relationship Agent | dependency-graph.md (system-wide dep map) | None beyond universal | Writes only to dependency-graph; reads only metadata and dependency declarations |

Excludes:
- Any agent outside Tier 12

Executed by:
- Onboarding agent (self-check, where possible): S02, S03, S05
- sysadmin:dlm-sysadmin: S04-alt (Audit Trail Agent bootstrap), S01, S06, S07, S08

## PREREQUISITES

P01: DLMS-2026-0014, DLMS-2026-0015, DLMS-2026-0016, DLMS-2026-0041
     (Definition of Done Policy), DLMS-2026-0020 (Document Dependency
     Policy — required for Document Relationship Agent), DLMS-2026-0023
     (TMPL-audit-event-001 — required for Audit Trail Agent), and
     DLMS-2026-0063 (Knowledge Base Contribution Policy — required for
     Knowledge Base Agent) are in effect.
     Verified by: sysadmin:dlm-sysadmin. Failure → D01.

P02: This agent's designated context package includes: (a) role identifier
     and designated output schema; (b) for Audit Trail Agent: DLMS-2026-0023
     (audit event schema) and DLMS-2026-0015 (audit trail format rules);
     (c) for Knowledge Base Agent: DLMS-2026-0063 (contribution criteria);
     (d) for Document Relationship Agent: the dependency graph schema and
     DLMS-2026-0020.
     Verified by: sysadmin:dlm-sysadmin. Failure → E01.

P03: For Knowledge Base Agent and Document Relationship Agent: Audit Trail
     Agent is reachable. Failure → E03.
     For Audit Trail Agent: this prerequisite does not apply — see S04-alt.

## STEPS

S01: Retrieve context package.
  action: Retrieve this agent's context package and confirm it satisfies
          P02.
  actor:  sysadmin:dlm-sysadmin
  reads:  designated context package
  writes: (none — verification only)
  on_failure: → E01

S02: Validate context boundary.
  action: Confirm READS is limited to the resources defined for each role:
          - Audit Trail Agent: READS = inbound audit event stream only;
            WRITES = audit-trail.log only; NEVER = document body content;
            policy bodies; artefact content.
          - Knowledge Base Agent: READS = learnings artefacts (from Stage
            Verifiers); WRITES = knowledge-base.md only; NEVER = document
            body content or policies other than DLMS-2026-0063.
          - Document Relationship Agent: READS = document metadata
            (doc_id, dependencies field) only; WRITES = dependency-graph.md
            only; NEVER = document body content.
  actor:  Onboarding agent; verified by sysadmin:dlm-sysadmin
  reads:  context boundary specification
  writes: boundary validation result (internal)
  on_failure: → D02

S03: Load governing policies into context.
  action: Load: DLMS-2026-0014, DLMS-2026-0015, DLMS-2026-0016,
          DLMS-2026-0041. Additionally:
          - Audit Trail Agent: load DLMS-2026-0023
          - Knowledge Base Agent: load DLMS-2026-0063
          - Document Relationship Agent: load DLMS-2026-0020
  actor:  Onboarding agent
  reads:  policy references from context package
  writes: active policy context (internal)
  on_failure: → E01

S04: Emit onboarding-start audit event — standard path (non-Audit Trail agents).
  action: For Knowledge Base Agent and Document Relationship Agent: write
          onboarding-start event per DLMS-2026-0015. Required fields:
          agent_id, role, tier = 12,
          onboarding_procedure_ref = "DLMS-2026-0091", timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015; DLMS-2026-0023
  writes: audit-trail.log (onboarding-start event)
  on_failure: → E03

S04-alt: Audit Trail Agent bootstrap record (Audit Trail Agent only).
  action: The Audit Trail Agent cannot write its own onboarding-start event
          because the audit trail does not exist until this agent is active.
          sysadmin:dlm-sysadmin manually creates a bootstrap audit record
          in audit-trail.log using DLMS-2026-0023 fields:
            agent_id: agent:audit-trail-agent
            tier: 12
            onboarding_procedure_ref: DLMS-2026-0091
            event_type: bootstrap-onboarding-start
            recorded_by: sysadmin:dlm-sysadmin
            timestamp: (ISO 8601)
          This bootstrap record is the one exception in the system where
          an audit event is written by a human rather than an agent. It
          must be preserved permanently (retention_class: RC-permanent).
  actor:  sysadmin:dlm-sysadmin
  reads:  DLMS-2026-0023
  writes: audit-trail.log (bootstrap-onboarding-start record)
  on_failure: → E03

S05: Confirm artefact format.
  action: Generate a zero-content test artefact against designated schema.
          - Audit Trail Agent: confirm it can write a valid audit event
            (using DLMS-2026-0023 fields) with outcome: test-event,
            then immediately discard. Confirm it does not write to any
            resource other than audit-trail.log.
          - Knowledge Base Agent: test entry must include source_learnings_ref
            (pointing to an originating learnings artefact),
            knowledge_type, and contribution_date fields.
          - Document Relationship Agent: test dependency-graph entry must
            include source_doc_id, target_doc_id, rel (relationship type),
            and assert_by fields.
  actor:  Onboarding agent
  reads:  designated output schema
  writes: test artefact (internal, discarded)
  on_failure: → E02

S06: Confirm separation criterion (Audit Trail Agent).
  action: For Audit Trail Agent: confirm that no other active agent
          (from any tier) shares the same agent_id as the Audit Trail Agent.
          The Audit Trail Agent must be a dedicated, singleton instance.
          For Knowledge Base Agent and Document Relationship Agent: confirm
          agent_ids are distinct from all other Tier 12 agents.
  actor:  sysadmin:dlm-sysadmin
  reads:  System-wide agent registry
  writes: separation confirmation note (internal)
  on_failure: → D03

S07: Confirm artefact exclusivity.
  action: For each Tier 12 agent, confirm no other active agent (in any
          tier) is assigned the same WRITES target:
          - audit-trail.log: no other agent may write here (S04-alt
            bootstrap record by sysadmin is the only exception, and it
            is a one-time initialisation event, not a permanent write
            assignment).
          - knowledge-base.md: only the Knowledge Base Agent writes here
          - dependency-graph.md: both the Document Relationship Agent
            (system-wide map) and the Tier 7 Dependency Index Updater
            (per-document entries) write to this file. Confirm the two
            agents hold distinct agent_ids and write distinct sections.
  actor:  sysadmin:dlm-sysadmin
  reads:  System-wide agent registry and write-target assignments
  writes: exclusivity confirmation note (internal)
  on_failure: → D04

S08: Register with Cross-Cutting Services roster.
  action: Register agent_id and role in the Cross-Cutting Services active
          roster maintained by sysadmin:dlm-sysadmin.
  actor:  sysadmin:dlm-sysadmin
  reads:  Cross-Cutting Services active roster
  writes: Registration entry
  on_failure: → E04

S09: Emit onboarding-complete audit event.
  action: For Knowledge Base Agent and Document Relationship Agent: write
          onboarding-complete event per DLMS-2026-0015.
          For Audit Trail Agent: sysadmin:dlm-sysadmin writes a bootstrap-
          onboarding-complete manual record in audit-trail.log using the
          same bootstrap record format as S04-alt. After this point, all
          further audit events (including any re-onboarding) are written
          by the Audit Trail Agent itself.
          Required fields (both paths): agent_id, role, tier = 12,
          onboarding_procedure_ref = "DLMS-2026-0091",
          outcome [success | failure], timestamp (ISO 8601).
  actor:  Onboarding agent (non-Audit Trail agents); sysadmin:dlm-sysadmin
          (Audit Trail Agent)
  reads:  DLMS-2026-0015; DLMS-2026-0023
  writes: audit-trail.log (onboarding-complete or bootstrap-onboarding-
          complete event)
  on_failure: → E03

## DECISION_POINTS

D01: If P01 fails → halt. Notify sysadmin:dlm-sysadmin.

D02: If S02 fails → halt. Notify sysadmin:dlm-sysadmin for context package
     correction.

D03: If S06 fails (agent_id conflict) → halt. Escalate to
     sysadmin:dlm-sysadmin. Assign a new unique agent_id.

D04: If S07 fails (write-target conflict outside the permitted shared
     dependency-graph exception) → halt. Escalate to sysadmin:dlm-sysadmin.

## OUTPUTS

| Artefact | Produced by step | Written to | Consumed by |
|---|---|---|---|
| Operational Cross-Cutting Services agent | S02–S05 | internal state | All tiers that use the service |
| Registration entry | S08 | Cross-Cutting Services roster | sysadmin:dlm-sysadmin |
| bootstrap-onboarding-start record (Audit Trail Agent only) | S04-alt | audit-trail.log | sysadmin:dlm-sysadmin; all auditing consumers |
| onboarding-start audit event (non-Audit Trail agents) | S04 | audit-trail.log | Audit Trail Agent |
| onboarding-complete / bootstrap-onboarding-complete | S09 | audit-trail.log | Audit Trail Agent; sysadmin:dlm-sysadmin |

## ERROR_CONDITIONS

E01: Context package unavailable or incomplete.
  likely_cause: DLMS-2026-0023, DLMS-2026-0063, or DLMS-2026-0020 not
                yet authored.
  resolution:   Defer; escalate to sysadmin:dlm-sysadmin.

E02: Artefact format validation fails.
  likely_cause: source_learnings_ref missing from Knowledge Base test entry;
                audit event schema fields malformed; dependency graph entry
                missing rel field.
  resolution:   Halt. Log. Escalate to sysadmin:dlm-sysadmin.

E03: Audit trail unreachable or bootstrap record cannot be written.
  resolution:   Halt. Alert sysadmin:dlm-sysadmin. For Audit Trail Agent
                S04-alt: retry bootstrap record manually. Do not mark
                onboarding complete until S04-alt and S09 bootstrap
                records are confirmed written.

E04: Roster registration fails.
  resolution:   Halt. Notify sysadmin:dlm-sysadmin.
