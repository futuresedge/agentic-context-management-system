## SUMMARY

This procedure governs the Indexing and Classification stage of the DLMS
document lifecycle: from Approval Gate handoff through context curation,
metadata extraction, classification, taxonomy validation, parallel index
updates, independent verification, and handoff to the Storage stage. The
Indexing stage has no dedicated DoD template; quality is governed by
DLMS-2026-0018 (Metadata Standard Policy) and DLMS-2026-0019 (Taxonomy
Policy) rather than a DoD checklist. The primary outputs are metadata-final.md
(canonical metadata record), entries in all four index structures, and
indexing-verification.md (stage gate artefact).

## SCOPE

Agents active in this stage:

| Pipeline Position | Agent | Output Artefact |
|---|---|---|
| P01 | Indexing-Classification Orchestrator | (coordination only) |
| P02 | Context Curator (Indexing) | indexing-context.md |
| P03 | Metadata Extractor | metadata-raw.md |
| P04 | Classification Agent | metadata-final.md |
| P05 | Taxonomy Validator | taxonomy-validation.md |
| P06–P09 | Index Updaters ×4 (PARALLEL) | master-index entry, index-by-type entry, index-by-tag entry, dependency-graph entry |
| P10 | Indexing Verifier | indexing-verification.md, indexing-learnings.md |
| P11 | Indexing Metrics Agent | indexing-metrics.md |

Note: P06–P09 (Index Updaters) activate in PARALLEL after taxonomy
validation passes. All four updaters must confirm write completion before
the stage advances.

Note on quality gate: this stage has no dedicated DoD template. The
Taxonomy Validator (P05) serves the equivalent role of a quality gate;
its pass outcome is the prerequisite for index update fan-out.

Excludes:
- Tier 2 Governance Layer agents that maintain the master index structures
  (Master Index Agent, Type Index Agent, Tag Index Agent, Dependency Graph
  Agent). The Tier 7 Index Updaters here append per-document entries; they
  do not modify the index structure itself.
- Approval Gate, Review, Creation, Storage, Distribution, and Archival
  stage agents

Executed by:
- agent:indexing-classification-orchestrator: pipeline coordination,
  parallel fan-out management (P06–P09), CI dispatch, and handoff
  (S01, S08, S10, S11)
- Stage agents: own designated pipeline steps (S02–S07, S09)
- sysadmin:dlm-sysadmin: escalation recipient for E02, E03, E05

## PREREQUISITES

P01: All Indexing stage agents are onboarded per DLMS-2026-0086 (Indexing
     and Classification Stage Agent Onboarding Procedure). If any agent
     instance is not onboarded, defer pipeline activation until onboarding
     is complete. Failure → E02.

P02: DLMS-2026-0014 (Verification Independence Policy),
     DLMS-2026-0015 (Audit Trail Policy), DLMS-2026-0016 (Agent Context
     Boundary Policy), DLMS-2026-0018 (Metadata Standard Policy),
     DLMS-2026-0019 (Taxonomy Policy), DLMS-2026-0021 (Taxonomy /
     Controlled Vocabulary), DLMS-2026-0036 (Document Classification
     Policy), DLMS-2026-0041 (Definition of Done Policy), and
     DLMS-2026-0043 (Quality Threshold Policy) are in effect.
     Verified by: agent:indexing-classification-orchestrator. Failure → E02.

P03: DLMS-2026-0021 (Taxonomy / Controlled Vocabulary) is current and
     accessible for Classification Agent and Taxonomy Validator. Failure
     → E02.
     Note: there is no dedicated DoD template for this stage. Taxonomy
     validation (P05/S05) serves as the equivalent quality gate.

P04: Audit Trail Agent is reachable and accepting log entries. Failure → E03.

P05: Approval Gate prerequisite artefacts are present: approval-
     verification.md (outcome = pass) and approval-status.md (decision =
     approved). If either artefact is absent or does not satisfy the
     required values, reject intake and halt. Failure → E05.

## STEPS

S01: Receive handoff from Approval Gate and validate prerequisites.
  action: Indexing-Classification Orchestrator receives the Indexing intake
          artefacts. Confirm P05: approval-verification.md outcome = pass
          and approval-status.md decision = approved. Log receipt to Audit
          Trail Agent.
  actor:  agent:indexing-classification-orchestrator
  reads:  approval-verification.md; approval-status.md
  writes: audit log entry
  on_failure: → E05

S02: Context Curator (Indexing) produces indexing context package.
  action: Context Curator (Indexing) reads designated context sources for
          this indexing run and produces indexing-context.md. READS is
          limited to designated context sources per DLMS-2026-0016.
          Context scope includes the document's doc_id, doc_type, status,
          and governing metadata/taxonomy policy references; does not
          include document body content.
  actor:  agent:context-curator-indexing
  reads:  designated context sources (doc_id, doc_type, approval-status.md
          summary, governing policies list — scoped per DLMS-2026-0016)
  writes: indexing-context.md
  on_failure: → E02

S03: Metadata Extractor produces raw metadata record.
  action: Metadata Extractor reads the approved document artefact (final
          draft) and extracts all metadata fields per DLMS-2026-0031
          (TMPL-metadata-raw-001). Produces metadata-raw.md containing
          extracted values prior to classification and tag validation.
  actor:  agent:metadata-extractor
  reads:  approved document artefact; DLMS-2026-0031
  writes: metadata-raw.md
  on_failure: → E02

S04: Classification Agent produces finalised metadata record.
  action: Classification Agent reads metadata-raw.md and DLMS-2026-0021
          (Taxonomy / Controlled Vocabulary). Maps extracted metadata fields
          to controlled vocabulary terms. Applies DLMS-2026-0036 (Document
          Classification Policy) classification rules. Produces
          metadata-final.md per DLMS-2026-0032 (TMPL-metadata-final-001).
  actor:  agent:classification-agent
  reads:  metadata-raw.md; DLMS-2026-0021; DLMS-2026-0036
  writes: metadata-final.md
  on_failure: → E02

S05: Taxonomy Validator evaluates classification.
  action: Taxonomy Validator reads metadata-final.md and DLMS-2026-0021
          (Taxonomy / Controlled Vocabulary). Independently validates that
          all classification terms in metadata-final.md are present in the
          controlled vocabulary and that required fields per DLMS-2026-0018
          (Metadata Standard Policy) are populated. Produces
          taxonomy-validation.md (outcome: pass | fail).
          Taxonomy Validator MUST NOT be the Classification Agent
          (DLMS-2026-0014 R01 independence requirement).
  actor:  agent:taxonomy-validator
  reads:  metadata-final.md; DLMS-2026-0021; DLMS-2026-0018
  writes: taxonomy-validation.md
  on_failure: → E02
  [D01] taxonomy-validation outcome = fail → return to S04 (Classification
        Agent revision). Note: no bounded revision counter applies here;
        the loop continues until taxonomy compliance is achieved or E02
        is triggered by persistent agent failure.
  [D01] taxonomy-validation outcome = pass → S06 (parallel index updates).

S06–S09: Index Updaters activate in PARALLEL.
  action: Indexing-Classification Orchestrator initiates concurrent
          activation of all four Index Updaters. Each updater reads
          metadata-final.md and appends or updates the per-document entry
          in its designated index structure, using DLMS-2026-0033
          (TMPL-index-entry-001) as output schema. Updaters write to
          separate index targets; no two updaters write to the same
          structure in the same pipeline pass.

  S06 — Master Index Updater:
    actor:  agent:master-index-updater
    reads:  metadata-final.md; DLMS-2026-0033
    writes: master-index entry for this doc_id

  S07 — Type Index Updater:
    actor:  agent:type-index-updater
    reads:  metadata-final.md; DLMS-2026-0033
    writes: index-by-type entry for this doc_id

  S08 — Tag Index Updater:
    actor:  agent:tag-index-updater
    reads:  metadata-final.md; DLMS-2026-0033
    writes: index-by-tag entry for this doc_id

  S09 — Dependency Index Updater:
    actor:  agent:dependency-index-updater
    reads:  metadata-final.md; DLMS-2026-0033
    writes: dependency-graph entry for this doc_id

  on_failure (any updater): → E02
  [D02] All four index update confirmations received → S10.
        Any updater failure → E02.

S10: Indexing Verifier evaluates stage completion.
  action: Indexing Verifier independently evaluates whether all four index
          updates were completed successfully and whether metadata-final.md
          satisfies DLMS-2026-0018 (Metadata Standard Policy) requirements.
          Reads metadata-final.md, taxonomy-validation.md, and index update
          confirmation records. Produces indexing-verification.md (outcome:
          pass | fail) per DLMS-2026-0030 (TMPL-verification-001) and
          indexing-learnings.md per DLMS-2026-0034 (TMPL-learnings-001).
          Indexing Verifier MUST NOT be the Classification Agent or Taxonomy
          Validator (DLMS-2026-0014 R01).
  actor:  agent:indexing-verifier
  reads:  metadata-final.md; taxonomy-validation.md; index update
          confirmation records (S06–S09)
  writes: indexing-verification.md; indexing-learnings.md
  on_failure: → E02
  [D03] indexing-verification outcome = fail → E01.

S11: Indexing Metrics Agent records stage performance.
  action: Indexing Metrics Agent reads indexing-verification.md,
          taxonomy-validation.md, and audit trail logs for this pipeline
          run. Records: elapsed stage time, classification revision count
          (taxonomy validation loop iterations), index update confirmation
          status per updater, and overall stage outcome. Produces
          indexing-metrics.md.
  actor:  agent:indexing-metrics
  reads:  indexing-verification.md; taxonomy-validation.md; audit trail
          log entries for this pipeline run
  writes: indexing-metrics.md
  on_failure: → E02

S12: CI dispatch.
  action: Dispatch indexing-metrics.md and indexing-learnings.md to the CI
          quality monitor queue. Dispatch indexing-verification.md to CI
          monitor scope. CI feedback is consumed by Tier 13 per
          DLMS-2026-0076 (CI Cycle Policy).
  actor:  agent:indexing-classification-orchestrator
  reads:  indexing-metrics.md; indexing-learnings.md;
          indexing-verification.md
  writes: CI queue entries (external to this stage's write scope)
  on_failure: log warning and continue (non-blocking)

S13: Handoff to Storage stage.
  action: Pass indexing-verification.md, metadata-final.md, and the
          approved document artefact to the Storage stage intake queue.
          Log handoff to Audit Trail Agent. Storage Stage SOP
          (DLMS-2026-0098) is triggered on receipt.
  actor:  agent:indexing-classification-orchestrator
  reads:  indexing-verification.md (confirm outcome = pass before handoff)
  writes: handoff artefact to Storage queue; audit log entry
  on_failure: → E02

## DECISION_POINTS

D01: Taxonomy Validator returns fail (at S05).
  condition: taxonomy-validation.md outcome = fail.
  action:    Return to S04 (Classification Agent). Log iteration to Audit
             Trail Agent. If persistent failure (>3 iterations without
             resolution) → E02 with escalation to agent:indexing-
             classification-orchestrator.

D02: Index update fan-out incomplete (at S06–S09).
  condition: One or more Index Updaters fail to confirm write completion.
  action:    → E02. Halt pipeline. Log which updater(s) failed.

D03: Indexing Verifier returns fail (at S10).
  condition: indexing-verification.md outcome = fail.
  action:    → E01. Do not advance to S11 or S12. Halt pipeline.

## OUTPUTS

| Artefact | Produced by | Purpose |
|---|---|---|
| indexing-context.md | Context Curator (Indexing) | Scoped context for this indexing run |
| metadata-raw.md | Metadata Extractor | Extracted pre-classification metadata |
| metadata-final.md | Classification Agent | Canonical metadata record with controlled vocabulary terms |
| taxonomy-validation.md | Taxonomy Validator | Classification compliance check result (quality gate) |
| master-index entry | Master Index Updater | Document entry in the master index |
| index-by-type entry | Type Index Updater | Document entry in the type-organised index |
| index-by-tag entry | Tag Index Updater | Document entry in the tag-organised index |
| dependency-graph entry | Dependency Index Updater | Document's dependency relationships in the dependency graph |
| indexing-verification.md | Indexing Verifier | Independent stage evaluation (stage gate artefact) |
| indexing-learnings.md | Indexing Verifier | Lessons and observations for CI feedback |
| indexing-metrics.md | Indexing Metrics Agent | Stage performance record |

## ERROR_CONDITIONS

E01: Stage verification failure.
  condition: Indexing Verifier returns outcome = fail (D03).
  action:    Halt pipeline. Log to Audit Trail Agent with failure reasons
             from indexing-verification.md. Escalate to
             sysadmin:dlm-sysadmin. Document does not advance to Storage
             stage until indexing is remediated.

E02: Agent unavailable or pipeline step failure.
  condition: Any stage agent fails to produce its designated output, or an
             Index Updater fails write confirmation.
  action:    Halt pipeline at failure point. Log to Audit Trail Agent
             including step identifier and agent ID.
             agent:indexing-classification-orchestrator escalates to
             sysadmin:dlm-sysadmin.

E03: Audit Trail Agent unreachable.
  condition: Audit Trail Agent does not respond at S01 or any subsequent
             audit log step.
  action:    Halt pipeline immediately. Do not proceed without audit
             capability (DLMS-2026-0015 R01). Escalate to
             sysadmin:dlm-sysadmin.

E05: Missing Approval Gate prerequisite.
  condition: approval-verification.md absent or outcome ≠ pass; or
             approval-status.md absent or decision ≠ approved.
  action:    Reject intake. Log to Audit Trail Agent identifying the absent
             or non-compliant artefact. Do not begin Indexing stage
             processing under any circumstances.

## REVIEW_SCHEDULE

This procedure is reviewed whenever DLMS-2026-0021 (Taxonomy / Controlled
Vocabulary) is updated with new terms, or when DLMS-2026-0018 (Metadata
Standard Policy) changes. Minimum annual review conducted by
agent:indexing-classification-orchestrator and sysadmin:dlm-sysadmin.
Any change to the parallel index updater set requires a version increment
per DLMS-2026-0038.
