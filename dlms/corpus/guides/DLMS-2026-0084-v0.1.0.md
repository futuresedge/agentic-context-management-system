## SUMMARY
This procedure governs the onboarding of any one of the seven Creation Stage
agent instances — the Tier 4 agents that collectively take an intake request
through context curation, problem analysis, authoring, template validation,
and creation verification to produce a compliant document draft. The
procedure_owner is the Creation Orchestrator; new agents register with it
upon completion. The primary outputs are an operational agent with a validated
context boundary and a queue assignment from the Creation Orchestrator.

## SCOPE

Applies to:
- All seven Creation Stage (Tier 4) agents listed in the table below
- agent:creation-orchestrator as procedure owner and queue assignment authority
- sysadmin:dlm-sysadmin for separation verification (S07) and escalation
- Audit Trail Agent as recipient of onboarding audit events

The seven Creation Stage agents, their designated outputs, and unique
separation constraints:

| Agent | Designated output | Separation constraint |
|---|---|---|
| Context Curator (Creation) | creation-context.md | None beyond universal |
| Problem Analysis Agent | problem-analysis.md | None beyond universal |
| DoD Agent (Creation) | creation-dod.md | Must not be same instance as Creation Verifier |
| Document Author | draft-v0.1-agent.md | Must not be same instance as Creation Verifier |
| Template Validator | template-compliance.md | Must not be same instance as Document Author |
| Creation Verifier | creation-verification.md + creation-learnings.md | Must not be same instance as DoD Agent or Document Author |
| Creation Metrics Agent | creation-metrics.md | None beyond universal |

Excludes:
- Creation Orchestrator onboarding (covered by DLMS-2026-0083)
- Any agent outside Tier 4
- Ongoing stage operation after onboarding is complete

Executed by:
- Onboarding agent (self-check steps): S02, S03, S04, S05, S08, S09
- agent:creation-orchestrator: queue assignment (S08)
- sysadmin:dlm-sysadmin: separation verification (S07)

## PREREQUISITES

P01: DLMS-2026-0014, DLMS-2026-0015, and DLMS-2026-0016 are in effect.
     Additionally: DLMS-2026-0035 (Document Creation Policy),
     DLMS-2026-0041 (Definition of Done Policy), DLMS-2026-0042 (Review
     Standards Policy), DLMS-2026-0043 (Quality Threshold Policy), and
     DLMS-2026-0057 (Creation Stage SLA) are in effect.
     Verified by: agent:creation-orchestrator. Failure → D01.

P02: This agent's designated context package exists and contains: (a) this
     agent's role identifier and designated output schema; (b) the Creation
     Stage DoD template reference (DLMS-2026-0024); (c) artefact template
     references relevant to this agent's role (DLMS-2026-0046 for Context
     Curator, DLMS-2026-0047 for Problem Analysis Agent; creation-dod schema
     for DoD Agent); (d) references to DLMS-2026-0015 and DLMS-2026-0016.
     Verified by: agent:creation-orchestrator. Failure → E01.

P03: Audit Trail Agent is reachable and accepting events. Failure → E03.

P04: agent:creation-orchestrator is active and accepting queue registration
     requests (required for S08). Failure → defer S08; note as pending.

## STEPS

S01: Retrieve context package.
  action: Retrieve this agent's designated context package and confirm it
          satisfies P02. Note the agent's role identifier and designated
          output artefact schema.
  actor:  agent:creation-orchestrator (on behalf of onboarding agent)
  reads:  designated context package
  writes: (none — verification only)
  on_failure: → E01

S02: Validate context boundary.
  action: Confirm the READS list is limited to: (a) this agent's designated
          input artefact(s) for its role; (b) the relevant artefact template
          schema(s) for this agent's output; (c) the governing policies from
          P01 relevant to this role; (d) audit event schema (DLMS-2026-0015).
          Confirm the NEVER list excludes: artefacts produced by this agent's
          downstream consumers; artefacts from other stages; any document
          whose creation this agent is tasked to produce. Per DLMS-2026-0016.
  actor:  Onboarding agent (self-check); verified by
          agent:creation-orchestrator
  reads:  context boundary specification within context package
  writes: boundary validation result (internal)
  on_failure: → D02

S03: Load governing policies into context.
  action: Load into active context: DLMS-2026-0014, DLMS-2026-0015,
          DLMS-2026-0016, DLMS-2026-0035, DLMS-2026-0041, DLMS-2026-0042,
          DLMS-2026-0043, DLMS-2026-0057, and the artefact template schemas
          relevant to this agent's role.
  actor:  Onboarding agent
  reads:  policy and template references from context package
  writes: active policy context (internal)
  on_failure: → E01

S04: Emit onboarding-start audit event.
  action: Write onboarding-start event per DLMS-2026-0015. Required fields:
          agent_id, role (this agent's role identifier), stage = "creation",
          tier = 4, onboarding_procedure_ref = "DLMS-2026-0084",
          timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015 (audit event schema)
  writes: audit-trail.log (onboarding-start event)
  on_failure: → E03

S05: Confirm artefact format.
  action: Generate a zero-content test artefact against this agent's
          designated output schema and confirm it passes format validation.
          The test artefact is not persisted. For the Creation Verifier:
          additionally confirm it can parse a known-passing creation-dod
          artefact and emit a creation-verification artefact with
          outcome: pass.
  actor:  Onboarding agent
  reads:  designated output schema from context package
  writes: test artefact (internal, discarded)
  on_failure: → E02

S06: Confirm SLA reference.
  action: Confirm this agent's context package includes a valid reference to
          DLMS-2026-0057 (Creation Stage SLA) and that the relevant SLA
          metric targets for this agent's role are loaded and accessible.
          The DoD Agent and Creation Verifier must be able to cite specific
          SLA metric identifiers; other agents confirm the SLA is present
          in context.
  actor:  Onboarding agent
  reads:  DLMS-2026-0057 from context
  writes: SLA reference confirmation (internal)
  on_failure: → E01 (SLA not loadable from context package)

S07: Confirm separation criterion.
  action: Per the separation constraints in the scope table, verify that
          this agent's agent_id is distinct from all agents it must not
          share an instance with. Specifically:
          - DoD Agent: agent_id ≠ Creation Verifier's agent_id
          - Document Author: agent_id ≠ Creation Verifier's agent_id and
            ≠ Template Validator's agent_id
          - Template Validator: agent_id ≠ Document Author's agent_id
          - Creation Verifier: agent_id ≠ DoD Agent's agent_id and
            ≠ Document Author's agent_id
          For agents with no constraint beyond universal: verify only that
          this agent_id ≠ its own downstream Verifier.
          Per DLMS-2026-0014 R01.
  actor:  sysadmin:dlm-sysadmin
  reads:  agent_ids of constrained peers from creation orchestrator's
          active agent registry
  writes: separation confirmation note (internal)
  on_failure: → D03

S08: Register with Creation Orchestrator and receive queue assignment.
  action: Dispatch a registration event to agent:creation-orchestrator
          containing: agent_id, role, stage = "creation", onboarding_status
          = "complete". Receive and record the queue assignment (slot within
          the creation pipeline) from the orchestrator.
  actor:  Onboarding agent; agent:creation-orchestrator (queue assignment)
  reads:  agent:creation-orchestrator endpoint from context package
  writes: Queue assignment entry in creation orchestrator's active agent
          roster
  on_failure: → E04

S09: Emit onboarding-complete audit event.
  action: Write onboarding-complete event per DLMS-2026-0015. Required
          fields: agent_id, role, stage = "creation", tier = 4,
          onboarding_procedure_ref = "DLMS-2026-0084",
          outcome [success | failure], queue_assignment (from S08 or null
          if deferred), timestamp (ISO 8601).
  actor:  Onboarding agent
  reads:  DLMS-2026-0015 (audit event schema)
  writes: audit-trail.log (onboarding-complete event)
  on_failure: → E03

## DECISION_POINTS

D01: If P01 fails (any required policy not in effect) → halt. Notify
     agent:creation-orchestrator and sysadmin:dlm-sysadmin. Do not proceed.

D02: If S02 fails (context boundary out of spec) → halt. Do not initiate
     the agent. Notify agent:creation-orchestrator for context package
     correction before re-attempting from S01.

D03: If S07 fails (separation constraint violated for this agent's role) →
     halt. Escalate to sysadmin:dlm-sysadmin. Separate agent instances must
     be provisioned before either constrained pair can be onboarded.

## OUTPUTS

| Artefact | Produced by step | Written to | Consumed by |
|---|---|---|---|
| Operational Creation Stage agent with validated context | S02–S06 | internal state | Creation Orchestrator; stage pipeline |
| Queue assignment entry in creation orchestrator | S08 | Creation Orchestrator's active roster | Creation Orchestrator |
| onboarding-start audit event | S04 | audit-trail.log | Audit Trail Agent; Agent Behaviour Analyst (CI) |
| onboarding-complete audit event | S09 | audit-trail.log | Audit Trail Agent; agent:creation-orchestrator |

## ERROR_CONDITIONS

E01: Context package unavailable or missing required references.
  condition:    Context package unreachable, or required policy/template
                references absent for this agent's role.
  likely_cause: Artefact templates (DLMS-2026-0046/0047) or SLA policy
                not yet authored; incorrect context package path.
  resolution:   agent:creation-orchestrator defers onboarding until all
                prerequisites are available; escalate to
                sysadmin:dlm-sysadmin if unresolvable.

E02: Artefact format validation fails.
  condition:    Agent cannot produce a conformant test artefact in S05.
  likely_cause: Output schema not loaded; agent capability misconfigured.
  resolution:   Halt. Log failure. Escalate to sysadmin:dlm-sysadmin.

E03: Audit trail unreachable.
  condition:    S04 or S09 cannot write to audit-trail.log.
  likely_cause: Audit Trail Agent offline; message bus fault.
  resolution:   Halt. Alert sysadmin:dlm-sysadmin. Do not mark complete.
                Retry only after both events are written.

E04: Creation Orchestrator rejects queue registration.
  condition:    agent:creation-orchestrator returns rejection or
                non-acknowledgement in S08.
  likely_cause: Orchestrator not active; role slot already filled by a
                duplicate instance; orchestrator version mismatch.
  resolution:   Halt. Notify sysadmin:dlm-sysadmin. Do not accept
                documents until a successful registration is confirmed.
