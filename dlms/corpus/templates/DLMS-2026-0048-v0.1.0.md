## SUMMARY
This template defines the schema of a review perspective artefact produced by
a single Perspective Reviewer Agent applying one cognitive lens during the
review stage. One perspective artefact is produced per lens per document
review session; all perspectives are consumed by the Review Synthesizer to
produce the review synthesis per DLMS-2026-0017.

## TARGET_DOC_TYPE
review-perspective

## PURPOSE
The review perspective is a single-lens review record produced by a named
Perspective Reviewer Agent as part of the multi-perspective review defined
in Multi-Perspective Review Policy (DLMS-2026-0017). Each Perspective
Reviewer receives the review context package as its sole input, applies one
named lens (e.g. accuracy, completeness, agent-readability, or structure),
and produces one perspective artefact. A review session produces typically
four perspective artefacts — one per reviewer — which the Review Synthesizer
then reads in aggregate. Perspective artefacts are not consumed directly by
the Approval Gate Agent; they are consumed only by the Review Synthesizer.
Each Perspective Reviewer must be a distinct agent identity, and none may
have participated in authoring the document under review.

## SCHEMA

### Header_Fields

FIELD_01:
  name:        perspective_id
  type:        string
  required:    true
  nullable:    false
  format:      RPERSPECTIVE-{doc_id}-{version}-{lens}-{NNNN}
  example:     RPERSPECTIVE-DLMS-2026-0030-0.1.0-accuracy-0001
  description: Unique identifier for this perspective artefact. NNNN is a
               zero-padded sequential integer. Immutable after assignment.

FIELD_02:
  name:        doc_id
  type:        string
  required:    true
  nullable:    false
  description: The DLMS doc_id of the document being reviewed.

FIELD_03:
  name:        doc_version
  type:        string
  required:    true
  nullable:    false
  format:      MAJOR.MINOR.PATCH
  description: The version of the document being reviewed. Perspective
               records are version-scoped; a perspective for v0.1.0 is
               not reused for v0.2.0.

FIELD_04:
  name:        review_context_ref
  type:        string
  required:    true
  nullable:    false
  description: Identifier or path of the review context package that was
               the sole input to this Perspective Reviewer's session. The
               Perspective Reviewer must not have read the document directly
               or any artefact outside the review context package.

FIELD_05:
  name:        reviewer_agent
  type:        string
  required:    true
  nullable:    false
  description: agent_id of the Perspective Reviewer Agent producing this
               record. Must be distinct from the document's created_by
               value per DLMS-2026-0014 (independence requirement).
  constraints:
    - Must differ from the document's created_by value
    - Must not have contributed to authoring the document under review

FIELD_06:
  name:        lens
  type:        enum
  required:    true
  nullable:    false
  values:      [accuracy, completeness, agent-readability, structure]
  description: >
    The single cognitive lens this Perspective Reviewer applied.
    accuracy:           Evaluates correctness of factual claims, policy
                        citations, and cross-references.
    completeness:       Evaluates whether all required content is present
                        and sufficiently developed.
    agent-readability:  Evaluates whether the document is parseable and
                        unambiguous for consuming agents.
    structure:          Evaluates conformance to template schema, section
                        ordering, naming conventions, and heading format.

FIELD_07:
  name:        reviewed_at
  type:        datetime
  required:    true
  nullable:    false
  format:      ISO 8601 with timezone
  description: Timestamp at which this perspective review was completed and
               this artefact was produced.

### Content_Fields

FIELD_08:
  name:        findings
  type:        list of finding objects
  required:    true
  nullable:    false
  description: Ordered list of specific findings identified by this
               Perspective Reviewer under the named lens. Empty list []
               is not permitted — at minimum, one finding with a pass
               and no observations must be recorded per lens.
  constraints:
    - At least one entry required
    - All findings must be specific, actionable, and traceable to
      the document content

  finding_object:
    finding_id:
      type:        string
      required:    true
      nullable:    false
      format:      F-{perspective_id}-{NN}
      description: Unique identifier for this finding within the perspective.
    description:
      type:        string
      required:    true
      nullable:    false
      description: A specific, actionable description of what was found.
                   For pass findings, a brief confirmation that the lens
                   criterion was met. For observations or failures, a
                   precise description of the issue.
      constraints:
        - Maximum 500 characters
    severity:
      type:        enum
      required:    true
      nullable:    false
      values:      [critical, major, minor, none]
      description: >
        none:     No issue found for this finding (pass).
        minor:    Stylistic or advisory issue; does not block advancement.
        major:    Substantive issue requiring resolution before approval;
                  blocks if unresolved.
        critical: Fundamental structural or accuracy failure; unconditional
                  block on advancement.
    recommendation:
      type:        string
      required:    false
      nullable:    true
      description: Specific corrective action recommended for severity
                   major or critical findings. Null when severity is none
                   or minor.
      constraints:
        - Maximum 500 characters
        - Required when severity is critical or major

FIELD_09:
  name:        overall_lens_verdict
  type:        enum
  required:    true
  nullable:    false
  values:      [pass, pass-with-observations, fail]
  description: >
    The aggregate verdict for this lens, derived from the findings list.
    Derivation rules:
      If any finding has severity critical or major → fail
      If no critical/major but any finding has severity minor → pass-with-observations
      If all findings have severity none → pass

FIELD_10:
  name:        blocking_findings
  type:        list of strings (finding_ids)
  required:    true
  nullable:    false
  description: Subset of finding_ids where severity is critical or major.
               These findings must be resolved before the document can
               advance. Empty list [] when overall_lens_verdict is pass or
               pass-with-observations.
  constraints:
    - Must be empty [] when overall_lens_verdict is pass or
      pass-with-observations
    - Must be non-empty when overall_lens_verdict is fail

## VALIDATION_RULES

V01: perspective_id is non-null and matches format
     RPERSPECTIVE-{doc_id}-{version}-{lens}-{NNNN}.
V02: reviewer_agent differs from the document's created_by value.
V03: lens is one of the four controlled enum values.
V04: findings contains at least one entry.
V05: Each finding_object has non-null finding_id, description, and severity.
V06: For findings with severity critical or major: recommendation is
     non-null and non-empty.
V07: overall_lens_verdict is correctly derived from findings per V07
     derivation rules above.
V08: blocking_findings is empty when overall_lens_verdict is pass or
     pass-with-observations; non-empty when overall_lens_verdict is fail.
V09: reviewed_at is a valid ISO 8601 datetime with timezone.
V10: doc_version matches format MAJOR.MINOR.PATCH.
