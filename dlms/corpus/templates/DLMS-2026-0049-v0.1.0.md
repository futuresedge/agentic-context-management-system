## SUMMARY
This template defines the schema of a review synthesis artefact produced
by the Review Synthesizer Agent after all Perspective Reviewers have
completed their lens reviews. The synthesis is the sole input to the
Approval Gate Agent and the Revision Agent, and constitutes the authoritative
review record for the review stage gate.

## TARGET_DOC_TYPE
review-synthesis

## PURPOSE
The review synthesis aggregates all individual review perspective artefacts
(per DLMS-2026-0048) into a coherent, non-redundant assessment that the
Approval Gate Agent can act on. The Review Synthesizer reads all perspective
artefacts for the document version under review and produces one synthesis.
The Approval Gate Agent reads the synthesis only — it does not read individual
perspective artefacts. The Revision Agent reads the synthesis to understand
what must change before re-submission. The Review Synthesizer must be a
distinct agent identity from all Perspective Reviewers whose artefacts it
synthesises, per Review Standards Policy (DLMS-2026-0042) and Verification
Independence Policy (DLMS-2026-0014).

## SCHEMA

### Header_Fields

FIELD_01:
  name:        synthesis_id
  type:        string
  required:    true
  nullable:    false
  format:      RSYNTH-{doc_id}-{version}-{NNNN}
  example:     RSYNTH-DLMS-2026-0030-0.1.0-0001
  description: Unique identifier for this review synthesis. NNNN is a
               zero-padded sequential integer scoped to the doc_id and
               version. Multiple synthesis cycles on the same version each
               increment NNNN. Immutable after assignment.

FIELD_02:
  name:        doc_id
  type:        string
  required:    true
  nullable:    false
  description: The DLMS doc_id of the document being reviewed.

FIELD_03:
  name:        doc_version
  type:        string
  required:    true
  nullable:    false
  format:      MAJOR.MINOR.PATCH
  description: The version of the document being reviewed. This synthesis
               is valid only for the specified version.

FIELD_04:
  name:        synthesized_by
  type:        string
  required:    true
  nullable:    false
  description: agent_id of the Review Synthesizer Agent producing this
               artefact. Must be distinct from the agent_id of every
               Perspective Reviewer in perspective_refs.
  constraints:
    - Must differ from every reviewer_agent value in the referenced
      perspective artefacts
    - Must differ from the document's created_by value

FIELD_05:
  name:        synthesized_at
  type:        datetime
  required:    true
  nullable:    false
  format:      ISO 8601 with timezone
  description: Timestamp at which synthesis was completed.

FIELD_06:
  name:        perspective_refs
  type:        list of strings
  required:    true
  nullable:    false
  description: Ordered list of perspective_ids (per DLMS-2026-0048) that
               were synthesised to produce this artefact. Must contain at
               least two perspective references. The synthesizer must have
               read all referenced perspective artefacts before producing
               this synthesis.
  constraints:
    - Minimum 2 entries required
    - All referenced perspective_ids must resolve to existing
      review-perspective artefacts for the same doc_id and doc_version

### Content_Fields

FIELD_07:
  name:        cross_cutting_themes
  type:        list of strings
  required:    true
  nullable:    false
  description: Recurring issues, patterns, or strengths identified across
               multiple perspective artefacts. Each entry is one thematic
               observation that cannot be attributed to a single lens.
               Empty list [] is permitted when all findings are lens-specific
               with no cross-cutting patterns.
  constraints:
    - Each entry: maximum 300 characters

FIELD_08:
  name:        blocking_issues
  type:        list of blocking issue objects
  required:    true
  nullable:    false
  description: Consolidated list of issues that must be resolved before the
               document can advance. Derived from blocking_findings across
               all perspective artefacts plus any additional synthesis-level
               blockers identified by the Review Synthesizer. Empty list []
               when synthesis_verdict is 'approve'.
  constraints:
    - Must be empty when synthesis_verdict is 'approve'
    - Must be non-empty when synthesis_verdict is 'return-for-revision'

  blocking_issue_object:
    issue_id:
      type:        string
      required:    true
      nullable:    false
      format:      BI-{synthesis_id}-{NN}
      description: Unique identifier for this blocking issue.
    source_perspective:
      type:        string
      required:    false
      nullable:    true
      description: The perspective_id where this issue was first identified.
                   Null for synthesis-level issues that are not attributable
                   to a single perspective.
    description:
      type:        string
      required:    true
      nullable:    false
      description: Clear description of the blocking issue and why it
                   prevents advancement.
      constraints:
        - Maximum 500 characters
    required_resolution:
      type:        string
      required:    true
      nullable:    false
      description: Specific action the Revision Agent or Document Author
                   must take to resolve this issue.
      constraints:
        - Maximum 500 characters

FIELD_09:
  name:        advisory_observations
  type:        list of strings
  required:    true
  nullable:    false
  description: Consolidated list of non-blocking observations (severity
               minor) from all perspectives that the Document Author or
               Revision Agent may address but which do not prevent
               advancement. Empty list [] when no advisory observations
               exist.
  constraints:
    - Each entry: maximum 500 characters

FIELD_10:
  name:        synthesis_verdict
  type:        enum
  required:    true
  nullable:    false
  values:      [approve, return-for-revision, defer]
  description: >
    The Review Synthesizer's recommended disposition.
    approve:              No blocking issues; document may proceed to the
                          Approval Gate Agent. revision_instructions must
                          be null.
    return-for-revision:  Blocking issues exist; document must be revised
                          before re-submission. revision_instructions must
                          be non-null.
    defer:                The review cannot be concluded due to external
                          dependency or missing information. The Creation
                          Orchestrator must surface the deferred status to
                          the SysAdmin.

FIELD_11:
  name:        recommended_disposition_rationale
  type:        string
  required:    true
  nullable:    false
  description: A brief explanation of the reasoning behind synthesis_verdict.
               Particularly important for 'defer' decisions where an
               external cause must be named.
  constraints:
    - Maximum 500 characters

FIELD_12:
  name:        revision_instructions
  type:        string
  required:    false
  nullable:    true
  description: >
    Structured instructions for the Revision Agent specifying what changes
    are required to address the blocking_issues. Each blocking issue must
    be addressed. Null when synthesis_verdict is 'approve' or 'defer'.
  constraints:
    - Required (non-null) when synthesis_verdict is 'return-for-revision'
    - Must address every issue in blocking_issues

## VALIDATION_RULES

V01: synthesis_id is non-null and matches format
     RSYNTH-{doc_id}-{version}-{NNNN}.
V02: synthesized_by differs from the document's created_by AND from every
     reviewer_agent value in the referenced perspective artefacts.
V03: perspective_refs contains at least two entries, all resolving to
     existing review-perspective artefacts for the same doc_id+doc_version.
V04: synthesis_verdict is one of [approve, return-for-revision, defer].
V05: When synthesis_verdict is 'approve': blocking_issues is empty AND
     revision_instructions is null.
V06: When synthesis_verdict is 'return-for-revision': blocking_issues is
     non-empty AND revision_instructions is non-null.
V07: revision_instructions (when non-null) references or addresses every
     issue_id in blocking_issues.
V08: recommended_disposition_rationale is non-null and non-empty.
V09: synthesized_at is a valid ISO 8601 datetime with timezone.
V10: doc_version matches format MAJOR.MINOR.PATCH.
