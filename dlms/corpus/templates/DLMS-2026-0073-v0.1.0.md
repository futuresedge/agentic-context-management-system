## SUMMARY
This template defines the schema and structure of a SysAdmin briefing
artefact produced by the SysAdmin Briefing Agent once per CI cycle,
after the improvement recommendations artefact is available. It condenses
the improvement recommendations into a compact, decision-ready summary
intended for human consumption by the DLM SysAdmin, with a read-time
target of at most 15 minutes.

## TARGET_DOC_TYPE
sysadmin-briefing

## SCHEMA

### Fields

FIELD_01:
  name:        report_id
  type:        string
  required:    true
  nullable:    false
  format:      SBR-{YYYY}-{NNNN}
  example:     SBR-2026-0001
  description: Unique identifier for this SysAdmin briefing artefact. NNNN
               is a zero-padded sequential integer scoped to the year.
               Immutable after assignment.

FIELD_02:
  name:        cycle_id
  type:        string
  required:    true
  nullable:    false
  format:      CYCLE-{YYYY}-{NNNN}

FIELD_03:
  name:        generated_by
  type:        string
  required:    true
  nullable:    false
  format:      agent:[agent-role-slug]
  constraints:
    - Must be agent:sysadmin-briefing-agent
    - Must differ from verified_by (Verification Independence Policy
      DLMS-2026-0014)

FIELD_04:
  name:        period_start
  type:        datetime
  required:    true
  nullable:    false
  format:      ISO 8601 with timezone offset

FIELD_05:
  name:        period_end
  type:        datetime
  required:    true
  nullable:    false
  format:      ISO 8601 with timezone offset
  constraints:
    - period_end must be >= period_start

FIELD_06:
  name:        source_verification_ref
  type:        string
  required:    true
  nullable:    false
  description: >
    Reference to the CI pipeline verifier artefact confirming that all
    upstream CI outputs for this cycle have been validated. The SysAdmin
    Briefing Agent must not produce a briefing until the verifier signals
    all five monitor reports and the synthesis chain are complete and
    conformant.
  note:         >
    This field replaces prior_report_ref. SysAdmin briefings are
    produced once per CI cycle and do not maintain a backward chain
    reference; the verification context is captured here instead.

FIELD_07:
  name:        source_recommendations_ref
  type:        string
  required:    true
  nullable:    false
  format:      IMP-{YYYY}-{NNNN}
  description: >
    The report_id of the improvement recommendations artefact this
    briefing summarises.

FIELD_08:
  name:        action_item_count
  type:        integer
  required:    true
  nullable:    false
  description: Total number of action items in the RECOMMENDATIONS section.
  constraints:
    - Must be >= 0
    - Must equal len(RECOMMENDATIONS entries)

FIELD_09:
  name:        critical_action_count
  type:        integer
  required:    true
  nullable:    false
  description: Count of action items with time_sensitivity: immediate.
  constraints:
    - Must be >= 0
    - Must equal len([AI in RECOMMENDATIONS where
        AI.time_sensitivity == "immediate"])

FIELD_10:
  name:        read_time_minutes
  type:        integer
  required:    true
  nullable:    false
  description: >
    Estimated reading time for this briefing artefact in minutes.
    Enforces compactness constraint. The SysAdmin Briefing Agent must
    produce a concise briefing that a human can read and act upon within
    the declared time.
  constraints:
    - Must be in range 1–15 (inclusive)
    - If the SysAdmin Briefing Agent calculates a longer than 15-minute
      briefing, it must trim lower-priority action items to an appendix
      note and flag this in context_notes

## REQUIRED_SECTIONS

SUMMARY:
  heading:     ## SUMMARY
  required:    true
  position:    1
  constraints:
    - Exactly 2–3 sentences
    - Must state action_item_count and critical_action_count
    - Must state read_time_minutes
    - Must reference source_recommendations_ref

SCOPE:
  heading:     ## SCOPE
  required:    true
  position:    2
  constraints:
    - Must identify source_verification_ref and source_recommendations_ref
    - Must state this briefing is addressed to a human DLM SysAdmin
      and is not an operational artefact for agent consumption
    - At least one Covers: and one Excludes: statement

PERIOD:
  heading:     ## PERIOD
  required:    true
  position:    3
  required_fields:
    period_start:               Timestamp — mirrors FIELD_04
    period_end:                 Timestamp — mirrors FIELD_05
    source_verification_ref:    Reference — mirrors FIELD_06
    source_recommendations_ref: IMP ID — mirrors FIELD_07
    context_notes:              Operational context; null if none

FINDINGS:
  heading:     ## FINDINGS
  required:    true
  position:    4
  description: >
    A concise, human-readable summary of the key themes from the CI
    cycle. Not a verbatim repeat of the synthesis or recommendations
    FINDINGS; rather a distilled interpretation aimed at enabling the
    DLM SysAdmin to make rapid, informed decisions. Maximum 10 findings
    to enforce brevity.
  finding_schema:
    id:              string — F prefix + two-digit sequential number
    category:        string — brief category label
    finding:         string — present tense, plain language; quantified
    severity:        enum — [info, warning, critical]
    action_item_refs: array of strings — AI ids that address this finding
  constraints:
    - Minimum 1 finding when action_item_count > 0
    - Maximum 10 findings (lower-priority themes trimmed per compactness)
    - F ids sequential from F01 with no gaps

EVIDENCE:
  heading:     ## EVIDENCE
  required:    true
  position:    5
  description: >
    Traceable references to upstream artefacts for each finding. Enables
    the SysAdmin to drill down if needed, without presenting raw data
    in the briefing itself.
  evidence_schema:
    id:              string — EV prefix + two-digit number
    source_artefact: string — IMP artefact ID, CI synthesis ID, or
                     individual monitor report ID
    data_type:       enum — [improvement-recommendations, ci-synthesis,
                     quality-report, performance-report, anomaly-report,
                     bottleneck-report, agent-behaviour-report]
    value:           string — specific finding or recommendation reference
    period:          string — cycle period reference
  constraints:
    - Minimum 1 entry
    - EV ids sequential from EV01 with no gaps

ANALYSIS:
  heading:     ## ANALYSIS
  required:    true
  position:    6
  description: >
    Brief interpretive context for each finding. Written for a human
    reader; plain language. Maximum 2–3 sentences per entry.
  analysis_schema:
    finding_ref:      string — F id
    interpretation:   string — plain language context; 2–3 sentences max
    urgency_note:     string or null — why this is time-sensitive if
                      time_sensitivity: immediate; null otherwise
  constraints:
    - Every finding with severity: warning or critical requires an entry
    - Total combined word count of all ANALYSIS entries must support the
      read_time_minutes constraint

RECOMMENDATIONS:
  heading:     ## RECOMMENDATIONS
  required:    true
  position:    7
  description: >
    Action items formatted for human decision-making. Each action item
    maps to one or more recommendations from the source IMP artefact.
    The DLM SysAdmin reviews these items and issues a change-directive
    artefact recording their decisions.
  action_item_schema:
    id:                  string — AI prefix + two-digit sequential number
    recommendation_ref:  string — R id from source IMP artefact
    action:              string — plain language, single sentence, imperative
    priority:            enum — [low, medium, high, immediate]
    time_sensitivity:    enum — [immediate, next-cycle, backlog]
    decision_required:   boolean — true if DLM SysAdmin must decide;
                         false for informational items only
  constraints:
    - Minimum 1 entry when action_item_count > 0
    - AI ids sequential from AI01 with no gaps
    - If escalation_required == true in upstream chain, at least one
      entry must have time_sensitivity: immediate

ESCALATION:
  heading:     ## ESCALATION
  required:    true
  position:    8
  required_fields:
    escalation_required: >
      Boolean. True when any action item has time_sensitivity: immediate
      OR when upstream escalation was carried in the IMP artefact.
    escalation_basis:    >
      Array of AI ids with time_sensitivity: immediate and/or note of
      upstream escalation carry. Empty [] when escalation_required == false.
    escalation_target:   sysadmin:dlm-sysadmin (the human) or null.
    notification_sent:   Boolean.

CHANGE_LOG:
  heading:     ## CHANGE_LOG
  required:    true
  position:    last
  format:      "- v[version] | [YYYY-MM-DD] | [agent_id] | [change summary]"

## OPTIONAL_SECTIONS

NOTES:
  heading:      ## NOTES
  description:  Trimmed lower-priority items or methodology notes.
  when_to_include: >
    When action items were trimmed to meet the read_time_minutes constraint.
    Trimmed items listed here with brief label and IMP recommendation_ref.
  position:     After CHANGE_LOG

## VALIDATION_RULES

V01:
  rule:     report_id is non-null, matches SBR-{YYYY}-{NNNN}, and is
            unique for the year.
  test:     >
    report_id != null AND
    report_id matches regex ^SBR-\d{4}-\d{4}$ AND
    no other sysadmin-briefing artefact for the same year shares this id.
  checked_by: CI Cycle Orchestrator; Audit Trail Agent

V02:
  rule:     generated_by must be agent:sysadmin-briefing-agent.
  test:     generated_by == "agent:sysadmin-briefing-agent"
  checked_by: CI Cycle Orchestrator

V03:
  rule:     source_recommendations_ref must be non-null and match the
            IMP-{YYYY}-{NNNN} format.
  test:     >
    source_recommendations_ref != null AND
    source_recommendations_ref matches regex ^IMP-\d{4}-\d{4}$
  checked_by: Agent Format Validator; CI Cycle Orchestrator

V04:
  rule:     read_time_minutes must be in range 1–15 (inclusive).
  test:     read_time_minutes >= 1 AND read_time_minutes <= 15
  checked_by: Agent Format Validator; SysAdmin Briefing Agent

V05:
  rule:     action_item_count must equal the actual count of action
            items in the RECOMMENDATIONS section.
  test:     action_item_count == len(RECOMMENDATIONS entries)
  checked_by: Agent Format Validator

V06:
  rule:     critical_action_count must equal the count of RECOMMENDATIONS
            entries with time_sensitivity: immediate.
  test:     >
    critical_action_count ==
      len([AI for AI in RECOMMENDATIONS
           where AI.time_sensitivity == "immediate"])
  checked_by: Agent Format Validator

V07:
  rule:     When upstream escalation was required (from IMP or CI synthesis
            chain), at least one RECOMMENDATIONS action item must have
            time_sensitivity: immediate.
  test:     >
    IF escalation_required == true THEN
      EXISTS AI in RECOMMENDATIONS where AI.time_sensitivity == "immediate"
  checked_by: SysAdmin Briefing Agent; Agent Format Validator

V08:
  rule:     FINDINGS must contain no more than 10 entries.
  test:     len(FINDINGS entries) <= 10
  checked_by: Agent Format Validator; SysAdmin Briefing Agent

V09:
  rule:     All nine required sections must be present and appear in
            the prescribed order.
  test:     >
    Sections SUMMARY, SCOPE, PERIOD, FINDINGS, EVIDENCE, ANALYSIS,
    RECOMMENDATIONS, ESCALATION, CHANGE_LOG all present and in sequence.
  checked_by: Agent Format Validator; Template Validator
