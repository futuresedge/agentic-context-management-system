## SUMMARY
This template defines the schema of an access manifest artefact, which
enumerates the agents explicitly permitted to access a C2 (restricted) or
C3 (confidential) DLMS corpus document. Its existence resolves the interim
SysAdmin directive mechanism declared in Access Control Policy
(DLMS-2026-0044 R07).

## TARGET_DOC_TYPE
access-manifest

## PURPOSE
The access manifest is a required artefact for every C2 and C3 document from
the moment of creation. For C2 documents, the Classification Agent produces
the manifest, listing permitted agent classes on a need-to-know basis. For C3
documents, sysadmin:dlm-sysadmin produces the manifest, which must include an
inline signed attestation and explicit named agent identities (not just
classes). The Access Gatekeeper agent evaluates access manifests at every
access attempt against a C2 or C3 document. One manifest is produced per
document; it is updated by amendment (SysAdmin directive) rather than
replacement. Absent or invalid manifests are immediately escalated per
DLMS-2026-0044 R05–R07.

## SCHEMA

### Header_Fields

FIELD_01:
  name:        manifest_id
  type:        string
  required:    true
  nullable:    false
  format:      MANIFEST-{doc_id}
  example:     MANIFEST-DLMS-2026-0099
  description: Unique identifier for this access manifest, scoped to the
               document it governs. One manifest exists per doc_id. The
               manifest_id is immutable. Updates to permitted access are
               appended as amendment records to the same manifest.

FIELD_02:
  name:        doc_id
  type:        string
  required:    true
  nullable:    false
  description: The DLMS doc_id of the document this manifest governs. Must
               correspond to an existing corpus document with
               confidentiality_class C2 or C3.

FIELD_03:
  name:        confidentiality_class
  type:        enum
  required:    true
  nullable:    false
  values:      [C2, C3]
  description: The confidentiality classification of the governed document.
               Only C2 and C3 documents require an access manifest. C0 and
               C1 documents must not have a manifest; their access is
               governed solely by agent registration status.

FIELD_04:
  name:        issued_by
  type:        string
  required:    true
  nullable:    false
  description: agent_id of the agent that issued this manifest. For C2
               documents, this is the Classification Agent. For C3
               documents, this must be sysadmin:dlm-sysadmin.
  constraints:
    - For C3: issued_by must equal 'sysadmin:dlm-sysadmin'; any other
      value is a manifest-integrity-violation audit event

FIELD_05:
  name:        issued_at
  type:        datetime
  required:    true
  nullable:    false
  format:      ISO 8601 with timezone
  description: Timestamp at which this manifest was issued. Must precede
               the first review-session-opened event for the governed doc_id
               per DLMS-2026-0044 R07.

FIELD_06:
  name:        expiry
  type:        datetime
  required:    false
  nullable:    true
  format:      ISO 8601 with timezone
  description: Optional expiry datetime for this manifest. Null indicates
               the manifest remains valid until explicitly amended or
               revoked by SysAdmin directive. When expiry is reached, the
               Access Gatekeeper treats the document as an unmanifested C2
               or C3 and escalates per DLMS-2026-0044 R05.

### Content_Fields

FIELD_07:
  name:        permitted_agents
  type:        list of permission objects
  required:    true
  nullable:    false
  description: Enumeration of agents permitted to access the governed
               document. Each entry specifies the agent identity, permitted
               operations, and the basis for access. For C2, agent_class is
               sufficient. For C3, agent_id is required for each entry.
  constraints:
    - Must contain at least one entry
    - For C3: every entry must have agent_id populated (not just agent_class)
    - sysadmin:dlm-sysadmin access is governed by DLMS-2026-0044 R11 and
      does not require a manifest entry

  permission_object:
    agent_class:
      type:        string
      required:    false
      nullable:    true
      description: The agent class permitted (e.g. 'Review Synthesizer',
                   'Approval Gate Agent'). Used for C2 manifests where
                   all instances of the class are permitted. Null for C3.
    agent_id:
      type:        string
      required:    false
      nullable:    true
      description: The specific agent identity permitted. Required for
                   every C3 manifest entry. Optional for C2 (where
                   agent_class is sufficient).
      constraints:
        - For C3 documents: agent_id must be non-null for every entry
    permitted_operations:
      type:        list of enum
      required:    true
      nullable:    false
      values:      [read, write]
      description: The operations this permission entry grants. At minimum
                   one value required.
    access_basis:
      type:        string
      required:    true
      nullable:    false
      description: One sentence stating why this agent class or agent
                   identity requires access to this document.
      constraints:
        - Maximum 300 characters

FIELD_08:
  name:        signed_attestation
  type:        attestation object
  required:    false
  nullable:    true
  description: Required for C3 documents; null for C2 documents. An inline
               attestation block produced by sysadmin:dlm-sysadmin
               confirming the legitimacy and necessity of the C3 access
               grants listed in this manifest. The attestation constitutes
               the SysAdmin's formal signing of the manifest for C3
               governance purposes per DLMS-2026-0044 R06.

  attestation_object:
    agent_id:
      type:        string
      required:    true
      nullable:    false
      description: The agent_id of sysadmin:dlm-sysadmin producing the
                   attestation. Must equal 'sysadmin:dlm-sysadmin'.
    timestamp:
      type:        datetime
      required:    true
      nullable:    false
      format:      ISO 8601 with timezone
      description: The timestamp at which the attestation was produced.
    attestation_statement:
      type:        string
      required:    true
      nullable:    false
      description: A brief statement from sysadmin:dlm-sysadmin confirming
                   that the listed access grants have been reviewed,
                   are necessary, and comply with DLMS access governance.
      constraints:
        - Maximum 500 characters

### Amendment_History

FIELD_09:
  name:        amendments
  type:        list of amendment objects
  required:    true
  nullable:    false
  description: Record of all amendments to this manifest since original
               issuance. Empty list [] at initial issuance. Amendments
               are appended; entries must not be modified or removed.
  amendment_object:
    amendment_id:
      type:        string
      format:      MANIFEST-AMD-{doc_id}-{NNNN}
      required:    true
      description: Unique identifier for this amendment entry.
    amended_by:
      type:        string
      required:    true
      description: agent_id of the agent making the amendment. For C3
                   manifest amendments, must be sysadmin:dlm-sysadmin.
    amended_at:
      type:        datetime
      required:    true
      format:      ISO 8601 with timezone
    directive_ref:
      type:        string
      required:    false
      nullable:    true
      description: doc_id of the SysAdmin directive authorising this
                   amendment. Required for C3; optional for C2.
    change_summary:
      type:        string
      required:    true
      description: One sentence description of what changed.
      constraints:
        - Maximum 300 characters

## VALIDATION_RULES

V01: manifest_id is non-null and matches format MANIFEST-{doc_id} where
     doc_id corresponds to an existing DLMS corpus document.
V02: confidentiality_class is C2 or C3. Any other value is
     manifest-invalid.
V03: For C3 documents: issued_by equals 'sysadmin:dlm-sysadmin';
     signed_attestation is non-null; every permitted_agents entry has
     agent_id populated. Violation produces manifest-integrity-violation
     audit event.
V04: For C2 documents: signed_attestation is null; at least one entry
     in permitted_agents has agent_class or agent_id populated.
V05: permitted_agents is non-empty (at least one entry required for
     all manifests).
V06: All permitted_operations values are drawn from [read, write].
V07: issued_at is a valid ISO 8601 datetime with timezone.
V08: For C3: signed_attestation.agent_id equals 'sysadmin:dlm-sysadmin'
     and attestation_statement is non-null and non-empty.
V09: amendments is present (empty list [] is valid at issuance). Entries
     in amendments are immutable after creation; no entry may be
     modified or deleted.
V10: For C3 manifest amendments: amended_by equals
     'sysadmin:dlm-sysadmin' AND directive_ref is non-null.
