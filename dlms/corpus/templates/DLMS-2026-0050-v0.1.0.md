## SUMMARY
This template defines the schema of an approval status artefact produced by
the Approval Gate Agent after evaluating a review synthesis against the
approval stage DoD (DLMS-2026-0026). It records the approval decision,
any conditions, and the human approval gate outcome where required.

## TARGET_DOC_TYPE
approval-status

## PURPOSE
The approval status artefact is the authoritative record of the Approval Gate
Agent's decision for a document entering the approval stage. It is produced
after the Approval Gate Agent reads the review synthesis (DLMS-2026-0049)
and the approval DoD (DLMS-2026-0026). The Review Verifier uses it to
verify the stage gate. The Status Transition Agent reads it to determine
whether to execute the status transition to 'approved'. For documents
requiring human approval, the approval status artefact is incomplete until
a human approver has populated the human_approved_at field; the Status
Transition Agent must not act on an incomplete approval status record. One
approval status artefact is produced per approval cycle; a re-submission
after revision produces a new record with a new approval_id.

## SCHEMA

### Header_Fields

FIELD_01:
  name:        approval_id
  type:        string
  required:    true
  nullable:    false
  format:      APPR-{doc_id}-{version}-{NNNN}
  example:     APPR-DLMS-2026-0030-0.1.0-0001
  description: Unique identifier for this approval status record. NNNN
               increments with each approval cycle for the same document
               version. Immutable after assignment.

FIELD_02:
  name:        doc_id
  type:        string
  required:    true
  nullable:    false
  description: The DLMS doc_id of the document being evaluated for approval.

FIELD_03:
  name:        doc_version
  type:        string
  required:    true
  nullable:    false
  format:      MAJOR.MINOR.PATCH
  description: The version of the document at the time of this approval
               evaluation.

FIELD_04:
  name:        review_synthesis_ref
  type:        string
  required:    true
  nullable:    false
  description: The synthesis_id (per DLMS-2026-0049) of the review synthesis
               this approval decision is based on. The Approval Gate Agent
               reads this synthesis only — not individual perspective
               artefacts.

FIELD_05:
  name:        gate_agent
  type:        string
  required:    true
  nullable:    false
  description: agent_id of the Approval Gate Agent producing this record.
               Must be distinct from the document's created_by value and
               from the synthesized_by value in the referenced synthesis.
  constraints:
    - Must differ from the document's created_by value

FIELD_06:
  name:        evaluated_at
  type:        datetime
  required:    true
  nullable:    false
  format:      ISO 8601 with timezone
  description: Timestamp at which the Approval Gate Agent completed its
               evaluation and produced this record.

### Decision_Fields

FIELD_07:
  name:        approval_decision
  type:        enum
  required:    true
  nullable:    false
  values:      [approve, return-for-revision, defer]
  description: >
    The Approval Gate Agent's decision.
    approve:              The document meets all criteria for advancement
                          to approved status.
    return-for-revision:  The review synthesis identifies blocking issues
                          that require resolution before approval.
    defer:                Approval cannot proceed due to a dependency,
                          external factor, or missing information.

FIELD_08:
  name:        rationale
  type:        string
  required:    true
  nullable:    false
  description: Brief explanation of the approval_decision, particularly
               for 'return-for-revision' or 'defer' decisions. For
               'approve' decisions, a brief confirmation statement.
  constraints:
    - Maximum 500 characters

FIELD_09:
  name:        conditions
  type:        list of strings
  required:    true
  nullable:    false
  description: Any conditions attached to an 'approve' decision that must
               be satisfied after approval. For unconditional approval,
               this is an empty list []. For 'return-for-revision' or
               'defer', this field records the blocking conditions.
  constraints:
    - Each entry: maximum 300 characters

### Human_Approval_Gate

FIELD_10:
  name:        human_approval_required
  type:        boolean
  required:    true
  nullable:    false
  description: Whether the approval decision requires a human approver to
               confirm before the document status transitions to 'approved'.
               Determined by the document's doc_type, tier, and any
               applicable policies. When true, the approval status record
               is incomplete until human_approver and human_approved_at are
               both populated.

FIELD_11:
  name:        human_approver
  type:        string
  required:    false
  nullable:    true
  description: The identity of the human approver who confirmed the
               approval decision. Null when human_approval_required is
               false. Required (non-null) when human_approval_required is
               true before the Status Transition Agent may act.
  constraints:
    - Must be non-null before Status Transition Agent executes when
      human_approval_required is true

FIELD_12:
  name:        human_approved_at
  type:        datetime
  required:    false
  nullable:    true
  format:      ISO 8601 with timezone
  description: Timestamp at which the human approver confirmed the
               decision. Null when human_approval_required is false.
               Required (non-null) when human_approval_required is true
               before the Status Transition Agent may act.
  constraints:
    - Must be non-null before Status Transition Agent executes when
      human_approval_required is true

## VALIDATION_RULES

V01: approval_id is non-null and matches format
     APPR-{doc_id}-{version}-{NNNN}.
V02: gate_agent differs from the document's created_by value.
V03: approval_decision is one of [approve, return-for-revision, defer].
V04: rationale is non-null and non-empty.
V05: review_synthesis_ref is non-null and resolves to an existing
     review-synthesis artefact for the same doc_id and doc_version.
V06: When human_approval_required is true AND approval_decision is
     'approve': both human_approver and human_approved_at must be
     non-null before the Status Transition Agent may act.
V07: When approval_decision is 'approve' and human_approval_required is
     false: human_approver and human_approved_at must be null.
V08: evaluated_at is a valid ISO 8601 datetime with timezone.
V09: doc_version matches format MAJOR.MINOR.PATCH.
