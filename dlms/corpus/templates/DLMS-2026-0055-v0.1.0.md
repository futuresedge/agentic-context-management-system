## SUMMARY
This template defines the schema of an archival recommendation artefact
produced by the Archival Stage Orchestrator before any archival action is
taken. It captures the eligibility basis, the recommended action, and the
rationale, and serves as the decision input for the Archival Log once the
action is executed.

## TARGET_DOC_TYPE
archival-recommendation

## PURPOSE
The archival recommendation is a pre-archival artefact that formalises the
Archival Stage Orchestrator's assessment before executing any status
transition or archival action. It is produced after the archival DoD
(DLMS-2026-0029) confirms the document is eligible for archival-stage
processing. The recommendation must be produced before the Archival Log;
the Archival Log references this artefact's rec_id. For RC-permanent
documents, manual initiation triggers an escalation recommendation rather
than a direct archive action — a sysadmin override is required
(DLMS-2026-0040). One recommendation is produced per archival event.

## SCHEMA

### Header_Fields

FIELD_01:
  name:        rec_id
  type:        string
  required:    true
  nullable:    false
  format:      ARCHVREC-{doc_id}-{version}-{NNNN}
  example:     ARCHVREC-DLMS-2026-0015-0.1.0-0001
  description: Unique identifier for this archival recommendation. NNNN
               increments per recommendation event for the same doc_id
               and version. Immutable after assignment.

FIELD_02:
  name:        doc_id
  type:        string
  required:    true
  nullable:    false
  description: The DLMS doc_id of the document being assessed for archival.

FIELD_03:
  name:        doc_version
  type:        string
  required:    true
  nullable:    false
  format:      MAJOR.MINOR.PATCH
  description: The version of the document being assessed for archival.

FIELD_04:
  name:        current_status
  type:        enum
  required:    true
  nullable:    false
  values:      [approved, superseded]
  description: The document's current lifecycle status at the time of this
               recommendation. Archival-stage assessments apply only to
               approved or superseded documents.

FIELD_05:
  name:        retention_class
  type:        string
  required:    true
  nullable:    false
  description: The retention class of the document as recorded in its
               frontmatter (e.g. RC-permanent, RC-7yr, RC-3yr).
               Must be a valid retention class per DLMS-2026-0039.

FIELD_06:
  name:        recommended_by
  type:        string
  required:    true
  nullable:    false
  description: agent_id of the Archival Stage Orchestrator producing this
               recommendation.

FIELD_07:
  name:        recommended_at
  type:        datetime
  required:    true
  nullable:    false
  format:      ISO 8601 with timezone
  description: Timestamp at which this recommendation was produced.

### Eligibility_Assessment

FIELD_08:
  name:        age_at_recommendation
  type:        string
  required:    true
  nullable:    false
  description: The age of the document at recommendation time, expressed
               as an ISO 8601 duration (e.g. P3Y2M for 3 years 2 months).
               Calculated from the document's created_at or approved_at
               timestamp to recommended_at.
  format:      ISO 8601 duration (PnYnMnD)
  example:     P3Y2M

FIELD_09:
  name:        retention_expiry_at
  type:        datetime
  required:    false
  nullable:    true
  format:      ISO 8601 with timezone
  description: The datetime at which this document's retention period
               expires. Must be null for RC-permanent documents.
               Non-null for all other retention classes.
  constraints:
    - Must be null when retention_class is RC-permanent

FIELD_10:
  name:        eligibility_basis
  type:        enum
  required:    true
  nullable:    false
  values:      [retention-expired, superseded, manually-initiated]
  description: >
    retention-expired:    The document's retention period has expired per
                          DLMS-2026-0039; retention_expiry_at is in the past.
    superseded:           The document has been superseded by a newer version
                          or replacement document (current_status: superseded).
    manually-initiated:   An authorised human or sysadmin has explicitly
                          requested archival outside the automated schedule.
                          When combined with RC-permanent, this must trigger
                          recommended_action: escalate-to-sysadmin.

### Recommendation

FIELD_11:
  name:        recommended_action
  type:        enum
  required:    true
  nullable:    false
  values:      [archive, retain, escalate-to-sysadmin]
  description: >
    archive:               Proceed with archival. Valid when eligibility_basis
                           is retention-expired or superseded for non-permanent
                           documents.
    retain:                Do not archive; conditions for archival are not met.
                           Used when a review of the assessment finds the
                           document should remain in its current state.
    escalate-to-sysadmin:  Escalate to sysadmin for manual decision. REQUIRED
                           when eligibility_basis is manually-initiated AND
                           retention_class is RC-permanent per DLMS-2026-0040.

FIELD_12:
  name:        rationale
  type:        string
  required:    true
  nullable:    false
  description: One to three sentences explaining why this recommendation
               was made. Must describe the eligibility basis and how the
               recommended action was determined.
  constraints:
    - Maximum 1000 characters

## VALIDATION_RULES

V01: rec_id is non-null and matches format
     ARCHVREC-{doc_id}-{version}-{NNNN}.
V02: current_status is one of [approved, superseded].
V03: retention_expiry_at is null when retention_class is RC-permanent.
V04: retention_expiry_at is non-null for all non-RC-permanent retention
     classes.
V05: When eligibility_basis is retention-expired: retention_expiry_at
     must be a datetime in the past (before recommended_at).
V06: When eligibility_basis is manually-initiated AND retention_class is
     RC-permanent: recommended_action must be escalate-to-sysadmin.
V07: recommended_action is one of [archive, retain, escalate-to-sysadmin].
V08: rationale is non-null and non-empty.
V09: age_at_recommendation matches ISO 8601 duration format PnYnMnD.
V10: doc_version matches format MAJOR.MINOR.PATCH.
