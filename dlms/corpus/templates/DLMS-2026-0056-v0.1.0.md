## SUMMARY
This template defines the schema of an archival log artefact produced by the
Archival Stage Orchestrator after an archival action is executed. It is the
immutable record of the status transition performed, references the Archival
Recommendation that authorised the action, and must be linked to an audit
event per DLMS-2026-0015.

## TARGET_DOC_TYPE
archival-log

## PURPOSE
The archival log is the post-archival record of the status transition applied
to a document. It is produced by the Archival Stage Orchestrator after the
action is either completed (the document's status has been updated) or
confirmed by the SysAdmin (in the case of an escalation). The log references
the Archival Recommendation (DLMS-2026-0055) that authorised the action. It
captures the archive location, the action taken, the sysadmin override where
applicable, and the audit event references. Archival log entries are
immutable; any correction requires a new archival log of type
transitioned-to-superseded or an audit annotation. One archival log is
produced per archival action execution.

## SCHEMA

### Header_Fields

FIELD_01:
  name:        log_id
  type:        string
  required:    true
  nullable:    false
  format:      ARCHL-{doc_id}-{version}-{NNNN}
  example:     ARCHL-DLMS-2026-0015-0.1.0-0001
  description: Unique identifier for this archival log. NNNN increments
               per archival event for the same doc_id and version.
               Immutable after production.

FIELD_02:
  name:        rec_ref
  type:        string
  required:    true
  nullable:    false
  description: The rec_id of the Archival Recommendation (DLMS-2026-0055)
               that authorised this archival action. Must reference an
               actual Archival Recommendation artefact.

FIELD_03:
  name:        doc_id
  type:        string
  required:    true
  nullable:    false
  description: The DLMS doc_id of the document on which the archival action
               was executed.

FIELD_04:
  name:        doc_version
  type:        string
  required:    true
  nullable:    false
  format:      MAJOR.MINOR.PATCH
  description: The version of the document on which the archival action was
               executed.

FIELD_05:
  name:        actioned_by
  type:        string
  required:    true
  nullable:    false
  description: agent_id of the Archival Stage Orchestrator or, when the
               action required sysadmin escalation, the sysadmin identifier
               (sysadmin:dlm-sysadmin) who authorised the action.

FIELD_06:
  name:        actioned_at
  type:        datetime
  required:    true
  nullable:    false
  format:      ISO 8601 with timezone
  description: Timestamp at which the archival action was executed and
               the document's status was updated.

### Archival_Action

FIELD_07:
  name:        archival_action
  type:        enum
  required:    true
  nullable:    false
  values:      [transitioned-to-archived, transitioned-to-superseded]
  description: >
    transitioned-to-archived:    The document status was changed to
                                 archived. Applicable when archival is due
                                 to retention expiry or manual initiation
                                 with sysadmin approval.
    transitioned-to-superseded:  The document status was changed to
                                 superseded. Applicable when a newer version
                                 or replacement document has been approved
                                 and this document is being formally retired.
                                 superseded_by_doc_id must be non-null.

FIELD_08:
  name:        superseded_by_doc_id
  type:        string
  required:    false
  nullable:    true
  description: The DLMS doc_id of the document that supersedes this one.
               Must be non-null when archival_action is
               transitioned-to-superseded. Must be null when archival_action
               is transitioned-to-archived.
  constraints:
    - Non-null when archival_action is transitioned-to-superseded
    - Must be null when archival_action is transitioned-to-archived

FIELD_09:
  name:        archive_location
  type:        string
  required:    true
  nullable:    false
  description: The storage path or identifier where the archived document
               is stored. Must be non-null; the document must be physically
               accessible at this location after archival per DLMS-2026-0040.
  example:     /dlms/archive/DLMS-2026-0015-v0.1.0-archived.md
  constraints:
    - Non-null and non-empty; must represent an accessible storage location

### Sysadmin_Override

FIELD_10:
  name:        sysadmin_override
  type:        override object
  required:    false
  nullable:    true
  description: Present when the archival action was escalated to sysadmin
               per the escalate-to-sysadmin recommendation path in
               DLMS-2026-0055. Null for automated archival events.

  override_object:
    approver:
      type:        string
      required:    true
      nullable:    false
      description: The sysadmin identifier (sysadmin:dlm-sysadmin) who
                   approved the override.
    approved_at:
      type:        datetime
      required:    true
      nullable:    false
      format:      ISO 8601 with timezone
      description: Timestamp at which the sysadmin approved the archival.
    approval_statement:
      type:        string
      required:    true
      nullable:    false
      description: One sentence justifying the sysadmin's approval of
                   the archival action.
      constraints:
        - Maximum 500 characters

### Audit_Links

FIELD_11:
  name:        audit_event_ref
  type:        string
  required:    true
  nullable:    false
  description: Reference to the audit event generated for this archival
               action per DLMS-2026-0015 R03. Single entry; one archival
               event maps to one primary audit event.
  format:      AUDIT-EVT-{YYYYMMDD}-{NNNN}
  example:     AUDIT-EVT-20260309-0012

## VALIDATION_RULES

V01: log_id is non-null and matches format
     ARCHL-{doc_id}-{version}-{NNNN}.
V02: rec_ref references a valid Archival Recommendation artefact
     (non-null, non-empty).
V03: When archival_action is transitioned-to-superseded:
     superseded_by_doc_id must be non-null and must reference an
     existing DLMS document.
V04: When archival_action is transitioned-to-archived:
     superseded_by_doc_id must be null.
V05: archive_location is non-null and non-empty.
V06: audit_event_ref is non-null and matches format
     AUDIT-EVT-{YYYYMMDD}-{NNNN}.
V07: When sysadmin_override is non-null: approver, approved_at, and
     approval_statement are all non-null within the override object.
V08: actioned_at is a valid ISO 8601 datetime with timezone.
V09: doc_version matches format MAJOR.MINOR.PATCH.
