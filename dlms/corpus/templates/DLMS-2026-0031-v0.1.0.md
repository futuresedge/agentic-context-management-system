## SUMMARY
This template defines the schema of a raw metadata capture record, produced
at document creation before classification has occurred. The raw record
captures the subset of frontmatter fields that are known at creation time
and provides a baseline snapshot used by the Classification Agent and the
Agent Format Validator to verify that creation-time metadata is correct.
It is a precursor to the Metadata Final record (DLMS-2026-0032).

## TARGET_DOC_TYPE
metadata-raw-record

## PURPOSE
A raw metadata record is produced by the Creation Orchestrator immediately
after a document file is laid down. It captures stable creation-time fields
before the Classification Agent assigns tags and confirms the full metadata
set. The raw record feeds the Agent Format Validator's schema check and is
retained as an audit artefact alongside the document it describes.

## SCHEMA

### Fields

FIELD_01:
  name:        record_id
  type:        string
  required:    true
  nullable:    false
  format:      MDR-{doc_id}-{version}
  example:     MDR-DLMS-2026-0030-0.1.0
  description: Unique identifier for this raw metadata record. Immutable.

FIELD_02:
  name:        capture_agent
  type:        string
  required:    true
  nullable:    false
  description: agent_id of the agent that produced this raw record
               (typically the Creation Orchestrator).

FIELD_03:
  name:        capture_timestamp
  type:        datetime
  required:    true
  nullable:    false
  format:      ISO 8601 with timezone
  description: When this raw record was produced. Must be at or after
               the document's created_at value.

FIELD_04:
  name:        doc_id
  type:        string
  required:    true
  nullable:    false
  description: The doc_id from the document's frontmatter. Must be
               non-null and correctly formatted at capture time.

FIELD_05:
  name:        title
  type:        string
  required:    true
  nullable:    false
  description: The title from the document's frontmatter.

FIELD_06:
  name:        doc_type
  type:        enum
  required:    true
  nullable:    false
  values:      [policy, procedure, standard, pattern, sla, specification,
               reference, report, taxonomy, template]
  description: The doc_type from the document's frontmatter.

FIELD_07:
  name:        status
  type:        string
  required:    true
  nullable:    false
  expected:    draft
  description: The status at capture time. For creation-stage raw records,
               expected value is always "draft".

FIELD_08:
  name:        version
  type:        string
  required:    true
  nullable:    false
  expected:    0.1.0
  description: The version at capture time. For new documents, expected
               value is 0.1.0. For amended documents being re-captured,
               the current version at time of capture.

FIELD_09:
  name:        created_at
  type:        datetime
  required:    true
  nullable:    false
  format:      ISO 8601 with timezone
  description: The created_at value from the document's frontmatter.

FIELD_10:
  name:        created_by
  type:        string
  required:    true
  nullable:    false
  description: The created_by agent identity from the document's frontmatter.

FIELD_11:
  name:        template_id
  type:        string
  required:    true
  nullable:    false
  description: The template_id from the document's frontmatter.

FIELD_12:
  name:        template_ver
  type:        string
  required:    true
  nullable:    false
  format:      MAJOR.MINOR.PATCH
  description: The template_ver from the document's frontmatter.

FIELD_13:
  name:        agent_path
  type:        string
  required:    true
  nullable:    false
  description: The agent_path from the document's frontmatter.

FIELD_14:
  name:        audit_ref
  type:        string
  required:    true
  nullable:    false
  format:      AUDIT-DLMS-{YYYY}-{NNNN}
  description: The audit_ref from the document's frontmatter.

FIELD_15:
  name:        validation_errors
  type:        list of error objects
  required:    true
  nullable:    false
  description: >
    List of field-level validation issues found by the Agent Format
    Validator at capture time. Empty list [] when all captured fields
    are valid. Each error object contains:
      field:    name of the frontmatter field in violation
      rule:     the specific rule from DLMS-2026-0018 that was violated
      found:    the actual value found
      expected: the expected format or value

  constraints:
    - Non-empty validation_errors do not prevent the raw record from
      being produced — the raw record documents the state as-found
    - The Creation Orchestrator must remediate all errors before the
      document can advance to the Review stage

## VALIDATION_RULES

V01: record_id matches MDR-{doc_id}-{version}.
V02: All 14 document-field captures (FIELD_04–FIELD_14) are non-null.
V03: capture_timestamp is not before the document's created_at value.
V04: doc_type is one of the ten valid enum values.
V05: version matches MAJOR.MINOR.PATCH format.
V06: audit_ref matches AUDIT-DLMS-{YYYY}-{NNNN}.
V07: validation_errors is a list (may be empty), never null.
