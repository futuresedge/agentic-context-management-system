## SUMMARY
This template defines the schema of a corpus index entry record, produced
by the Tag Index Agent for each document version that successfully passes
the Storage stage gate. Index entry records are the primary lookup artefacts
for corpus navigation, context package construction, and agent discovery.
They are populated from the document's final metadata record (DLMS-2026-0032).

## TARGET_DOC_TYPE
index-entry-record

## PURPOSE
An index entry record provides a lightweight, denormalised snapshot of a
document's key navigational fields without requiring agents to open the full
document file. The corpus index is maintained as a set of index entry records.
Agents performing search, routing, or context discovery consume the index
rather than reading individual document frontmatter directly.

## SCHEMA

### Fields

FIELD_01:
  name:        index_key
  type:        string
  required:    true
  nullable:    false
  format:      {doc_id}
  example:     DLMS-2026-0030
  description: The primary lookup key for this index entry. Set to the
               document's doc_id. Unique across the corpus index.
  constraints:
    - One index entry per doc_id (the current active version)
    - Superseded versions are replaced by a new entry; prior entries are
      moved to the version history sub-index

FIELD_02:
  name:        doc_id
  type:        string
  required:    true
  nullable:    false
  description: The document's doc_id. Must match index_key.

FIELD_03:
  name:        title
  type:        string
  required:    true
  nullable:    false
  description: The document's title as declared in frontmatter.

FIELD_04:
  name:        doc_type
  type:        enum
  required:    true
  nullable:    false
  values:      [policy, procedure, standard, pattern, sla, specification,
               reference, report, taxonomy, template]
  description: The document's doc_type.

FIELD_05:
  name:        status
  type:        enum
  required:    true
  nullable:    false
  values:      [draft, under_review, approved, superseded, archived]
  description: The document's current status at the time of indexing.

FIELD_06:
  name:        version
  type:        string
  required:    true
  nullable:    false
  format:      MAJOR.MINOR.PATCH
  description: The version of the document this entry reflects.

FIELD_07:
  name:        tags
  type:        list of strings
  required:    true
  nullable:    false
  description: The document's final tag list, sourced from the final
               metadata record (DLMS-2026-0032). All values must be
               active terms from DLMS-2026-0021.
  constraints:
    - Minimum one tag
    - Must be identical to tags in the corresponding final metadata record

FIELD_08:
  name:        agent_path
  type:        string
  required:    true
  nullable:    false
  description: Absolute path to the document file. Agents use this to
               retrieve the full document when needed beyond index data.

FIELD_09:
  name:        audit_ref
  type:        string
  required:    true
  nullable:    false
  description: The document's audit_ref. Used by audit lookup queries.

FIELD_10:
  name:        supersedes
  type:        string
  required:    false
  nullable:    true
  description: The doc_id this document supersedes, if any. Null otherwise.

FIELD_11:
  name:        superseded_by
  type:        string
  required:    false
  nullable:    true
  description: The doc_id of the document that supersedes this one.
               Null while the document is in active status.
               Set when this document's status changes to superseded.

FIELD_12:
  name:        indexed_at
  type:        datetime
  required:    true
  nullable:    false
  format:      ISO 8601 with timezone
  description: When this index entry was produced or last updated.

FIELD_13:
  name:        indexing_agent
  type:        string
  required:    true
  nullable:    false
  description: agent_id of the Tag Index Agent that produced this entry.

FIELD_14:
  name:        source_metadata_record
  type:        string
  required:    true
  nullable:    false
  format:      MDF-{doc_id}-{version}
  description: The record_id of the final metadata record (DLMS-2026-0032)
               from which this index entry was populated. Provides
               traceability from index entry back to the classification event.

## VALIDATION_RULES

V01: index_key equals doc_id.
V02: doc_type is one of the ten valid enum values.
V03: status is one of the five valid enum values.
V04: version matches MAJOR.MINOR.PATCH format.
V05: tags is non-empty and every value exists in DLMS-2026-0021 with
     status: active.
V06: tags matches the tags list in the referenced final metadata record.
V07: source_metadata_record matches MDF-{doc_id}-{version} and references
     a final metadata record where all_validation_passed is true.
V08: When superseded_by is non-null, it resolves to an existing corpus
     document with status: approved or superseded.
V09: indexed_at is not before the final metadata record's capture_timestamp.
