## SUMMARY
This template defines the schema of a distribution plan artefact produced
by the Distribution Orchestrator before any distribution action begins.
It specifies the intended recipients, format, channel, and preconditions
that must be satisfied before distribution may proceed for a given document
version.

## TARGET_DOC_TYPE
distribution-plan

## PURPOSE
The distribution plan is a pre-distribution artefact that formalises the
Distribution Orchestrator's intent before any distribution action is taken.
It is produced after the distribution DoD (DLMS-2026-0028) check confirms
the document is ready for distribution. It captures the target recipients,
their permitted access level, the format to be delivered, and confirms
that all preconditions — including classification-based restrictions — have
been verified. The Distribution Log (DLMS-2026-0054) references the plan and
records what actually occurred. One distribution plan is produced per
distribution event; a redistribution produces a new plan with a new plan_id.
The Distribution Orchestrator must not proceed to distribution without an
approved plan.

## SCHEMA

### Header_Fields

FIELD_01:
  name:        plan_id
  type:        string
  required:    true
  nullable:    false
  format:      DISTPLAN-{doc_id}-{version}-{NNNN}
  example:     DISTPLAN-DLMS-2026-0030-0.1.0-0001
  description: Unique identifier for this distribution plan. NNNN increments
               per distribution event for the same doc_id and version.
               Immutable after assignment.

FIELD_02:
  name:        doc_id
  type:        string
  required:    true
  nullable:    false
  description: The DLMS doc_id of the document to be distributed.

FIELD_03:
  name:        doc_version
  type:        string
  required:    true
  nullable:    false
  format:      MAJOR.MINOR.PATCH
  description: The version of the document to be distributed.

FIELD_04:
  name:        confidentiality_class
  type:        enum
  required:    true
  nullable:    false
  values:      [C0, C1, C2, C3]
  description: The confidentiality classification of the document at the
               time of distribution planning. Determines which restrictions
               apply per DLMS-2026-0044 and DLMS-2026-0045.

FIELD_05:
  name:        planned_by
  type:        string
  required:    true
  nullable:    false
  description: agent_id of the Distribution Orchestrator producing this plan.

FIELD_06:
  name:        planned_at
  type:        datetime
  required:    true
  nullable:    false
  format:      ISO 8601 with timezone
  description: Timestamp at which this distribution plan was produced.

FIELD_07:
  name:        scheduled_distribution_at
  type:        datetime
  required:    false
  nullable:    true
  format:      ISO 8601 with timezone
  description: The scheduled time for distribution to begin. Null if
               distribution is to proceed immediately upon plan approval.

### Distribution_Scope

FIELD_08:
  name:        external_distribution_permitted
  type:        boolean
  required:    true
  nullable:    false
  description: Whether external distribution (outside the DLMS system) is
               permitted for this document. True only for C0 (public)
               documents. Must be false for C1, C2, and C3 documents per
               DLMS-2026-0044 R04. The Distribution Orchestrator must not
               include recipient_type: external entries in target_recipients
               when this field is false.
  constraints:
    - Must be false when confidentiality_class is C1, C2, or C3
    - May be true only when confidentiality_class is C0

FIELD_09:
  name:        target_recipients
  type:        list of recipient objects
  required:    true
  nullable:    false
  description: Enumeration of intended recipients with their access
               type and format. Each entry specifies who will receive
               the document, in what form, and whether they are internal
               or external to the DLMS.
  constraints:
    - Must contain at least one entry
    - When external_distribution_permitted is false: no entry may have
      recipient_type: external

  recipient_object:
    recipient_id:
      type:        string
      required:    true
      nullable:    false
      description: agent_id, system identifier, or external party name
                   for the intended recipient.
    recipient_type:
      type:        enum
      required:    true
      nullable:    false
      values:      [agent, system, external]
      description: >
        agent:    A DLMS agent or agent class.
        system:   An internal non-agent system (e.g. index, registry).
        external: A party outside the DLMS system. Only permitted when
                  external_distribution_permitted is true.
    format:
      type:        enum
      required:    true
      nullable:    false
      values:      [markdown, pdf, json]
      description: The format in which the document will be delivered to
                   this recipient.
    access_basis:
      type:        string
      required:    true
      nullable:    false
      description: One sentence explaining why this recipient requires
                   access to this document.
      constraints:
        - Maximum 300 characters

FIELD_10:
  name:        distribution_channel
  type:        string
  required:    true
  nullable:    false
  description: The delivery mechanism for this distribution (e.g.
               'corpus-read-access', 'api-delivery', 'human-portal').
  constraints:
    - Maximum 200 characters

### Preconditions

FIELD_11:
  name:        preconditions
  type:        list of precondition objects
  required:    true
  nullable:    false
  description: Conditions that must be verified as satisfied before
               distribution may begin. Each precondition is checked by
               the Distribution Orchestrator and must be confirmed. This
               list must include at minimum: classification verification
               and DoD passed confirmation. Empty list [] is not valid.
  constraints:
    - Minimum 2 entries required (classification check + DoD check)

  precondition_object:
    condition:
      type:        string
      required:    true
      nullable:    false
      description: A specific precondition that must be satisfied.
      constraints:
        - Maximum 300 characters
    satisfied:
      type:        boolean
      required:    true
      nullable:    false
      description: Whether this precondition is confirmed satisfied at
                   the time of plan production. All preconditions must
                   be satisfied before the plan may be used to initiate
                   distribution.
    verified_by:
      type:        string
      required:    true
      nullable:    false
      description: The agent or check that confirmed this precondition.

## VALIDATION_RULES

V01: plan_id is non-null and matches format
     DISTPLAN-{doc_id}-{version}-{NNNN}.
V02: confidentiality_class is one of [C0, C1, C2, C3].
V03: When confidentiality_class is not C0: external_distribution_permitted
     is false AND no target_recipients entry has recipient_type: external.
V04: target_recipients is non-empty.
V05: All preconditions have satisfied: true before distribution begins;
     a plan with any unsatisfied precondition must not be acted on.
V06: preconditions contains at least 2 entries.
V07: planned_at is a valid ISO 8601 datetime with timezone.
V08: doc_version matches format MAJOR.MINOR.PATCH.
V09: All recipient_object entries have non-null recipient_id,
     recipient_type, format, and access_basis.
